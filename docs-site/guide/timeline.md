# タイムライン

タイムラインでは、画像・動画・音声などを時間軸に配置して、一つの映像を作ります。字幕や図形を重ねたり、エフェクトで下の映像を加工したり、[Visual Module](./visual-module.md)で組んだ処理を決まった時間だけ動かしたりできます。

## シーン・レイヤー・クリップ

タイムラインは、次の3つの単位で構成されます。

| 単位 | 役割 | 例 |
| --- | --- | --- |
| シーン（Scene） | 一つの時間軸と画面サイズを持つ、レイヤーのまとまり | 本編、オープニング |
| レイヤー（Layer） | 素材や処理の種類、見た目・音量などの設定を持つ段 | 背景動画、タイトル、BGM |
| クリップ（Clip） | レイヤーを表示・再生する時間範囲 | タイトルを2秒から5秒まで表示する区間 |

例えば、10秒のシーンに次のようなレイヤーを置けます。映像は下の段から上の段へ重ねます。

| 上下の順序 | レイヤー | クリップの範囲 |
| --- | --- | --- |
| 上 | タイトルのテキスト | 2〜5秒 |
| 中 | 背景の動画 | 0〜10秒 |
| 下 | BGMの音声 | 0〜10秒 |

この場合、2〜5秒の間だけ背景動画の上にタイトルが表示されます。音声レイヤーは画像を出力しないため、映像を隠しません。

グループとTransformを除くレイヤーには、複数のクリップを置けます。同じレイヤー内ではクリップ同士を重ねられませんが、終了と開始をぴったり接触させることはできます。同じ時刻に複数の素材を表示するには、別のレイヤーを使います。

### レイヤーで共有する設定

レイヤーの名前・パラメータ・キーフレーム・合成設定・音量は、同じレイヤー内のクリップで共有します。例えば、画像レイヤーの不透明度を変えると、そのレイヤー内のすべての画像クリップに適用されます。

画像・動画・音声の素材や、シーンレイヤーが参照するシーンはクリップごとに選びます。一方、テキストの本文、シェイプの種類、エフェクトの種類、Visual Moduleの定義や参照先はレイヤーの設定です。クリップごとに別の設定が必要なら、レイヤーを分けるか、対応するパラメータにキーフレームを使います。

クリップがない区間では、そのレイヤーは映像や音声を出しません。最後のクリップを削除してもレイヤーやキーフレームは残るので、同じ設定のままクリップを追加し直せます。

## シーンを管理する

タイムライン上部の **Scene** メニューで、編集するシーンを切り替えたり、**New Scene** からシーンを追加したりできます。隣のメニューには、名前変更・複製・削除、**Scene resolution**（解像度設定）があります。他のシーンから参照されているシーンは削除できません。

シーンの長さは、そのシーン内のグループ・Transformの子孫も含めたクリップのうち、最も遅い終了時刻までです。クリップがなければ0秒です。キーフレームだけを後ろに置いても、シーンは長くなりません。

解像度はプロジェクトの基準サイズに合わせるか、幅と高さを指定します。別のシーンに配置した場合も、「プロジェクトに合わせる」は親シーンのサイズではなく、プロジェクトの基準サイズを使います。

シーンを別のシーンの中で使う方法は、[シーンレイヤー](./timeline/layers/scene.md)を参照してください。

## カメラと奥行き {#camera}

**Add Layer → Camera** から[カメラレイヤー](./timeline/layers/camera.md)を追加し、シーンの視点を設定できます。各レイヤーは画面と平行な平面として描かれます。カメラの向きは固定で、3Dの傾き・平面同士の交差・Zによる自動並べ替えは扱いません。重なり順はタイムラインの上下関係を維持します。

| 設定 | 動作 |
| --- | --- |
| Camera XY | 視点を左右・上下へ移動します。映像は逆方向へ動きます |
| Camera Z | 視点の距離です。小さくすると平面へ近づきます |
| Vertical field of view | 縦方向の画角（度）です。広げると広い範囲が映ります |
| レイヤーの Compositing → Z | 大きくするとカメラに近づき、大きく映ります |

初期値はXYが0、Camera Zが約2.414、画角45度です。レイヤーのZが0なら従来の2D配置と同じ大きさ・位置になります。Zの1単位はシーンの高さの半分に相当します。カメラと同じ位置・背後や、カメラから0.001単位未満の平面は表示しません。カメラ設定とレイヤーのZには、式・キーフレーム・オートメーションを使えます。カメラのパラメータをキーフレーム入力へ切り替え、レイヤーを展開すると、タイムライン上でキーの追加・移動・コピー・削除ができます。キーの時刻は所属シーン基準です。

現在時刻にクリップがある、有効なカメラレイヤーのうち最上段を採用します。カメラレイヤーが映像レイヤーより下にあっても、そのシーン全体に適用します。該当するカメラがない区間では2D表示となり、Zによる拡大縮小や非表示は行いません。設定済みのZは保持され、有効なカメラの区間で再び適用されます。カメラはシーン直下、または祖先がすべてTransformの場所に配置できます。グループ配下には入れられません。階層を展開した表示順で優先順位を決め、折りたたみ状態は影響しません。

映像レイヤーとグループの**Coordinate space**は、レイヤー一覧の立方体アイコンで切り替えます。オンは**In space**、オフは**On screen**です。詳細パネルの**Compositing → Coordinate space**からも変更できます。新規レイヤーの初期値はOn screenです。Coordinate spaceはレイヤー全体で共通の静的な設定で、式・キーフレーム・オートメーションでは切り替えられません。変更はUndo/Redoに対応します。

**In space** はカメラとZによる奥行き表現を有効にします。**On screen** は、その合成先の画面座標で配置します。画面全体を加工するEffectやVisual Module、視点に追従させない字幕に使います。奥行きを維持するグループ内では、その親グループの位置・拡縮も重ねて適用しません。平面化グループ内のOn screenはグループ内部の2D座標で、外側の平面配置は引き続き適用されます。TransformのXY移動はOn screenにも加わりますが、TransformのZは適用しません。On screenへ切り替えても、設定済みのZやそのキーフレームは保持されます。

[グループ](./timeline/layers/group.md)は、内部を2D合成して1枚の平面にするか、子のZを保ったまま投影後にまとめるかを選べます。[子Scene](./timeline/layers/scene.md)は自身のカメラで描画を完了し、親Sceneでは1枚の平面になります。

### 画面外の内容と画質

Text・Shapeとグループ内の中間画像は画面外の内容も保持します。子を右へずらしてから親を左へ戻した場合や、カメラで画面外へ移動した場合も、その部分を表示できます。**Clip to frame** を有効にすると、そのレイヤーの基準枠で切り取れます。切り取った画素は親やカメラを動かしても復元しません。

Effect・Visual Moduleの入出力や、別Sceneの出力は有限の画面です。下層画像をEffect・Visual Moduleへ渡す時点で、その合成先のシーン枠へ収めます。これらの処理の外側の画素は生成しません。

カメラで拡大しても素材を自動で高解像度に再生成しないため、大きな拡大ではぼける場合があります。広い画面外領域や多段グループは中間画像のメモリー使用量・描画時間を増やします。過大な領域では画素密度を下げてGPU資源を制限するため、細部が粗くなることがあります。必要に応じてClip to frame、プレビュー倍率、素材・出力解像度を調整してください。

カメラ移動もプロジェクトのモーションブラーに含まれます。レイヤーの **Disable motion blur** でそのレイヤー自身を固定しても、外側のカメラ移動によるブラーは残ります。カメラレイヤーの **Disable camera motion blur** をオンにすると、そのカメラによるブラーだけを無効にできます。露光中に使用するカメラが切り替わる境界では露光範囲を区切り、前後の視点を混ぜません。上段に隠れて採用されないカメラの開始・終了や、同じカメラレイヤーの隣接クリップの境界では、露光を短縮しません。

## レイヤーを追加する

タイムラインの **＋（Add Layer）** から種類を選びます。グループとTransform以外の新しいレイヤーには、現在のシーク位置から標準で5秒のクリップが作られます。動画・音声の素材が5秒より短い場合は、素材の長さまでになります。

| 種類 | 主な用途 |
| --- | --- |
| [画像](./timeline/layers/image.md) | 写真・ロゴ・背景などの静止画を表示する |
| [動画](./timeline/layers/video.md) | 動画素材の映像と音声を使う |
| [音声](./timeline/layers/audio.md) | BGM・効果音・録音を再生する |
| [テキスト](./timeline/layers/text.md) | タイトルや字幕を描く |
| [シェイプ](./timeline/layers/shape.md) | 楕円や長方形を描く |
| [エフェクト](./timeline/layers/effect.md) | 一つのエフェクトで映像を生成・加工する |
| [Visual Module（インライン）](./timeline/layers/inline-visual-module.md) | そのレイヤー専用のノード構成を作る |
| [Visual Module（参照）](./timeline/layers/visual-module.md) | プロジェクト内のVisual Moduleを再利用する |
| [カメラ](./timeline/layers/camera.md) | 視点を動かし、クリップでカメラを切り替える |
| [Transform](./timeline/layers/transform.md) | カメラや映像の子を持ち、画像をまとめずにXYZ移動を継承する |
| [グループ](./timeline/layers/group.md) | 同じシーン内のレイヤーをまとめ、合成設定や音量を一括で調整する |
| [シーン](./timeline/layers/scene.md) | 別のシーンを映像・音声として配置する |
| [VOICEVOX](./timeline/layers/voicevox.md) | 読み上げ音声と字幕を作る |

レイヤーを選ぶと、詳細パネルで名前や種類ごとの設定を編集できます。レイヤーの並び替えで、映像を重ねる順序や、エフェクトが受け取る下層の内容が変わります。

レイヤーは初期状態では折りたたまれており、新しく追加したレイヤーも折りたたまれます。**Wrap in Transform** でまとめた直後は子を展開します。レイヤー名の右にある矢印で、展開・折りたたみを切り替えられます。通常のレイヤーを折りたたむと、クリップを表示するメインレーンだけが残り、キーフレームレーン・Clip timeの目盛り・VOICEVOXのSpeechレーンは非表示になります。グループを折りたたむと、子レイヤーが非表示になります。折りたたんでも映像や音声の出力、キーフレームの効果は変わりません。

レイヤーの名前の行をクリックしてから、Shiftを押しながら別の行をクリックすると、間のレイヤーも含めて範囲選択できます。続けてShift＋クリックすると、同じ起点から選択範囲を変更できます。折りたたんだグループ内の子レイヤーは範囲に含まれません。Ctrl／Command＋クリックでは個別に選択・解除でき、Ctrl／Command＋Shift＋クリックでは既存の選択に範囲を追加できます。

レイヤーの名前の行を右クリックすると、**Group**（グループ化）・**Rename**（名前変更）・**Duplicate**（複製）・**Delete**（削除）のメニューが開きます。選択済みの行を右クリックすると選択中のレイヤー全体が対象になり、未選択の行ではそのレイヤーだけが対象になります。Renameは単一選択時だけ表示され、Groupは同じ階層で連続するレイヤーを選択した場合に使えます。複製は元レイヤーのすぐ上に配置され、グループの子レイヤーも含みます。複数レイヤーの複製・削除も、一回のUndoで元に戻せます。

## グループでまとめる

同じ階層で連続するレイヤーを複数選択し、**Group** でまとめられます。グループ内にさらにグループを作ることもできます。グループの行に表示される帯を左右へドラッグすると、子孫のクリップとキーフレームをまとめて移動できます。帯の長さは変更できません。詳しくは[グループレイヤー](./timeline/layers/group.md)を参照してください。

## クリップを編集する

クリップを選択すると、詳細パネルに開始時刻や長さが表示されます。数値入力の時間単位はミリ秒（ms）です。1秒は1000msです。

| 操作 | 変わるもの |
| --- | --- |
| クリップ本体を左右にドラッグ／**Start** を変更 | シーン上の配置位置。使う素材の範囲は維持する |
| 左端をドラッグ／**Trim start** を変更 | 開始位置・長さ・内容オフセット。後ろの終了位置を維持する |
| 右端をドラッグ／**Duration** を変更 | 長さ。開始位置と内容オフセットを維持する |
| レイヤーのクリップ用レーンの空白をダブルクリック | その位置にクリップを追加する |
| クリップの右クリックメニューの **Delete**／**Remove Clip**／選択中にDelete・Backspace | クリップを削除する |

空白への追加は標準5秒で、次のクリップまでの空きや、動画・音声の素材長に制限されます。移動やトリムでも、隣のクリップを押し出したり追い越したりはしません。画像やVisual Moduleなどの生成系クリップは、現在、左端を前へ延ばす操作に対応していません。

動画・音声クリップには右側に二つのハンドルがあります。右上は素材範囲のトリム、右下の繰り返しアイコンはトリム範囲をループさせる全体長の変更です。Inspectorでは **Trimmed duration** と **Total duration** を分けて設定します。ループ中のトリムは全体終端を維持します。詳しくは[動画レイヤーのループ再生](./timeline/layers/video.md)を参照してください。

Shift・Ctrl・Commandを押しながらクリップを選ぶと複数選択でき、まとめて移動できます。複数移動では間隔を保ち、すべてのクリップが収まる範囲内で移動します。配置位置や長さは整数ミリ秒で扱い、長さは最低1msです。

選択済みのクリップを右クリックすると、**Delete** で選択中のクリップをまとめて削除できます。未選択のクリップを右クリックした場合は、そのクリップだけが対象になります。複数クリップの削除も、一回のUndoで元に戻せます。

クリップを移動すると、移動開始時にその区間内にあるキーフレームやVOICEVOXの発話キーも同じ量だけ移動します。終端ちょうどのキーも追従しますが、同じレイヤーの次のクリップがその時刻から始まる場合は、次のクリップ側として扱います。

同じパラメータやSpeechレーンの動かさないキーとの間には100msを残し、追い越せない位置でクリップごと止まります。開始時から100ms未満なら、その間隔を下限にします。複数選択では全対象を同じ量だけ動かし、キー同士の間隔を保ちます。

トリムではキーを移動しません。トリムで区間外になったキーは、その後クリップを移動しても追従しません。また、区間外のキーとの補間や、区間より前から続く発話の再生位置まで維持する操作ではありません。

タイムラインの背景を押すと、その時点で選択が解除されます。そのままドラッグすると、範囲内のクリップやキーフレームを選択できます。Shiftを押しながら操作すると、既存の選択を保持して範囲選択できます。

### コピーと貼り付け

クリップを選び、Ctrl+C／Ctrl+V（macOSではCommand+C／Command+V）でコピー・貼り付けできます。コピー元と同じシーン・同じレイヤーへ、先頭のクリップが現在のシーク位置に来るように貼り付けます。複数クリップの間隔と、それぞれの素材・内容オフセットまたは素材範囲・速度・ループ・長さを維持します。

一つでも既存クリップに重なる場合は、全体を貼り付けません。レイヤーの設定やキーフレームはクリップと一緒にはコピーされません。

::: info 現在の制約
クリップのレイヤー間移動・分割・スリップ編集には未対応です。動画・音声はクリップごとの固定速度と逆再生に対応しています。途中で速度を変えるキー・式には未対応です。
:::

## シーン上の時刻と内容時刻 {#time}

シーン上の配置位置と、素材のどこを使うかは別の情報です。

通常再生の動画・音声クリップは **Source range** に使用する素材範囲を持ち、**Speed** と **Reverse playback** でその範囲の進み方を決めます。例えば、シーンの5秒から素材の2〜8秒を200%で再生すると、シーンの6秒では素材の4秒、クリップ全体は3秒になります。逆再生では同じ素材範囲を末尾から再生します。設定方法は[動画レイヤー](./timeline/layers/video.md)・[音声レイヤー](./timeline/layers/audio.md)を参照してください。

動画の **Hold current frame** は、指定地点のフレームをクリップ全体で表示します。素材の時刻は固定され、表示時間は独立して調整できます。不透明度や変形のキーは引き続きシーンの時刻で進み、元動画の音声は無音になります。

ループ中は素材を読み出す位置がトリム範囲の再生末尾から再生先頭へ戻ります。動画の映像と有効な音声は同じ範囲・倍率・方向を使います。

子シーンやVisual Moduleなどの内容時刻は、従来どおり **Content offset**（内容オフセット）と配置位置から求めます。これらのクリップには速度設定はありません。

```text
内容時刻 = 内容オフセット + 現在のシーン時刻 − クリップの開始時刻
```

一方、レイヤーの不透明度・位置・音量・公開パラメータなどのキーや式は、所属シーン上の時刻を使います。クリップの移動時には追従対象のキーの時刻を書き換えますが、式の時間基準は変わりません。詳しくは[パラメータの時間と参照範囲](./parameters.md#time-and-scope)を参照してください。

クリップの終了時刻ちょうどでは、そのクリップは無効になります。例えば0〜3秒と3〜5秒のクリップを接して置くと、3秒では後者だけが使われます。

## 映像を合成する {#compositing}

映像は透明な背景から始まり、有効なレイヤーを下から順に合成します。画像を出力するレイヤーの **Compositing** で、合成方法・不透明度・変形を設定できます。

### 通常合成と置き換え

**Blend mode** の初期値は通常合成（`normal`）です。レイヤーの透明な部分から下の映像が見えるので、タイトルや図形を重ねる用途に向いています。乗算や加算など、色の混ぜ方を変える合成方法も選べます。

置き換え（`replace`）は、レイヤーの出力を、背景まで含めた完成映像として扱います。**Opacity** が1なら、透明部分も含めて下の映像を置き換えます。0なら下の映像のまま、途中の値では下の映像とレイヤーの出力の間を補間します。

例えば、下の動画全体を加工するエフェクトやVisual Moduleには置き換えが適しています。背景を含んだ出力を通常合成すると、その背景をもう一度重ねることになり、半透明部分の見た目が変わる場合があります。

クリップがないレイヤーは合成を行いませんが、有効なクリップが透明な画像を返す場合は合成します。置き換えでは、その透明な画像によって下の映像も透明になります。

### Fitと変形

素材は **Fit** で画面に合わせてから、**Origin** を支点に拡大縮小・回転し、その支点を **Position** の位置へ配置します。

| 設定 | 意味 |
| --- | --- |
| **Fit** | `contain` は縦横比を保って全体を収める（初期値）。`cover` は縦横比を保って画面を埋め、はみ出しを切る。`stretch` は画面の縦横比に合わせて伸縮する |
| **Position** | 支点を置く画面上の位置。中央が `[0, 0]`、左下が `[-1, -1]`、右上が `[1, 1]` |
| **Origin** | 素材内の支点。透明な余白も含む素材全体の中央が `[0, 0]`、左下が `[-1, -1]`、右上が `[1, 1]` |
| **Scale** | 横・縦の倍率。`[1, 1]` が等倍、負の値は反転、いずれかが0なら透明 |
| **Rotation** | 時計回りの回転。値1が180度、2が360度 |
| **Opacity** | 不透明度。初期値は1 |

例えば、`Origin = [-1, -1]`、`Position = [-1, -1]` にすると、素材の左下をシーンの左下に合わせられます。Originは回転の中心だけでなく配置にも影響するため、回転や倍率を変えなくてもOriginの変更で映像が動きます。

変形はレイヤーが出した画像全体にかかります。背景を加工するエフェクトの場合も、作用する場所だけを動かす設定ではありません。加工位置だけを変えたい場合は、エフェクト内部の位置や範囲のパラメータを使います。また、Scaleを変えても描画解像度自体は変わりません。

## モーションブラー {#motion-blur}

プロジェクト設定の **Motion blur** を有効にすると、フレーム前後の複数時刻で描画した映像を平均し、動きをぼかします。**Shutter angle** が露光時間、**Export samples** が書き出し時のサンプル数です。プレビューのサンプル数はフッターの **Motion blur** で選択します。

映像レイヤーの **Compositing → Disable motion blur** をオンにすると、そのレイヤー自身のモーションブラーを無効にできます。初期値はオフで、プロジェクトの設定に従います。プロジェクトで無効になっているブラーをレイヤー側で有効にすることはできません。

オンにしたレイヤーは、表示するクリップ・内容・変形・不透明度などをフレーム本来の時刻で評価します。そのレイヤーのクリップ開始・終了や動画のループ境界によって、他のレイヤーの露光が短くなることもありません。例えば字幕だけを無効にすると、字幕の出入りによって背景のブラーが変化するのを防げます。音声の再生には影響しません。

グループ・シーンレイヤーでオンにすると、その配下の映像も含めて無効になります。内部のレイヤーに保存された設定は変更しません。同じ子シーンの別配置には、それぞれの配置の設定が適用されます。

子レイヤーだけで無効にしても、親グループや配置先のシーンレイヤーが動くことによるブラーは残ります。また、下層を入力にするエフェクトやVisual Moduleでは、入力画像の動きやブラーは引き続き反映されます。

ブラー対象のレイヤーは共通のサンプル時刻で描画します。対象レイヤーのカットや動画のループ境界、現在描画している最上位シーンの開始・終了をまたがないよう、必要に応じて全体の露光を短縮します。そのため、ブラー対象のままの別レイヤーのカットでは、背景のブラーも短くなることがあります。子シーン内のカットも対象ですが、ブラーを無効にしたレイヤーが子シーンの長さを決めている場合、その終端によって親シーンの露光が短くなることはありません。

::: info 履歴に依存するエフェクト
過去の描画結果を使うエフェクトは、モーションブラーの動作保証対象外です。レイヤーのブラーを無効にしても、下層入力や各サンプルの評価によって描画履歴が更新される場合があります。
:::

## 音声とプレビュー

音声・動画・シーン・VOICEVOXのレイヤーは、**Audio → Volume** で音量を調整します。1が元の音量、0が無音です。複数のレイヤーの音声は、それぞれの音量を適用してミックスします。映像のOpacityは音量を変えません。

タイムライン上部の **Preview** でタイムラインの表示に切り替え、再生・一時停止やシークで確認します。フレーム送り・前後のキーへの移動、**Snap Settings** によるスナップ設定も利用できます。**CUE** は押している間だけ再生し、離すと試聴開始位置へ戻ります。

プレビューのヘッダーには、現在表示しているシーンの名前が表示されます。名前をクリックすると、**Scene** の一覧から表示するシーンを切り替えられます。**Visual Module** の一覧から対象を選ぶと、LIVEプレビューに切り替わります。

## 最初の編集例

1. Assetsパネルの **Add asset** で、背景に使う画像を読み込みます。
2. シーク位置を0秒にし、**Add Layer → Image** でその画像を選びます。
3. シーク位置を2秒にし、**Add Layer → Text** でタイトルを作ります。フォントの読み込みと選択は[テキストレイヤー](./timeline/layers/text.md)を参照してください。
4. テキストレイヤーを画像レイヤーより上に置き、クリップの右端を表示したい時刻まで調整します。
5. テキストレイヤーのOpacityにキーを設定すれば、[フェードイン](./parameters.md#keyframes)も作れます。

素材を配置してから、表示期間・上下関係・パラメータの順に調整すると、結果を確認しながら編集できます。

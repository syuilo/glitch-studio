# タイムライン

タイムラインでは、画像・動画・音声などを時間軸に配置して、一つの映像を作ります。字幕や図形を重ねたり、エフェクトで下の映像を加工したり、[Visual Module](./visual-module.md)で組んだ処理を決まった時間だけ動かしたりできます。

## シーン・レイヤー・クリップ

タイムラインは、次の3つの単位で構成されます。

| 単位 | 役割 | 例 |
| --- | --- | --- |
| シーン（Scene） | 一つの時間軸と画面サイズを持つ、レイヤーのまとまり | 本編、オープニング |
| レイヤー（Layer） | 素材や処理の種類、見た目・音量などの設定を持つ段 | 背景動画、タイトル、BGM |
| クリップ（Clip） | レイヤーを表示・再生する時間範囲 | タイトルを2秒から5秒まで表示する区間 |

例えば、10秒のシーンに次のようなレイヤーを置けます。映像は下の段から上の段へ重ねます。

| 上下の順序 | レイヤー | クリップの範囲 |
| --- | --- | --- |
| 上 | タイトルのテキスト | 2〜5秒 |
| 中 | 背景の動画 | 0〜10秒 |
| 下 | BGMの音声 | 0〜10秒 |

この場合、2〜5秒の間だけ背景動画の上にタイトルが表示されます。音声レイヤーは画像を出力しないため、映像を隠しません。

一つのレイヤーに複数のクリップを置けます。同じレイヤー内ではクリップ同士を重ねられませんが、終了と開始をぴったり接触させることはできます。同じ時刻に複数の素材を表示するには、別のレイヤーを使います。

### レイヤーで共有する設定

レイヤーの名前・パラメータ・キーフレーム・合成設定・音量は、同じレイヤー内のクリップで共有します。例えば、画像レイヤーの不透明度を変えると、そのレイヤー内のすべての画像クリップに適用されます。

画像・動画・音声の素材や、シーンレイヤーが参照するシーンはクリップごとに選びます。一方、テキストの本文、シェイプの種類、エフェクトの種類、Visual Moduleの定義や参照先はレイヤーの設定です。クリップごとに別の設定が必要なら、レイヤーを分けるか、対応するパラメータにキーフレームを使います。

クリップがない区間では、そのレイヤーは映像や音声を出しません。最後のクリップを削除してもレイヤーやキーフレームは残るので、同じ設定のままクリップを追加し直せます。

## シーンを管理する

タイムライン上部の **Scene** メニューで、編集するシーンを切り替えたり、**New Scene** からシーンを追加したりできます。隣のメニューには、名前変更・複製・削除と **Scene resolution**（解像度設定）があります。他のシーンから参照されているシーンは削除できません。

シーンの長さは、そのシーンに直接置かれたクリップのうち、最も遅い終了時刻までです。クリップがなければ0秒です。キーフレームだけを後ろに置いても、シーンは長くなりません。

解像度はプロジェクトの基準サイズに合わせるか、幅と高さを指定します。別のシーンに配置した場合も、「プロジェクトに合わせる」は親シーンのサイズではなく、プロジェクトの基準サイズを使います。

シーンを別のシーンの中で使う方法は、[シーンレイヤー](./timeline/layers/scene.md)を参照してください。

## レイヤーを追加する

タイムラインの **＋（Add Layer）** から種類を選びます。新しいレイヤーには、現在のシーク位置から標準で5秒のクリップが作られます。動画・音声の素材が5秒より短い場合は、素材の長さまでになります。

| 種類 | 主な用途 |
| --- | --- |
| [画像](./timeline/layers/image.md) | 写真・ロゴ・背景などの静止画を表示する |
| [動画](./timeline/layers/video.md) | 動画素材の映像と音声を使う |
| [音声](./timeline/layers/audio.md) | BGM・効果音・録音を再生する |
| [テキスト](./timeline/layers/text.md) | タイトルや字幕を描く |
| [シェイプ](./timeline/layers/shape.md) | 楕円や長方形を描く |
| [エフェクト](./timeline/layers/effect.md) | 一つのエフェクトで映像を生成・加工する |
| [Visual Module（インライン）](./timeline/layers/inline-visual-module.md) | そのレイヤー専用のノード構成を作る |
| [Visual Module（参照）](./timeline/layers/visual-module.md) | プロジェクト内のVisual Moduleを再利用する |
| [シーン](./timeline/layers/scene.md) | 別のシーンを映像・音声として配置する |
| [VOICEVOX](./timeline/layers/voicevox.md) | 読み上げ音声と字幕を作る |

レイヤーを選ぶと、詳細パネルで名前や種類ごとの設定を編集できます。レイヤーの並び替えで、映像を重ねる順序や、エフェクトが受け取る下層の内容が変わります。

## クリップを編集する

クリップを選択すると、詳細パネルに開始時刻や長さが表示されます。数値入力の時間単位はミリ秒（ms）です。1秒は1000msです。

| 操作 | 変わるもの |
| --- | --- |
| クリップ本体を左右にドラッグ／**Start** を変更 | シーン上の配置位置。使う素材の範囲は維持する |
| 左端をドラッグ／**Trim start** を変更 | 開始位置・長さ・内容オフセット。後ろの終了位置を維持する |
| 右端をドラッグ／**Duration** を変更 | 長さ。開始位置と内容オフセットを維持する |
| レイヤーのクリップ用レーンの空白をダブルクリック | その位置にクリップを追加する |
| **Remove Clip**／選択中にDelete・Backspace | クリップを削除する |

空白への追加は標準5秒で、次のクリップまでの空きや、動画・音声の素材長に制限されます。移動やトリムでも、隣のクリップを押し出したり追い越したりはしません。画像やVisual Moduleなどの生成系クリップは、現在、左端を前へ延ばす操作に対応していません。

Shift・Ctrl・Commandを押しながらクリップを選ぶと複数選択でき、まとめて移動できます。複数移動では間隔を保ち、すべてのクリップが収まる範囲内で移動します。配置位置や長さは整数ミリ秒で扱い、長さは最低1msです。

### コピーと貼り付け

クリップを選び、Ctrl+C／Ctrl+V（macOSではCommand+C／Command+V）でコピー・貼り付けできます。コピー元と同じシーン・同じレイヤーへ、先頭のクリップが現在のシーク位置に来るように貼り付けます。複数クリップの間隔と、それぞれの素材・内容オフセット・長さを維持します。

一つでも既存クリップに重なる場合は、全体を貼り付けません。レイヤーの設定やキーフレームはクリップと一緒にはコピーされません。

::: info 現在の制約
クリップのレイヤー間移動・分割・スリップ編集・再生速度を変える時間伸縮には未対応です。また、クリップを移動しても、レイヤーのキーフレームやVOICEVOXの発話キーは追従しません。
:::

## シーン上の時刻と内容時刻 {#time}

シーン上の配置位置と、素材のどこを使うかは別の情報です。**Content offset**（内容オフセット）は、クリップの先頭で使う素材側の時刻です。

```text
内容時刻 = 内容オフセット + 現在のシーン時刻 − クリップの開始時刻
```

例えば、シーンの5秒に始まる動画クリップの内容オフセットが2秒なら、シーンの6秒では動画の3秒の位置を表示します。動画・音声の再生位置、子シーンに渡す時刻、Visual Module内部の時間は、この内容時刻を使います。

一方、レイヤーの不透明度・位置・音量・公開パラメータなどのキーや式は、所属シーン上の時刻を使います。そのため、クリップを移動してもフェードなどのキーは元の時刻に残ります。詳しくは[パラメータの時間と参照範囲](./parameters.md#time-and-scope)を参照してください。

クリップの終了時刻ちょうどでは、そのクリップは無効になります。例えば0〜3秒と3〜5秒のクリップを接して置くと、3秒では後者だけが使われます。

## 映像を合成する {#compositing}

映像は透明な背景から始まり、有効なレイヤーを下から順に合成します。画像を出力するレイヤーの **Compositing** で、合成方法・不透明度・変形を設定できます。

### 通常合成と置き換え

**Blend mode** の初期値は通常合成（`normal`）です。レイヤーの透明な部分から下の映像が見えるので、タイトルや図形を重ねる用途に向いています。乗算や加算など、色の混ぜ方を変える合成方法も選べます。

置き換え（`replace`）は、レイヤーの出力を、背景まで含めた完成映像として扱います。**Opacity** が1なら、透明部分も含めて下の映像を置き換えます。0なら下の映像のまま、途中の値では下の映像とレイヤーの出力の間を補間します。

例えば、下の動画全体を加工するエフェクトやVisual Moduleには置き換えが適しています。背景を含んだ出力を通常合成すると、その背景をもう一度重ねることになり、半透明部分の見た目が変わる場合があります。

クリップがないレイヤーは合成を行いませんが、有効なクリップが透明な画像を返す場合は合成します。置き換えでは、その透明な画像によって下の映像も透明になります。

### Fitと変形

素材は **Fit** で画面に合わせてから、**Origin** を支点に拡大縮小・回転し、その支点を **Position** の位置へ配置します。

| 設定 | 意味 |
| --- | --- |
| **Fit** | `contain` は縦横比を保って全体を収める（初期値）。`cover` は縦横比を保って画面を埋め、はみ出しを切る。`stretch` は画面の縦横比に合わせて伸縮する |
| **Position** | 支点を置く画面上の位置。中央が `[0, 0]`、左下が `[-1, -1]`、右上が `[1, 1]` |
| **Origin** | 素材内の支点。透明な余白も含む素材全体の中央が `[0, 0]`、左下が `[-1, -1]`、右上が `[1, 1]` |
| **Scale** | 横・縦の倍率。`[1, 1]` が等倍、負の値は反転、いずれかが0なら透明 |
| **Rotation** | 時計回りの回転。値1が180度、2が360度 |
| **Opacity** | 不透明度。初期値は1 |

例えば、`Origin = [-1, -1]`、`Position = [-1, -1]` にすると、素材の左下をシーンの左下に合わせられます。Originは回転の中心だけでなく配置にも影響するため、回転や倍率を変えなくてもOriginの変更で映像が動きます。

変形はレイヤーが出した画像全体にかかります。背景を加工するエフェクトの場合も、作用する場所だけを動かす設定ではありません。加工位置だけを変えたい場合は、エフェクト内部の位置や範囲のパラメータを使います。また、Scaleを変えても描画解像度自体は変わりません。

## 音声とプレビュー

音声・動画・シーン・VOICEVOXのレイヤーは、**Audio → Volume** で音量を調整します。1が元の音量、0が無音です。複数のレイヤーの音声は、それぞれの音量を適用してミックスします。映像のOpacityは音量を変えません。

タイムライン上部の **Preview** でタイムラインの表示に切り替え、再生・一時停止やシークで確認します。フレーム送り・前後のキーへの移動、**Snap Settings** によるスナップ設定も利用できます。**CUE** は押している間だけ再生し、離すと試聴開始位置へ戻ります。

## 最初の編集例

1. Assetsパネルの **Add asset** で、背景に使う画像を読み込みます。
2. シーク位置を0秒にし、**Add Layer → Image** でその画像を選びます。
3. シーク位置を2秒にし、**Add Layer → Text** でタイトルを作ります。フォントの読み込みと選択は[テキストレイヤー](./timeline/layers/text.md)を参照してください。
4. テキストレイヤーを画像レイヤーより上に置き、クリップの右端を表示したい時刻まで調整します。
5. テキストレイヤーのOpacityにキーを設定すれば、[フェードイン](./parameters.md#keyframes)も作れます。

素材を配置してから、表示期間・上下関係・パラメータの順に調整すると、結果を確認しながら編集できます。

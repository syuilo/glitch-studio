# タイムライン

タイムラインでは、素材やVisual Moduleを時間に沿って並べます。複数の映像を重ねたり、音声を配置したりして、一つのSceneをつくります。

## Scene・レイヤー・クリップ

| 名前 | 役割 |
| --- | --- |
| Scene | 複数のレイヤーをまとめた、一つのタイムライン |
| レイヤー | 映像や音声を置く段。重ね順、パラメータ、合成設定などを持つ |
| クリップ | レイヤーの内容を、いつからどれだけ表示・再生するかを決める区間 |

同じレイヤーには複数のクリップを置けますが、時間を重ねることはできません。同時に表示したい映像は、別のレイヤーに置きます。

Sceneの長さは、そのScene内で最後に終わるクリップまでです。クリップがない区間では、そのレイヤーから映像や音声は出力されません。

## 例：最初のクリップを短くする

[新しいプロジェクト](./getting-started.md)の `Main Scene` には、Visual Moduleの10秒のクリップがあります。

1. タイムラインの **Preview** を押し、Sceneの出力をプレビューします。
2. クリップの右端を左へドラッグして、表示時間を短くします。
3. クリップ内の位置へシークし、映像が表示されることを確認します。
4. クリップ本体をドラッグして開始位置を右へ移動すると、その前に空白の時間をつくれます。

クリップの削除とレイヤーの削除は別の操作です。最後のクリップを削除しても、レイヤーとそのパラメータは残ります。

## レイヤーを追加する

タイムラインの **Add Layer**（＋）から、追加する種類を選びます。画像・動画・音声のほか、エフェクトやVisual Moduleも使用できます。

Visual Moduleには、主に次の二つの配置方法があります。

- **Visual Module (Reference)**：プロジェクト内のVisual Moduleを参照します。同じ定義を使う配置に、定義の編集が反映されます。
- **Visual Module (Inline)**：そのレイヤー専用のVisual Moduleを作成します。

## 重ね方を決める

通常の合成では、レイヤーの出力を下のレイヤーまでの映像に重ねます。不透明度や位置・回転・拡大率を調整して、配置を整えます。

`replace` は、下の映像を含めた完成結果を出力するVisual Moduleなどに使います。不透明度が1なら、透明な部分も含めて下の映像を置き換えます。

::: tip 変形する対象
レイヤーの変形は、そのレイヤーが出力した映像全体に適用されます。背景を加工するVisual Moduleでは、処理範囲だけでなく、出力に含まれる背景も一緒に動きます。
:::

## 時間に合わせて値を変える

位置や不透明度などを時間に合わせて変えたいときは、[パラメータのキーフレーム](./parameters.md#キーフレーム)を使います。

レイヤーのキーフレームはScene上の時刻に置かれます。現在、クリップを移動してもキーフレームは一緒には移動しないため、必要に応じてキーの位置も調整してください。

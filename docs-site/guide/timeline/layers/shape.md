# シェイプレイヤー

シェイプレイヤーは、楕円や長方形を描きます。字幕の背景、枠、円形のアクセント、輪郭を使ったアニメーションなどを、画像素材なしで作れます。

## 追加する

**Add Layer → Shape** から、**Ellipse**（楕円）または **Rectangle**（長方形）を選びます。長方形は **Corner radius** を設定すると角丸にできます。

一つのレイヤーに一つの形状を持ち、クリップはその表示期間を決めます。作成後に楕円から長方形などへ種類を変更することはできません。別の種類が必要なら、新しいレイヤーを作ります。

## 位置とサイズ

| 設定 | 意味 |
| --- | --- |
| **Position** | 形状の中心位置。画面中央が `[0, 0]`、左下が `[-1, -1]`、右上が `[1, 1]` |
| **Size** | 輪郭を付ける前の全幅・全高。両方ともシーンの高さを1とする |
| **Rotation** | 形状の中心を支点に時計回りに回転。1が180度 |
| **Corner radius** | 長方形の角丸半径。シーンの高さを1とする |

Sizeの初期値は `[0.5, 0.5]` です。横長のシーンでも縦横の基準は同じなので、Ellipseなら真円、Rectangleなら正方形になります。例えば高さ1080のシーンなら、幅・高さともに540を基準とした大きさです。

幅か高さが0以下になると透明になります。角丸半径は0から短辺の半分までに制限されます。

## 塗りと輪郭

**Fill** と **Stroke** は、それぞれ有効・無効と色を設定できます。初期状態は白い塗りが有効、輪郭が無効です。

**Stroke width** はシーンの高さに対する比率です。**Stroke alignment** で、形状の内側・中央・外側のどこに輪郭を付けるかを選べます。形状のSizeを変えても輪郭幅は維持されます。

例えば、Fillを無効にしてStrokeを有効にすると枠だけを描けます。字幕の背景にする場合は、塗りを半透明にした長方形を、[テキストレイヤー](./text.md)の下に置きます。

## 輪郭が描かれていくアニメーション

**Stroke progress** は輪郭を描く割合です。0で輪郭なし、0.5で半周、1で全周になります。塗りや輪郭幅には影響しません。

**Stroke start** は輪郭の開始位置です。形状の周に沿って、上中央を0、右中央を0.25、下中央を0.5、左中央を0.75、上中央へ戻る位置を1とし、時計回りに進みます。

Strokeを有効にし、Stroke progressを0から1へ[キーフレーム](../../parameters.md#keyframes)で変えると、一周描かれていくアニメーションになります。Stroke startだけを動かせば、部分的な輪郭を周回させられます。

## シェイプの設定と合成

シェイプ自体の位置・サイズ・回転と、**Compositing** の変形は別です。前者で図形を描き、その画像全体へ後者の変形や不透明度を適用します。

複数の図形はレイヤーを分けて重ねます。現在、一つのシェイプレイヤー内の複数形状、グラデーション、任意パス、プレビュー上での形状自体の直接編集には対応していません。

# Visual Moduleレイヤー（参照）

参照Visual Moduleレイヤーは、プロジェクト内の登録済み[Visual Module](../../visual-module.md)をタイムラインで使います。同じ処理を複数の場面へ配置し、ノード構成をまとめて管理したいときに向いています。

## 追加する

1. 処理を始めたい位置へシークします。
2. **Add Layer → Visual Module (Reference)** を選びます。
3. プロジェクト内のVisual Moduleを選択します。
4. **Module Parameters** で公開パラメータを設定し、クリップの長さを調整します。

選択肢にはプロジェクトに登録されているものが表示されます。現在、Visual ModuleエディターのNewは未実装です。その場で新しい構成を作る場合は、[インライン方式](./inline-visual-module.md)を使ってください。

## 共有するものと個別に設定するもの

| 内容 | 共有範囲 |
| --- | --- |
| ノード構成・内部ノードの設定・公開入出力の定義 | 同じVisual Moduleを参照する配置全体 |
| Module Parametersに指定した値・式・キー | そのレイヤー |
| 合成・不透明度・変形 | そのレイヤー |
| 開始時刻・長さ・内容オフセット | そのクリップ |

内部構成はVisual Moduleエディターで編集します。変更は同じ定義を使うLIVEや、ほかのタイムライン配置にも反映されます。

例えば「加工の強さ」を公開したVisual Moduleを二つのレイヤーから参照し、一方を0.2、もう一方を0.8にできます。構成は共有しながら、見た目をレイヤーごとに変えられます。指定していない公開パラメータは定義の初期値を使います。

## 入力と合成を決める

主画像入力には、そのレイヤーより下の合成映像が渡ります。この入力はModule Parametersの通常の編集項目には出ません。主音声入力がある場合は、初期状態で下層音声が割り当てられます。

映像にはPrimary outputに指定した主出力を使います。出力を受け取った後に、レイヤーのCompositingを適用します。

初期の合成は通常合成（`normal`）です。透明背景の素材を生成する構成ならそのまま使えます。下層の映像を加工して背景ごと返す構成なら、置き換え（`replace`）へ変更してください。[合成の違い](../../timeline.md#compositing)を参照してください。

## 時間と処理状態

Module Parametersの式やキーは、所属シーンの時刻で動きます。Visual Module内部のTIMEはクリップの内容時刻なので、トリムで開始する内容位置が変わります。内部のPROGRESSはクリップの表示区間内で0から1へ進みます。

定義を共有していても、各配置・各クリップの処理状態は独立しています。一方のクリップで蓄積したエフェクトの履歴が、別の配置へ引き継がれるわけではありません。

同じレイヤーに追加したクリップは、参照先と公開パラメータを共有します。別のVisual Moduleや異なる設定で同時に動かす場合は、レイヤーを分けます。

# 画像レイヤー

画像レイヤーは、Assetsに読み込んだ静止画を表示します。写真、ロゴ、背景、透過画像などを、指定した時間だけ映像に重ねたいときに使います。

## 追加する

1. Assetsパネルの **Add asset** から画像を読み込みます。
2. タイムラインで表示を始めたい位置へシークします。
3. **Add Layer → Image** を選び、読み込んだ画像を選択します。
4. 作成されたクリップの端を動かし、表示期間を調整します。

新しいクリップの長さは標準5秒です。静止画自体に再生時間はないため、右端を延ばして長く表示できます。同じレイヤーの次のクリップを越えて延ばすことはできません。

## サイズと配置を調整する

レイヤーを選び、**Compositing** を開きます。初期状態は通常合成・Opacity 1・Fit `contain`で、画像全体がシーンに収まります。

背景として画面全体を埋めるならFitを`cover`にします。ロゴを小さく重ねるならScaleを下げ、Positionで位置を決めます。透過画像の透明な部分からは下の映像が見えます。

Originは、透明な余白も含めた画像全体を基準にします。見えている図柄の中心と画像全体の中心が違うと、回転や配置の支点もずれます。詳しくは[合成と変形](../../timeline.md#compositing)を参照してください。

## 複数の画像を切り替える

同じレイヤーの空白にクリップを追加すると、そのクリップで使う画像を選べます。クリップの **Change source** から、別の画像へ差し替えることもできます。差し替え後も、開始位置と表示する長さは維持されます。

例えば、0〜3秒に写真A、3〜6秒に写真Bを置くと、同じレイヤーでスライドを切り替えられます。PositionやScaleなどの設定はレイヤー全体で共有されるため、画像ごとに別の配置を固定したい場合はレイヤーを分けます。

2枚をクロスフェードさせるには、別々の画像レイヤーに重なる時間を作り、上のレイヤーのOpacityを[キーフレーム](../../parameters.md#keyframes)で変化させます。

## 画像を加工する

画像の上に[エフェクトレイヤー](./effect.md)や[インラインVisual Moduleレイヤー](./inline-visual-module.md)を置くと、画像を含む下層の合成結果を加工できます。元の画像クリップの表示期間と、加工を有効にするクリップの期間は別々に設定できます。

移動・トリム・コピーの共通操作は[タイムライン](../../timeline.md)を参照してください。

# エフェクトレイヤー

エフェクトレイヤーは、一つのエフェクトを直接タイムラインで動かします。ノード構成を組まずに、下層の映像を加工したり、画像を生成したりしたいときに使います。クリップの期間だけ処理が有効になります。

## 追加する

1. 処理を始めたい位置へシークします。
2. **Add Layer → Effect** からエフェクトを選びます。
3. 下層を加工する場合は、加工対象のレイヤーより上に配置します。
4. レイヤーの詳細でパラメータを調整し、クリップで有効な期間を決めます。

エフェクトの種類とパラメータはレイヤーで共有します。別のエフェクトに変えるには、新しいエフェクトレイヤーを追加します。

## 加工と生成の初期設定

エフェクトは、既存の入力を加工するものと、画像などを生成するものに分かれます。追加時の設定は、それに合わせて決まります。

| 種類 | 主画像入力の初期値 | 合成の初期値 |
| --- | --- | --- |
| 加工するエフェクト | 主画像入力があれば **Layers below** | 置き換え（`replace`） |
| 生成するエフェクト | エフェクトで定義された初期値 | 通常合成（`normal`） |

Layers belowは、同じシーン内で自分より下にあるレイヤーの合成結果です。下に何もなければ透明な画像になります。

例えば背景動画の上に加工系エフェクトを置くと、下層映像を受け取り、加工後の結果で置き換えます。その上にテキストを置けば、テキストには加工をかけずに重ねられます。テキストも加工したい場合は、エフェクトレイヤーをテキストより上に置きます。

入力方式と合成方法は、作成後は独立した設定です。主入力を手動で変更しても合成方法は自動では変わりません。主画像入力をResetすると、加工系ではLayers belowへ戻ります。

## 入力とパラメータ

各パラメータには固定値・式・オートメーション・対応する型のキーなどを設定できます。レイヤーの式とキーは所属シーンの時刻で動き、クリップを移動しても時刻の基準は変わりません。

主入力以外でも、対応する画像入力にはLayers belowを指定できます。画像の読み取り方はSamplingから設定します。音声を受け取るエフェクトでは、[下層音声や指定レイヤーの音声](../../parameters.md#audio-input)を選べます。主音声入力を持つ場合、その初期値は下層音声です。

入力が選べない場合は、パラメータの型や接続可否を確認してください。すべてのパラメータが画像入力に対応しているわけではありません。

## 解像度と合成

描画解像度は次から選べます。

| モード | 使うサイズ |
| --- | --- |
| 自動（Auto） | 素材固有のサイズや、エフェクトが解像度の基準に使う入力画像のサイズ。どちらもなければ所属シーンのサイズ |
| 描画先（Context） | 所属シーンのサイズ |
| サイズ指定（Custom / Absolute） | 指定した幅と高さ |

描画後の位置・倍率・不透明度・重ね方は **Compositing** で調整します。画像を作る解像度と、画面上に置く大きさは別です。[合成の説明](../../timeline.md#compositing)も参照してください。

## Visual Moduleとの使い分け

一つのエフェクトで済む処理には、このレイヤーを使えます。分岐・複数入力・複数の処理を組み合わせたい場合は、[インラインVisual Module](./inline-visual-module.md)や[参照Visual Module](./visual-module.md)が向いています。

エフェクトに複数の出力があっても、タイムラインでは主出力だけを使います。主出力がないエフェクトは映像の合成を行いません。候補にはタイムラインでの利用に向かないものも含まれ、Player入力や、シーク前の描画履歴を必要とする動作は保証されません。

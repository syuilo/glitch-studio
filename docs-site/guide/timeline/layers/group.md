# グループレイヤー

グループは、同じシーン内の複数レイヤーをまとめるレイヤーです。タイトルと背景図形を一緒に動かしたり、複数の音声の音量をまとめて調整したりできます。グループの中にグループを作ることもできます。

## 作成と整理

同じ階層で連続するレイヤーをShift・Ctrl・Commandで選択し、**Group** を押します。**Add Layer → Group** では空のグループを作成できます。

レイヤー名の部分をドラッグすると移動できます。グループ行の中央へドロップするとその中へ入り、行の上端・下端へドロップするとその前後へ移動します。子を選んで **Move out** を押すと、一つ外の階層へ移せます。

グループ名の矢印で子の行を開閉できます。折りたたんでも映像や音声は変わりません。目のボタンでグループを無効にすると、子孫もすべて無効になります。

**Ungroup** は子をグループのあった位置へ取り出します。グループ自身の合成設定や音量は取り除かれるため、設定を変更していた場合は見た目や音量が変わります。作成・移動・解除はUndo/Redoで戻せます。

## 合成設定と音量

子の映像を透明背景にまとめ、その結果へグループ自身の **Compositing** を適用します。不透明度は子を合成した後に適用されます。例えば、重なり合う図形全体を一度に半透明にできます。画面サイズは所属シーンと同じで、画面の外側は切り取られます。

グループ内のエフェクトやVisual Moduleが下層画像を受け取る場合、同じグループ内の下層だけを使います。外側の背景は入力されません。そのため、背景を加工するエフェクトをグループに入れると、見た目が変わる場合があります。

グループの **Volume** は、子孫の音量に乗算されます。合成設定・音量には通常の式やキーフレームを使えます。

## 時間方向にまとめて動かす

グループの行には、子孫の最も早いクリップ開始から最も遅いクリップ終了までの帯が表示されます。途中の空白も含みます。帯を左右にドラッグすると、子孫のクリップと、グループ自身・子孫のキーフレームやVOICEVOX発話キーを同じ量だけ移動します。クリップの外にあるキーも移動します。

帯の端を伸縮することはできません。素材の読み出し位置・速度・長さは変わらず、子シーンを参照する場合も配置だけが移動します。式やオートメーションの時刻は所属シーンの時刻のままです。最も早いクリップやキーが0秒より前へ出ない位置で止まります。

空のグループには帯を表示しません。無効な子のクリップも帯の長さに含まれますが、映像・音声がない隙間を埋めることはありません。

## 音声参照と複製

**Audio from layer** は、同じシーン内なら別のグループ内のレイヤーも参照できます。参照先自身とその子孫の音量は反映し、参照先の親グループの音量は反映しません。ただし、参照先または祖先グループが無効なら入力なしになります。

グループを複製すると、その内部同士の音声参照は複製されたレイヤーへ付け替わります。外部のレイヤーへの参照はそのまま維持します。

## シーンとの違い

グループは所属シーンと時間軸・画面サイズを共有し、その場で子を所有します。[シーンレイヤー](./scene.md)は別に定義されたシーンを参照し、独自の画面サイズや時間軸を持つ内容を複数の場所へ再利用できます。シーンレイヤーにはクリップのトリムや内容オフセットがあり、グループにはありません。

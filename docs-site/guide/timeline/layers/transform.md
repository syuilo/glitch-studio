# Transformレイヤー

Transformは、子レイヤーへXYZの移動を加えるレイヤーです。カメラ・画像・テキスト・グループなどを入れられ、Transformを入れ子にすることもできます。子の画像を1枚にまとめず、それぞれの奥行き・不透明度・合成方法を保ちます。

## 作成と階層操作

**Add Layer → Transform** で空のTransformを追加します。同じ階層で連続するレイヤーを選び、ツールバーまたは右クリックメニューの **Wrap in Transform** を押すと、選択したレイヤーを子にできます。

グループと同じように、行の矢印で子を開閉します。レイヤー名をTransform行の中央へドラッグすると子として配置されます。**Move out** は一つ外の階層へ移動し、**Unwrap container** は親を取り除いて子を同じ位置へ取り出します。解除すると親の移動量がなくなるため、表示位置が変わる場合があります。これらの操作はUndo/Redoで戻せます。

Transformの無効化は、カメラ・音声を含む子孫全体へ適用します。折りたたみは表示だけの操作で、描画やカメラの選択に影響しません。

## 移動とアニメーション

詳細パネルの **Transform** で **Position XY** と **Position Z** を設定します。初期値はどちらも0です。式・キーフレーム・オートメーションが使え、時刻は所属シーン基準です。親と子の移動を重ね、入れ子なら祖先の移動も継承します。回転・拡縮・不透明度・音量の設定はありません。

例えば、カメラをTransformに入れ、カメラのXYをキーフレームで始点から終点まで動かします。親のXYに時間で変化する小さな揺れを与えると、移動経路へ揺れを加えられます。確認用には親のXYを次の式にすると、横方向に往復する揺れになります。

```aiscript
[0.02 * Math:sin(TIME * 20), 0]
```

カメラと映像を同じTransformに入れると両方が同じ量だけ移動するため、相対的な位置は変わりません。視点だけを揺らしたい場合は、映像をそのTransformの外に置きます。

**In space** の子は親のXYZを含めて投影します。**On screen** の子にもTransformのXY移動を加えますが、Zとカメラは適用しません。平面化グループの内部ではTransformのZも無視され、XYだけが内部の2D配置へ反映されます。

## グループとの違い

| 動作 | Transform | グループ |
| --- | --- | --- |
| 子の画像 | 下層へ個別に合成 | 独立して合成した結果を下層へ重ねる |
| 下層画像・下層音声の入力 | 外側の下層も引き継ぐ | グループ内の下層だけ |
| 全体の不透明度・合成方法・音量 | 持たない | まとめて設定できる |
| カメラの子 | 配置できる | 配置できない |

重なり順はタイムライン順です。Transformの子は連続したひとまとまりとして並び、外側のレイヤーが子の間に割り込むことはありません。Transform自体は中間画像や追加のGPU合成パスを作りません。

カメラはシーン直下、または祖先がすべてTransformの場所へ配置できます。グループの中のTransformにはカメラを入れられません。カメラの優先順位は、階層を展開した表示順で最上段の有効なカメラです。

## 時間移動とモーションブラー

Transform自身にクリップはありません。子孫クリップの最初から最後までを帯で表示し、帯をドラッグすると子孫のクリップと、親・子孫のキーを一括移動します。式・オートメーションの時計は所属シーンのままです。空のTransformには帯を表示しません。

**Disable motion blur for this subtree** は、Transform自身と子孫をフレームの基準時刻で評価します。さらに外側の親やシーンのカメラによる動きは残ります。子カメラだけでブラーを無効にした場合も、親Transformの揺れによるブラーは残ります。

音声の再生時刻・音量はTransformのXYZ移動では変わりません。音量の一括調整にはグループを使ってください。

# Transformレイヤー

Transformは、子レイヤーへXYZの移動・XYの拡縮・平面内の回転を加えるレイヤーです。カメラ・画像・テキスト・グループなどを入れられ、Transformを入れ子にすることもできます。子の画像を1枚にまとめず、それぞれの奥行き・不透明度・合成方法を保ちます。

## 作成と階層操作

**Add Layer → Transform** で空のTransformを追加します。同じ階層で連続するレイヤーを選び、ツールバーまたは右クリックメニューの **Wrap in Transform** を押すと、選択したレイヤーを子にできます。

グループと同じように、行の矢印で子を開閉します。レイヤー名をTransform行の中央へドラッグすると子として配置されます。**Move out** は一つ外の階層へ移動し、**Unwrap container** は親を取り除いて子を同じ位置へ取り出します。解除すると親の変形がなくなるため、表示が変わる場合があります。これらの操作はUndo/Redoで戻せます。

Transformの無効化は、カメラ・音声を含む子孫全体へ適用します。折りたたみは表示だけの操作で、描画やカメラの選択に影響しません。

## 移動・拡縮・回転とアニメーション

詳細パネルの **Transform** で **Position XY**・**Position Z**・**Scale**・**Rotation** を設定します。初期値は位置と回転が0、Scaleが `[1, 1]` です。式・キーフレーム・オートメーションが使え、時刻は所属シーン基準です。不透明度・音量の設定はありません。

ローカル原点を支点として、拡縮→回転→移動の順に適用します。子の大きさ・角度だけでなく、子の配置位置もまとめて変わります。回転の1は時計回り180度です。Scaleは横と縦で別々に設定でき、負数は反転、0はその軸を潰します。Zの距離はScaleで変わりません。

入れ子では子から親へ変換を重ねます。横と縦で異なる倍率の親と、回転した子を組み合わせると、直角が崩れるせん断も生じます。

例えば、カメラをTransformに入れ、カメラのXYをキーフレームで始点から終点まで動かします。親のXYに時間で変化する小さな揺れを与えると、移動経路へ揺れを加えられます。確認用には親のXYを次の式にすると、横方向に往復する揺れになります。

```aiscript
[0.02 * Math:sin(TIME * 20), 0]
```

カメラと映像を同じTransformに入れると両方が同じ量だけ移動するため、相対的な位置は変わりません。視点だけを揺らしたい場合は、映像をそのTransformの外に置きます。

子カメラの位置にも親の移動・拡縮・回転が反映され、親のRotationはカメラのRollへ加わります。Scaleはカメラ位置だけに作用し、画角・ロール・映像の縦横比を変更しません。そのため、カメラと映像を同じTransformに入れても、Scaleによる拡縮は相殺されません。

**In space** の子は親の変形とZを含めて投影します。**On screen** の子にもTransformのXY移動・拡縮・回転を適用しますが、Zとカメラは適用しません。平面化グループの内部ではTransformのZも無視され、移動・拡縮・回転が内部の2D配置へ反映されます。

## グループとの違い

| 動作 | Transform | グループ |
| --- | --- | --- |
| 子の画像 | 下層へ個別に合成 | 独立して合成した結果を下層へ重ねる |
| 下層画像・下層音声の入力 | 外側の下層も引き継ぐ | グループ内の下層だけ |
| 全体の不透明度・合成方法・音量 | 持たない | まとめて設定できる |
| カメラの子 | 配置できる | 配置できない |

重なり順はタイムライン順です。Transformの子は連続したひとまとまりとして並び、外側のレイヤーが子の間に割り込むことはありません。Transform自体は中間画像や追加のGPU合成パスを作りません。

カメラはシーン直下、または祖先がすべてTransformの場所へ配置できます。グループの中のTransformにはカメラを入れられません。カメラの優先順位は、階層を展開した表示順で最上段の有効なカメラです。

## 時間移動とモーションブラー

Transform自身にクリップはありません。子孫クリップの最初から最後までを帯で表示し、帯をドラッグすると子孫のクリップと、親・子孫のキーを一括移動します。式・オートメーションの時計は所属シーンのままです。空のTransformには帯を表示しません。

**Disable motion blur for this subtree** は、Transform自身と子孫をフレームの基準時刻で評価します。さらに外側の親やシーンのカメラによる動きは残ります。子カメラだけでブラーを無効にした場合も、親Transformの揺れによるブラーは残ります。

音声の再生時刻・音量はTransformの移動・拡縮・回転では変わりません。音量の一括調整にはグループを使ってください。

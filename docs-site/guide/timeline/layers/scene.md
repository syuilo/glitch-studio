# シーンレイヤー

シーンレイヤーは、別のシーンの映像と音声を、一つの素材のように配置します。タイトルと背景をまとめたオープニングや、複数のレイヤーで作った場面を再利用したいときに使います。

配置先を「親シーン」、配置する側を「子シーン」と呼びます。

## 追加する

1. タイムラインのSceneメニューから、子として使うシーンを作り、レイヤーやクリップを配置します。
2. 親シーンへ切り替え、配置したい位置へシークします。
3. **Add Layer → Scene** から子シーンを選びます。
4. 親シーンにできたクリップの表示期間を調整します。

クリップを選んで **Open scene** を押すと、参照先のシーンを編集できます。**Change source** では別のシーンに変更できます。変更しても配置の開始と長さは維持し、内容オフセットは0に戻ります。

## 子シーンのどこを再生するか

子シーンへは、クリップの[内容時刻](../../timeline.md#time)が渡ります。

例えば、親の10秒から始まるクリップで内容オフセットが2秒なら、親の11秒では子の3秒を表示します。子シーン内部のレイヤーのキーや式も、その子の3秒として評価されます。

子シーンの長さを編集しても、親の配置クリップの長さは自動では変わりません。親のクリップが子の終了より長い場合、子の終了後は透明・無音になります。子を長くした場合も、続きを見せるには親のクリップを延ばします。

同じ子シーンを複数回配置できます。子の内容を編集するとすべての参照先へ反映されますが、配置位置やトリムはクリップごとに独立しています。

## 画面サイズと変形

子シーンは、自分の解像度で一枚の画面を作ってから親へ渡します。親の **Compositing** のFit・Origin・Scaleなどは、透明な余白も含む子シーンの画面全体に適用されます。

例えば、子シーンの中央に小さなロゴだけを置いても、Originの基準はロゴの輪郭ではなく、子シーンの画面です。

子の解像度設定でプロジェクトに合わせる場合は、親シーンではなくプロジェクトの基準サイズを使います。正方形の子シーンを横長の親へ置くなど、異なる縦横比を組み合わせることもできます。

## 音声をまとめて扱う

子シーンに含まれる音声は、子側の各レイヤーの音量を適用してから、親のシーンレイヤーの **Audio → Volume** を適用します。親側で一つの場面全体をフェードアウトする、といった調整ができます。

シーンレイヤーを[音声解析の入力](../../parameters.md#audio-input)に指定すると、配置のトリムと音量を反映した子シーン全体の音声を使います。親から子シーン内部の特定レイヤーを直接選ぶことはできません。

## Visual Moduleとの使い分け

シーンはレイヤーと時間軸をまとめる単位です。[Visual Module](../../visual-module.md)は、ノードをつないだ処理をまとめる単位です。

字幕・BGM・複数の素材を含む一つの場面を再利用するならシーン、画像処理の構成と操作パラメータを再利用するならVisual Moduleが向いています。

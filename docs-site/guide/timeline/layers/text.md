# テキストレイヤー

テキストレイヤーは、タイムライン上にタイトルや字幕を描きます。文字の本文・フォント・装飾はレイヤーに設定し、クリップで表示期間を決めます。

## 追加する

1. **Add Layer → Text** を選びます。
2. レイヤーの詳細で **Text** に本文を入力します。
3. **Font** でフォントを選び、サイズと位置を調整します。
4. クリップの開始と長さを、文字を表示したい区間に合わせます。

フォントはAssetsパネルの **Add asset** からフォントファイルを読み込めます。利用可能な環境では、**Import local font** でコンピューター上のフォントも取り込めます。フォントを選択しない場合は、標準のsans-serifフォントを使います。

## 文字の見た目を設定する

| 設定 | 意味 |
| --- | --- |
| **Size (height ratio)** | シーンの高さに対する文字サイズ。0.1なら高さの10%を基準にする |
| **Position** | 文字を置く位置。中央が `[0, 0]`、上方向が正のY |
| **Alignment** | 左・中央・右の整列 |
| **Color** | 文字色と透明度 |
| **Line height (size ratio)** | 文字サイズに対する行間の比率 |
| **Outline width / color** | 文字サイズに対する輪郭幅と、その色 |
| **Drop shadow** | 影の有効・無効。色・ずれ・ぼかしも設定できる |

輪郭幅、影のずれ・ぼかし、行間は文字サイズを基準にします。例えば、文字サイズを大きくすると、同じ比率の輪郭や影も大きくなります。

### 長い文字列のはみ出し

**Max width (width ratio)** は、シーンの幅に対する最大幅です。**Overflow** で、その幅を超えた場合の扱いを選びます。

| 選択肢 | 動作 |
| --- | --- |
| **Do nothing** | 幅を超えてもそのまま表示する |
| **Shrink font size** | 文字サイズを縮めて収める |
| **Compress horizontally** | 横方向に圧縮して収める（初期値） |

文字の形を保ちたい場合はShrink font size、文字の高さを保ちたい場合はCompress horizontallyを使います。

## 本文を切り替える・動かす

同じレイヤー内のクリップは本文や装飾を共有します。クリップを追加するだけでは、別の本文にはなりません。

短い字幕を順番に切り替えるなら、Textの入力方式を **Keyframes** にし、各時刻に文字列を設定できます。文字列は補間せず、次のキーで切り替わります。別々の位置や装飾のタイトルを同時に出すなら、レイヤーを分けてください。

位置・色・サイズや、**Compositing → Opacity** にキーを設定すると、移動やフェードも作れます。キーはシーン上の時刻で動きます。[パラメータ](../../parameters.md)も参照してください。

## 文字の設定とレイヤー合成

Text側のPositionやSizeは文字自体の配置を決めます。Compositing側のPosition・Scale・Rotationは、文字を描いた画像全体にかかります。文字を描いた後にさらに変形する操作として使い分けます。

読み上げ音声と字幕を一緒に作る場合は、[VOICEVOXレイヤー](./voicevox.md)を使えます。

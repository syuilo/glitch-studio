# 動画レイヤー

動画レイヤーは、動画素材の映像と、必要に応じてその音声をタイムラインで再生します。再生位置はシーンの時刻とクリップの配置から決まります。

## 追加する

1. Assetsパネルの **Add asset** から動画を読み込みます。
2. 配置したい位置へシークし、**Add Layer → Video** を選びます。
3. 動画素材を選びます。
4. クリップの長さや位置を調整します。

最初の長さは標準5秒で、動画がそれより短ければ素材の長さまでになります。動画全体を使う場合は、右端を素材の終わりまで延ばします。

動画内の音声を利用できない場合、追加時に理由が表示され、映像だけで追加できる場合があります。

## 素材の一部を使う

クリップの左端を右へトリムすると、その分だけ動画の先頭を読み飛ばします。例えば、0秒に置いたクリップの左端を2秒まで縮めると、クリップはシーンの2秒から始まり、動画の2秒から再生します。その後、クリップ本体を5秒へ移動すれば、シーンの5秒から動画の2秒を再生できます。

クリップの **Content offset** は、動画のどこから再生するかを示します。右端を縮めても、この開始位置は変わりません。延長できる範囲は素材長と、同じレイヤーの隣のクリップで制限されます。

現在、時間伸縮による速度変更や、スリップ編集には対応していません。[シーン上の時刻と内容時刻](../../timeline.md#time)も参照してください。

## 映像と音声を設定する

映像のサイズ・位置・不透明度は、レイヤーの **Compositing** で設定します。

音声の有効・無効は、クリップを選んで **Audio enabled** で切り替えます。同じレイヤーにある動画クリップごとに、元音声を使うかどうか決められます。音声のない素材では有効にできません。

音量はレイヤーの **Audio → Volume** で設定し、同じレイヤー内で共有します。映像のOpacityを0にしても音声は消えないため、音もフェードさせたい場合はVolumeにもキーを設定してください。

## 動画を差し替える

クリップの **Change source** から、別の動画素材を選べます。配置の開始時刻は維持し、内容オフセットは0に戻ります。長さは新しい動画の素材長と、次のクリップまでの空きに合わせて設定されます。

動画を同時に複数表示するならレイヤーを分けます。同じレイヤーで連続して別の動画へ切り替えるなら、クリップを接して配置します。

## 加工や音声解析に使う

上に[エフェクトレイヤー](./effect.md)を置けば、動画を含む下層映像を加工できます。音声は波形やスペクトラムなどの[音声入力](../../parameters.md#audio-input)にも使えます。

タイムラインの動画クリップはPlayerの再生ボタンや再生位置には連動しません。LIVEのPlayer入力と区別して扱ってください。

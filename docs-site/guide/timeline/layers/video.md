# 動画レイヤー

動画レイヤーは、動画素材の映像と、必要に応じてその音声をタイムラインで再生します。再生位置はシーンの時刻とクリップの配置から決まります。

## 追加する

1. Assetsパネルの **Add asset** から動画を読み込みます。
2. 配置したい位置へシークし、**Add Layer → Video** を選びます。
3. 動画素材を選びます。
4. クリップの長さや位置を調整します。

最初の長さは標準5秒で、動画がそれより短ければ素材の長さまでになります。動画全体を使う場合は、右端を素材の終わりまで延ばします。

動画内の音声を利用できない場合、追加時に理由が表示され、映像だけで追加できる場合があります。

## 素材の一部を使う

等速のクリップの左端を右へトリムすると、その分だけ動画の先頭を読み飛ばします。例えば、0秒に置いたクリップの左端を2秒まで縮めると、クリップはシーンの2秒から始まり、動画の2秒から再生します。その後、クリップ本体を5秒へ移動すれば、シーンの5秒から動画の2秒を再生できます。

クリップの **Source range** は、使用する素材の開始位置と終了位置です。延長できる範囲は素材長と、同じレイヤーの隣のクリップで制限されます。逆再生中は、左トリムで素材の末尾側を、右トリムで素材の先頭側を削ります。

## 速度を変更する・逆再生する

1. 動画クリップを選び、Inspectorの **Speed** に倍率を百分率で入力します。100%が等速、50%が半分の速度、200%が2倍速です。指定範囲は1〜1600%です。
2. 逆再生する場合は **Reverse playback** をオンにします。
3. 変更後の長さを確認し、**Apply speed** を押します。

素材範囲と配置の開始位置を維持し、クリップの右端が伸縮します。例えば素材の2〜8秒を使うクリップは、50%で12秒、200%で3秒になります。逆再生は選択中の素材範囲の末尾から始まります。0%は指定できません。隣のクリップと重なる場合は適用できないため、先に配置を調整してください。変更はUndo/Redoできます。

ループ中は1周と全体の長さが同じ倍率で変わります。配置長はミリ秒単位に丸めますが、素材範囲は保持します。不透明度・変形・音量のキーはシーン上の時刻に残ります。短くしたクリップの外に残ったキーは、必要に応じて別途調整してください。

有効な音声も同じ速度と方向で再生します。スローでは音程が下がり、早送りでは上がります。音程を維持する機能はありません。スロー時は元のフレームを保持して表示し、新しい中間フレームは生成しません。速度を途中で変えるキー・式やフリーズには未対応です。[シーン上の時刻と内容時刻](../../timeline.md#time)も参照してください。

## トリムした範囲を繰り返す

1. 左端と右上のハンドルで、繰り返したい素材範囲をトリムします。
2. 右下の繰り返しアイコンがあるハンドルを右へ引き、クリップ全体を延長します。
3. 延長部分では、トリムした範囲の映像と有効な音声が繰り返されます。

例えば、素材の2〜5秒を選んで全体を8秒にすると、3秒の範囲を2回再生し、最後は素材の2〜4秒を再生します。整数回で終わらせる必要はありません。スナップが有効でクリップ終端の吸着が有効なら、1周ごとの境界にも吸着します。同じレイヤーの次のクリップを越えて延長することはできません。

繰り返し部分には模様と周期の区切り線が表示されます。右上のトリムハンドルは1周目の終端に残り、右下のハンドルがクリップ全体の終端になります。ズームアウトして周期が細かくなった場合は、読めない区切り線やローカル目盛りを省略します。

Inspectorでは **Trimmed duration** が1周分の長さ、**Total duration** が繰り返しを含む全体長です。Total durationを伸ばしてもループを設定できます。右下のハンドルを1周分まで戻すか、**Remove loop** を押すと、全体長を1周分に縮めてループを解除します。

ループ中に右上をトリムすると、すべての周の素材範囲が変わり、クリップ全体の終端は維持されます。左トリムは配置の開始を動かし、倍率・方向に応じて素材の再生開始側を削り、全体終端を維持します。最初の1周を消すところまではトリムできません。

ループ設定はクリップごとに保持し、コピーにも引き継がれます。不透明度・音量・キーフレームはシーン上の時刻で進むため、繰り返しながら全体をフェードさせられます。再生・途中シーク・書き出しで同じ範囲を使います。

映像と音声は末尾から先頭へそのまま接続します。自動クロスフェードは行わないため、素材によっては音の継ぎ目が聞こえます。モーションブラーはループ境界をまたいで末尾と先頭を混ぜません。

## 映像と音声を設定する

映像のサイズ・位置・不透明度は、レイヤーの **Compositing** で設定します。

音声の有効・無効は、クリップを選んで **Audio enabled** で切り替えます。同じレイヤーにある動画クリップごとに、元音声を使うかどうか決められます。音声のない素材では有効にできません。

音量はレイヤーの **Audio → Volume** で設定し、同じレイヤー内で共有します。映像のOpacityを0にしても音声は消えないため、音もフェードさせたい場合はVolumeにもキーを設定してください。

## 動画を差し替える

クリップの **Change source** から、別の動画素材を選べます。配置の開始時刻は維持し、素材範囲は先頭からに戻り、速度は100%の順再生、ループは解除されます。長さは新しい動画の素材長と、次のクリップまでの空きに合わせて設定されます。

動画を同時に複数表示するならレイヤーを分けます。同じレイヤーで連続して別の動画へ切り替えるなら、クリップを接して配置します。

## 加工や音声解析に使う

上に[エフェクトレイヤー](./effect.md)を置けば、動画を含む下層映像を加工できます。音声は波形やスペクトラムなどの[音声入力](../../parameters.md#audio-input)にも使えます。

タイムラインの動画クリップはPlayerの再生ボタンや再生位置には連動しません。LIVEのPlayer入力と区別して扱ってください。

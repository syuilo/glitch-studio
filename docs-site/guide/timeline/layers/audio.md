# 音声レイヤー

音声レイヤーは、音声素材をタイムラインで再生します。BGM・効果音・録音したナレーションなどに使います。画像は出力せず、ほかの映像レイヤーを隠しません。

## 追加する

1. Assetsパネルの **Add asset** から音声ファイルを読み込みます。
2. 再生を始めたい位置へシークし、**Add Layer → Audio** を選びます。
3. 音声素材を選択します。
4. クリップの長さを、使用したい範囲に調整します。

最初の長さは標準5秒で、素材が短ければその長さまでになります。長いBGMを使うときは、右端を延ばしてください。

## 再生範囲を決める

クリップ本体の移動は、シーン上での再生開始位置を変えます。左トリムは素材の先頭から使わない部分を取り除き、右トリムは再生を終える位置を変えます。素材長や、隣のクリップを越える延長はできません。

**Change source** では別の音声素材に変更できます。シーン上の開始位置を保ち、内容オフセットは0へ戻り、長さは新素材と次のクリップまでの空きに合わせて設定されます。

同じレイヤーのクリップ同士は重ねられません。効果音をBGMに重ねたり、2曲をクロスフェードしたりする場合は、別のレイヤーを使います。

## 音量とフェード

レイヤーの **Audio → Volume** で音量を調整します。1が素材の元の音量、0が無音で、同じレイヤー内の全クリップに適用されます。

Volumeの入力方式を[Keyframes](../../parameters.md#keyframes)にすると、フェードイン・フェードアウトを作れます。例えば、0〜10秒のBGMなら次のキーを設定できます。

| シーン上の時刻 | Volume |
| --- | --- |
| 0ms | 0 |
| 1000ms | 1 |
| 9000ms | 1 |
| 10000ms | 0 |

キー間をLinearにすると、最初と最後の1秒で音量が変化します。クリップを移動してもキーは追従しないので、必要に応じてキーも移動してください。

複数の音声は加算してミックスされます。自動で音量をそろえる処理はないため、重ねた結果が大きすぎる場合は各レイヤーのVolumeを下げて調整します。

## 波形やスペクトラムに使う

音声を可視化するエフェクトやVisual Moduleでは、このレイヤーを[音声入力](../../parameters.md#audio-input)として選べます。**Audio from layer** なら特定のBGMだけ、**Audio from layers below** なら下層の複数音声をまとめて解析できます。

音声レイヤー自体が波形画像を出すわけではありません。画像を描くエフェクトは別のレイヤーに置きます。タイムラインの音声再生はクリップの配置に従い、LIVE用Playerの再生位置とは独立しています。

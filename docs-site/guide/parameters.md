# パラメータ

パラメータは、エフェクトの強さ、色、レイヤーの位置・不透明度・音量などを決める設定です。
静的に値を設定するだけでなく、式やキーフレームで動的に変化させたり、Visual Module内部では別のノードの出力を入力したりできます。

## 制御方式

パラメータ名のラベルをクリックして、どのようにそのパラメータを制御するか設定できます。

使用する箇所によって、利用可能な制御方式は異なります。

| 方式 | 使用可能箇所 | 説明 |
| --- | --- | --- |
| **Literal** | すべて | スライダー・数値欄・色選択などで固定値を設定する |
| **Environment Variable** | すべて | 現在時刻など、変数を参照する |
| **Expression** | すべて | 式を評価する |
| **Automation Graph (Inline)** | すべて | カーブを使う |
| **Automation Graph (Reference)** | すべて | カーブを参照する |
| **Node** | Visual Module | 別ノードの出力を受け取る |
| **Custom Parameter** | Visual Module | カスタムパラメータを受け取る |
| **Keyframes** | タイムライン | 時刻ごとに値を設定する |
| **Layers below** | タイムライン | 下層の合成画像を受け取る |
| **Audio from layers below / Audio from layer** | タイムライン | 下層全体または指定レイヤーの音声を使う |

## 式

入力方式をExpressionにすると、表示される欄に式を入力できます。

式は[AiScript](https://aiscript-dev.github.io/)として解釈されます。

Visual Module内部では、カスタムパラメータを `PARAM("amount")` のように参照できます。引数には対象のカスタムパラメータのReference Nameを指定します。

Uniformなカスタムパラメータ(ノード入力不能なカスタムパラメータ)のみ参照できます。

## キーフレーム {#keyframes}

キーは「この時刻ではこの値」という指定です。

タイムラインのレイヤーで、動かしたいパラメータの入力方式を **Keyframes** にすると、そのパラメータ用のキーフレームレーンがレイヤーに追加されます。

レーン上をダブルクリックするとキーを追加できます。

キーを選択すると詳細パネルで値の設定などが行えます。

数値・ベクトル・色などの連続的な型のパラメータであれば、キー間の補間方法を設定することもできます。

## テクスチャのサンプリング設定

Visual ModuleのNode入力や、エフェクトレイヤーのLayers below入力では、**Sampling** からテクスチャの読み取り方法を設定できます。

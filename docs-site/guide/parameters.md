# パラメータ

パラメータは、エフェクトの色・強さ・位置などを決める設定です。同じノードでも、パラメータの値や入力方法によって結果が変わります。

## 値を直接編集する

**Literal** は、値を直接指定する方法です。数値はスライダーや入力欄、色は色のコントロールなど、そのパラメータに合った方法で編集します。

例えば、FillノードのColorを変更すると、出力する単色が変わります。初めて使うエフェクトでは、一つずつ値を変えながらプレビューを確認すると、各設定の役割を把握できます。

## 入力方法を選ぶ

パラメータのメニューから、利用できる入力方法を選びます。選べる方法は、パラメータの型や編集している場所によって異なります。

| 方法 | 主な用途 |
| --- | --- |
| Literal | 固定の数値・色・選択肢などを指定する |
| Environment Variable | 利用可能な時刻などの変数を、そのまま値として使う |
| Expression | 式で値を計算する |
| Node | Visual Module内の別のノードの出力を受け取る |
| Keyframes | 時刻ごとに値を設定して、変化をつくる |
| Automation Graph | グラフで値の変化を設定する |

音声の取得元を指定するパラメータには、式やキーフレームは使いません。LIVEではPlayer、タイムラインでは下のレイヤーの音声や指定したレイヤーの音声を選びます。

## 式で値を計算する

式はAiScriptとして評価されます。例えば、数値パラメータで **Expression** を選び、次のように入力すると、値は `0.5` になります。

```text
1 / 2
```

時刻を使う場合は、`TIME` が秒、`TIME_MS` がミリ秒です。

```text
TIME_MS / 1000
```

この式の値は、評価時刻が0秒なら0、1秒なら1になります。受け取るパラメータの範囲に合うよう、必要に応じて計算を調整します。

### 時刻の基準

タイムラインのレイヤー設定・音量・Visual Moduleへの引数では、`TIME` は所属するSceneの時刻です。

Visual Module内部のノードでは、クリップの内容時刻を使います。例えばSceneの3秒から始まるクリップで、内容のオフセットが0秒なら、Sceneの4秒時点でVisual Module内部の `TIME` は1です。

レイヤー側の式には、`PROGRESS` や `END_TIME` は公開されません。式を別の場所へコピーするときは、利用できる変数と時刻の基準を確認してください。

## キーフレーム

対応するパラメータでは、時刻ごとに値を置き、その間を補間できます。例えば、レイヤーの不透明度をSceneの0秒で0、1秒で1に設定すると、フェードインを作成できます。

タイムラインのキーは、クリップ内の相対位置ではなくSceneの時刻を基準にします。同じレイヤーに複数のクリップがある場合も、一つの時間軸上で値が変化します。

## 設定を戻す

パラメータの **Reset** は、その設定を既定の状態へ戻します。直前の編集を取り消したいときは、アプリ上部のUndoボタンを使います。

既定の入力方法は、使う場所によって異なる場合があります。例えば、タイムラインで下の映像を加工するエフェクトの主入力は、リセットすると下のレイヤーからの入力に戻ります。

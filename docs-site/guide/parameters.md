# パラメータ

パラメータは、エフェクトの強さ、色、レイヤーの位置・不透明度・音量などを決める設定です。固定値を手で調整するだけでなく、式やキーフレームで時間に応じて変化させたり、別のノードの出力を入力にしたりできます。

## 値の型と入力方式

「どのような値を扱うか」が**型**、「どこからその値を得るか」が**入力方式**です。例えば、Opacityは数値型で、固定値・式・キーなどから値を決められます。選べる方式は、型と編集する場所によって異なります。

| 主な型 | 値の例・用途 |
| --- | --- |
| 数値（Scalar / Number） | 強さ、倍率、角度、時間などの一つの数値 |
| 真偽値（Bool / Flag） | 有効・無効などの切り替え |
| 文字列（String） | テキストの本文 |
| 色（Color） | 赤・緑・青・アルファの4成分。アルファ0は透明、1は不透明 |
| ベクトル（Vector） | 位置やサイズなどの2成分 |
| 選択肢（Enumなど） | あらかじめ定義された候補からの選択 |
| 素材・Playerの参照 | 画像やフォント、LIVEで使うメディアの指定 |
| 音声（Audio） | 波形やスペクトラムなどが解析する音声の取得元 |
| 配列・構造体 | 同じ型の要素の並びや、複数の名前付き項目のまとまり |

単位や範囲は設定ごとに異なります。例えば、レイヤーのPositionは画面中央を0、画面端を±1とする座標ですが、シェイプのSizeはシーンの高さに対する比率です。各項目の表示やレイヤーの記事を確認してください。

## 入力方式を変える

パラメータのラベルをクリックすると、**Input source** のメニューが開きます。パラメータ行の右クリックからも開けます。

| メニュー | 用途 |
| --- | --- |
| **Literal** | スライダー・数値欄・色選択などで固定値を設定する |
| **Environment Variable** | 現在時刻など、使用可能な変数をそのまま使う |
| **Expression** | 式で値を計算する |
| **Keyframes** | タイムライン上の時刻ごとに値を設定する |
| **Automation Graph (Inline)** | そのパラメータ専用のカーブを使う |
| **Automation Graph (Reference)** | その編集範囲で利用できる登録済みカーブを参照する |
| **Node** | Visual Module内の別ノードの出力を受け取る |
| **Custom Parameter** | Visual Moduleの公開カスタムパラメータを受け取る |
| **Layers below** | エフェクトレイヤーで、下層の合成画像を受け取る |
| **Audio from layers below / Audio from layer** | タイムラインで、下層全体または指定レイヤーの音声を使う |

すべての項目が常に表示されるわけではありません。例えばNodeは接続可能なノード入力だけ、Keyframesは対応する型と編集箇所だけで使えます。

**Reset** は入力方式も含めて初期設定へ戻します。加工系エフェクトレイヤーの主画像入力は下層画像へ、主音声入力は下層音声へ戻ります。

## 式で動かす

入力方式をExpressionにすると、表示される欄に式を入力できます。例えば、数値パラメータに次の式を設定すると、時間に応じて値が増えます。

```text
TIME * 0.1
```

`TIME` は秒、`TIME_MS` はミリ秒です。上の例では、評価に使う時刻が3秒のとき、値は0.3になります。どの時刻を指すかは、式を置いた場所によって変わります。

Visual Module内部では、公開カスタムパラメータを `PARAM("amount")` のように参照できます。Reference Nameが `amount` で、ノード入力を許可していないパラメータが対象です。画像の配線や音声入力を`PARAM`で読むことはできません。

## キーフレームでアニメーションを作る {#keyframes}

キーは「この時刻ではこの値」という指定です。数値・ベクトル・色はキー間を補間でき、文字列・真偽値・選択肢はキーの位置で切り替えます。

1. タイムラインのレイヤーで、動かしたいパラメータの入力方式を **Keyframes** にします。
2. 表示されたキーのレーンでキーを選択します。空白のダブルクリックでキーを追加できます。
3. 詳細パネルの **Time** と **Value** を設定します。
4. 数値・ベクトル・色では、キー間の補間を設定します。一定値を保つHold、直線的に変えるLinear、加速・減速を付けるイージングを使えます。

### 例：1秒でフェードインする

0〜5秒に表示する画像クリップを用意し、レイヤーの **Compositing → Opacity** をKeyframesにします。次の2つのキーを作り、その間をLinearにします。

| シーン上の時刻 | Opacity |
| --- | --- |
| 0ms | 0 |
| 1000ms | 1 |

これで最初の1秒をかけて画像が現れます。2秒から始まるクリップで同じフェードを作るなら、キーを2000msと3000msに置きます。キーはレイヤーに属するため、クリップの開始に自動ではそろいません。

キーはドラッグやTimeの入力で移動でき、複数選択・削除・コピーと貼り付けもできます。貼り付け先はコピー元と同じシーン・レイヤー・パラメータで、先頭のキーを現在のシーク位置へ合わせます。同じパラメータの同時刻に既存キーがある場合は、全体を貼り付けません。

キーのドラッグやTimeの入力では、同じパラメータの動かさないキーとの間に100msを残し、追い越しを防ぎます。開始時から100ms未満なら、その間隔を下限にします。複数キーを一緒に移動するときは、選択したキー同士の間隔を維持します。VOICEVOXの発話キーも同じ制限を使います。

タイムラインのキーはシーン上の絶対時刻を使い、繰り返しやクリップ終端を基準にした評価は行いません。クリップを移動すると区間内のキーも追従します。終端キーの扱いは[クリップの編集](./timeline.md#クリップを編集する)を参照してください。クリップの長さ変更ではキーの時刻は変わりません。

## オートメーションでカーブを使う

**Automation Graph (Inline)** では、**Edit graph** から専用のカーブを編集します。Referenceでは登録済みのカーブを選択します。

カーブの時間軸にはミリ秒と正規化された時間があり、正規化されたカーブは **Duration (ms)** で再生時間を指定します。**Wrap mode** では範囲外の扱いを設定でき、端の値を保つ・繰り返す・往復する動きを作れます。

例えば、強さが0から1へ変わる正規化カーブでDurationを1000ms、Wrap modeを往復にすると、1秒で0から1へ進み、次の1秒で0へ戻ります。特定のシーン時刻へ値を置くときはキーフレーム、カーブの再利用や繰り返しにはオートメーションが便利です。

## 時間と参照範囲 {#time-and-scope}

| 編集する場所 | `TIME` / `TIME_MS` が指す時刻 | 補足 |
| --- | --- | --- |
| レイヤーの合成・音量・本文・図形・エフェクトのパラメータ | 所属シーンの時刻 | クリップを動かしても時間の基準は変わらない |
| レイヤーからVisual Moduleへ渡す公開パラメータ | 所属シーンの時刻 | 内部ノードの式とは別の範囲で評価する |
| タイムラインで動くVisual Moduleの内部 | クリップの内容時刻 | 内容オフセット＋シーン時刻−クリップ開始時刻 |

Visual Module内部では `PROGRESS` はクリップ開始で0、終了に向かって1となる進行度です。`END_TIME_MS` は内容オフセット＋クリップの長さ、`END_TIME` はその秒単位の値です。これらはレイヤー側の式には公開されません。

例えば、開始5秒・長さ4秒・内容オフセット2秒のVisual Moduleクリップを、シーンの6秒で見ると、レイヤー側の`TIME`は6、内部の`TIME`は3、内部の`PROGRESS`は0.25です。

Visual Module内部の `WIDTH` / `HEIGHT` は描画先の解像度です。各ノードが出力する画像のサイズではありません。LIVEではプロジェクト、タイムラインでは所属シーンのサイズを基準に、プレビュー・書き出しの倍率を反映します。

変数やカスタムパラメータ、参照できるオートメーションは、その編集範囲ごとに決まります。親シーンやVisual Module内部の名前が、別の範囲でも自動で使えるわけではありません。

## 画像・データを接続する

Visual ModuleのNode入力や、エフェクトレイヤーのLayers below入力では、**Sampling** から画像の読み取り方法を設定できます。

| 設定 | 役割 |
| --- | --- |
| Fit | 入力と出力の縦横比の合わせ方 |
| Wrap | 画像の外側を参照したときの繰り返し方など |
| Filter | 画素を滑らかに補間するか、近い画素をそのまま使うか |

通常の接続の初期値は `cover`・反転しながら繰り返す `repeatMirrored`・線形補間の `linear` です。接続のcontainでできる余白もWrapの設定に従うため、自動的に透明になるとは限りません。これは[レイヤー合成のFit](./timeline.md#compositing)とは別の設定です。

具体的な[ドラッグ配線の操作](./visual-module.md#wiring)と、[Fit・Wrap・Filterの全選択肢と組み合わせ例](./visual-module.md#input-sampling)は、Visual Moduleの記事で説明しています。

## 音声入力を選ぶ {#audio-input}

音声入力は、波形やスペクトラムなどが「どの音を解析するか」を指定します。音声を再生するレイヤーのVolumeとは役割が異なります。

タイムラインでは、**Audio from layers below** で同じ親グループ（グループ外では同じシーン直下）の下層音声をまとめて使えます。音声付き動画・音声・VOICEVOX・グループ・子シーンの音声を含み、それぞれの音量設定も反映します。**Audio from layer** では、上下の順序に関係なく、同じシーン内の指定レイヤー一つの音声を使います。別のグループ内のレイヤーも選べます。参照先自身とその子孫の音量を反映し、参照先の親グループの音量は反映しません。ただし、参照先自身または祖先グループが無効なら入力なしになります。子シーン内部のレイヤーは直接選べません。

LIVEではPlayerを選択します。音声入力は固定の取得元の指定であり、式・キーフレーム・オートメーション・画像ノードの配線では切り替えません。公開音声パラメータを内部へ渡すときはCustom Parameterを使います。

## 配列と構造体

配列は要素を追加・複製・削除・並び替えできる設定です。構造体は複数の名前付き項目をまとめます。内部の各項目で、対応する入力方式を選べます。例えば、配列の要素ごとに違う画像を接続する構成も作れます。

配列・構造体全体へ式やノード接続を割り当てることはできません。子の項目を編集してください。配列の要素を削除すると、その要素に属するキーも削除され、Undoで一緒に戻ります。

Visual Moduleの公開カスタムパラメータについては、配列・構造体・Any型の定義や値を編集するUIは現在未対応です。

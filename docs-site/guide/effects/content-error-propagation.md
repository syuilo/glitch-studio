# Content error propagation

Content error propagationは、画像の輪郭や色の変化に沿って、色や明るさの誤差を広げるエフェクトです。輪郭をなぞる変色や、物体の境界で止まる色の筋を作れます。[Visual Module](../visual-module.md)のエフェクトノード、または[エフェクトレイヤー](../timeline/layers/effect.md)として追加します。

元画像の細部と透明度は保持します。色の誤差だけを計算して加えるため、画像全体を低解像度へ縮小して出力する処理にはなりません。

## 最初の調整

1. **Propagation path** を **Along contours** にします。
2. **Source probability** で破損の発生密度、**Error strength** で変色の強さを調整します。
3. **Propagation length (% of short side)** を増やして誤差が進む距離を長くします。
4. 物体の境界を越えて広がる場合は、**Boundary threshold** を下げます。
5. 模様を変えたい場合は **Seed** を変更します。

誤差は発生源から両方向へ広がり、すでに到達した場所にも残ります。伝播距離や発生源の間隔などは画面短辺に対する割合で指定するので、出力解像度だけを上げても画面全体に対する大きさは変わりません。

## 発生源と色

| 設定 | 動作 |
| --- | --- |
| **Error strength** | 誤差を元画像へ加える強さ。0なら入力をそのまま返す |
| **Source probability** | 各領域に誤差の発生源を置く確率。0なら発生しない |
| **Source spacing (% of short side)** | 発生源を配置する領域の間隔。小さくすると密になる |
| **Source size / spacing** | 発生する円の直径を間隔に対する比率で指定。小さくすると細い筋になりやすい |
| **Error mode** | RGB、Luminance、Chromaから誤差の種類を選ぶ |

**RGB** は各色チャンネルに別々の誤差、**Luminance** は主に明るさの誤差、**Chroma** は主に色の誤差を加えます。完全に透明な場所からは誤差を発生させません。

## 伝播する方向

| Propagation path | 動作 |
| --- | --- |
| **Along contours** | 輪郭に沿って進む |
| **Across contours** | 色や明るさの変化が大きい方向へ進む |
| **Fixed direction** | Fallback directionで指定した軸の両方向へ進む |

**Content following** は画像の内容に追従する割合です。1で強く追従し、0では固定方向になります。輪郭がはっきりしない平坦な場所では、追従する設定でも **Fallback direction** を使います。

**Guidance radius (% of short side)** は方向を調べる範囲です。小さくすると細かい模様の方向へ追従し、大きくすると広い範囲の構造を使います。方向の判定にはRGBと透明度を使うため、明るさが同じ色同士の境界や、透明な図形の輪郭も対象になります。

## 距離・減衰・境界

**Propagation length (% of short side)** は進む距離の目安です。20なら短辺の20%を各方向へ進みます。画像端や境界、途中の減衰によって、実際に見える筋は短くなることがあります。0では発生源だけが残ります。

**Retention at full length** は、その距離を進んだときの強さの保持率です。1なら距離による減衰がなく、値を下げるほど先端が弱くなります。0では伝播せず、発生源だけが残ります。

**Boundary blocking** は色や透明度の境界で伝播を抑える強さです。1で強く抑え、0では境界による抑制を行いません。**Boundary threshold** を下げると弱い変化も境界として扱い、上げると境界を越えやすくなります。境界の判定はどのPropagation pathでも有効です。

## 精度と再現性

**Propagation steps** は距離を何段階に分けて計算するかを指定します。多くすると曲線や細い境界を追いやすくなり、計算量も増えます。長い距離を指定したときは、ステップ数も増やすと経路の飛び越しを抑えられます。

**Analysis resolution (short side)** は方向と誤差を計算する画像の短辺のサンプル数です。高くすると細い模様や小さな発生源を扱いやすくなり、GPUメモリ使用量と計算量が増えます。低くしても元画像自体の細部は維持しますが、誤差の形と境界の判定は粗くなります。発生サイズが小さすぎて模様が出ない場合は、発生サイズか解析解像度を上げます。

同じ入力と設定なら、再生・シーク・書き出しで同じ結果になります。前フレームの描画には依存しません。時間によって誤差を変えたい場合は、Seedなどに式・キー・オートメーションを設定します。

# Adaptive block glitch

Adaptive block glitchは、入力画像の色や透明度の変化に合わせて、大きさの異なるブロックを作るエフェクトです。平坦な領域では大きなブロック、細かい模様や輪郭のある領域では小さなブロックになり、ブロックごとに位置や色を破損させられます。

[Visual Module](../visual-module.md)のエフェクトノード、または[エフェクトレイヤー](../timeline/layers/effect.md)として追加できます。

## ブロックの分け方

| 設定 | 動作 |
| --- | --- |
| **Maximum block size (% of short side)** | 最大ブロックの一辺。画面短辺に対する百分率で指定する |
| **Subdivision levels** | 最大何回細分化するか。1回ごとに縦横を半分にする。0なら全て同じ大きさ |
| **Detail threshold** | 色・透明度の変化をどれだけ許容するか。小さくすると細かく分割されやすくなる |
| **Analysis samples per axis** | 最小セル内を解析するサンプル数。増やすと細い模様を検出しやすくなる |

例えば最大サイズ25%、分割階層5なら、最小ブロックの一辺は短辺の約0.78%です。最大サイズから始め、各領域の変化が閾値を超える場合だけ4分割します。平坦な領域は途中で分割が止まるため、大小のブロックが混在します。

同じ縦横比で出力解像度だけを上げても、ブロックの視覚的な大きさは変わりません。描画には元の入力を直接使うため、ブロック分割のために画像全体がぼけることもありません。

最大サイズを小さくしたり分割階層を増やしたりすると、解析するセルが増えます。GPUの上限に達した場合は、最大サイズを大きくするか分割階層を減らしてください。サンプル数を増やすと解析の計算量が増えます。

## 破損を調整する

**Corruption probability** は各ブロックを破損させる確率、**Strength** は元画像に対する破損結果の混合率です。選ばれなかったブロックは元の画像を表示します。

| 設定 | 動作 |
| --- | --- |
| **Displacement (block widths)** | ブロック全体をランダムな方向へずらす。1なら各軸で、その場所のブロック1個分まで |
| **Snap displacement to blocks** | ずれを、そのブロックの一辺の整数倍に揃える |
| **Color error** | ブロック内のRGBに一定の誤差を加えて変色させる |
| **Channel displacement (block widths)** | 赤と青の参照位置を別々にずらす |
| **Flatten blocks** | ブロックを中央の代表色で塗り、破損したモザイクのようにする |

各強度を0にすれば、その加工を止められます。例えば位置ずれを0にして変色だけを作ったり、色の誤差とチャンネルずれを0にして画像の断片だけを移動したりできます。

位置ずれの単位は、その場所のブロックの一辺です。同じ値でも、大きなブロックは大きく、小さなブロックは細かく移動します。Snapを有効にした場合、丸めによって小さな変位は0になることがあります。

Flatten blocksは初期状態では無効です。無効のままなら、破損したブロック内にも元画像の輪郭や細かい模様が残ります。範囲外へずれた部分の読み取り方は、入力のSampling設定に従います。

## 分割の輪郭を表示する

**Block outline width** を上げると、各ブロックの境界へ黒い輪郭線を表示します。幅は各ブロックの一辺に対する割合です。

破損していないブロックにも輪郭線が表示されるため、Corruption probabilityを0にして分割だけを見ることもできます。輪郭線を残したまま破損を重ねる表現にも使えます。

## Seedと透明度

**Seed** は、破損するブロックや位置・色のずれを変更します。ブロックの分け方は入力画像と解析設定で決まり、Seedを変えても分割自体は変わりません。

同じ入力と設定なら、再生・シーク・書き出しで同じ結果になります。時間によって破損を変えたい場合は、Seedなどに式やオートメーションを設定します。入力画像が変化すると、それに応じてブロックの分け方も変化します。

**Preserve alpha** は初期状態で有効です。元画像の透明部分の形を保ちながら、色の内容だけをずらします。無効にすると、ずれた参照位置の透明度も使うため、透明部分の形も移動します。

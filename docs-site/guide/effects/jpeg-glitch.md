# JPEG glitch

JPEG glitchは、JPEG画像が破損したような変色・縞・ブロックのずれを作るエフェクトです。[Visual Module](../visual-module.md)のエフェクトノード、または[エフェクトレイヤー](../timeline/layers/effect.md)として追加できます。量子化、DC・ACの破損、DC誤差の伝播、配置ずれ、再同期をそれぞれ切り替えられます。

## ブロックの大きさと圧縮

**Block size (% of short side)** は、輝度ブロックの一辺を画面短辺の百分率で指定します。2なら短辺の2%です。同じ縦横比で出力解像度だけを変えても、画面全体に対するブロックの大きさは変わりません。

**Quantization** を有効にするとJPEGの圧縮による細部の消失やブロック模様を作ります。**JPEG quality** を下げるほど圧縮が強くなります。100でもわずかな丸めが残るため、量子化を省きたい場合はQuantizationを無効にします。

**Chroma subsampling** を4:2:0にすると、明るさよりも色の情報を粗くします。色がにじみやすくなり、色差ブロックの一辺は輝度ブロックの2倍になります。4:4:4では色差を間引きません。

Block sizeを小さくするほど計算量とメモリ使用量が増えます。GPUの上限に達した場合は、Block sizeを大きくしてください。

## 色と明るさの破損：DC

**DC corruption** は、ブロックの平均的な明るさや色を変えます。

| 設定 | 動作 |
| --- | --- |
| **DC corruption probability** | 各成分のブロックが破損する確率。0なら発生しない |
| **DC luminance error** | 明るさの誤差の大きさ |
| **DC chroma error** | 色差の誤差の大きさ |
| **DC error propagation** | 同じ成分の後続ブロックへ誤差を持続させる |
| **DC error retention** | 次のブロックへ進むごとの保持率。1なら減衰せず、0なら持続しない |

伝播を無効にすると、破損したブロックだけが変色します。有効にすると画像の途中から変色が続くようになります。誤差が複数回発生すると、その誤差が累積します。

## 模様や細部の破損：AC

**AC corruption** は、細部を消したり、ブロック内に縞や格子の模様を作ったりします。

**AC block corruption probability** は破損するブロックの確率、**AC coefficient corruption probability** はそのブロック内で加工する係数の確率です。**AC corruption strength** で加工の強さを調整します。

| AC corruption mode | 動作 |
| --- | --- |
| **Mixed** | 係数ごとに以下の方式を選ぶ |
| **Drop** | 係数を消して細部を失わせる |
| **Invert sign** | 係数の符号を反転する |
| **Amplify** | 係数を増幅し、平坦な部分にも異常な模様を加える |
| **Shift frequency** | AC frequency shiftで指定した数だけ係数の参照位置をずらす |

**AC minimum zigzag index** と **AC maximum zigzag index** は対象とする周波数の範囲です。1〜63で指定し、小さい番号ほどおおむね低周波、大きい番号ほど高周波に対応します。低周波の破損は大きな模様、高周波の破損は細かい模様を作りやすくなります。

## 配置ずれと再同期

**Block displacement** は、画像のブロック列の参照先をずらします。**Block displacement probability** で発生率、**Maximum displacement step (MCUs)** で1回の発生によるずれの上限を指定します。ずれは次のブロックにも続き、新たなずれが発生すると加算されます。

MCUは明るさと色をまとめた単位です。4:4:4では輝度ブロック1個分、4:2:0では縦横2個ずつの輝度ブロックと、その範囲の色差をまとめた単位になります。

**Restart synchronization** を有効にすると、**Restart interval (MCUs)** ごとにDC誤差と配置ずれをリセットします。短い間隔では破損が小さな区間に収まり、長い間隔では広く持続します。無効にすると画像の末尾まで持続します。配置ずれの参照先は同じ区間内で折り返します。

再同期はすでに破損した部分を修復する設定ではありません。また、再同期地点でも新たな破損は発生します。DC誤差の伝播と配置ずれを両方無効にした場合、再同期だけを切り替えても見た目は変わりません。

## Seedと透明度

**Seed** で破損位置や誤差を変更します。同じ入力と設定なら、再生・シーク・書き出しで同じ結果になります。時間によって破損を変えたい場合は、Seedに式やオートメーションを設定します。

元の入力の透明度は保持します。色の配置がずれても透明部分の形は移動しません。

すべての破損を無効にしても、処理用の画像へのリサンプリングや色差の間引きは残ります。入力をそのまま通す場合は、エフェクト自体を無効にしてください。

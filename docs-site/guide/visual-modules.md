# Visual Moduleとノード

Visual Moduleは、複数のノードをつないで画像処理をまとめたものです。LIVEで出力を確認したり、タイムラインのレイヤーとして配置したりできます。

## ノードの役割

ノードは、それぞれ一つの処理を担当します。入力を受け取って加工するものもあれば、素材がなくても色や模様を生成するものもあります。

| ノード | 役割 |
| --- | --- |
| In | Visual Moduleの外部から渡された入力を、内部のノードへ渡す |
| エフェクトのノード | 単色や模様を生成する、画像をぼかす、色を変えるなどの処理を行う |
| Out | どのノードの結果をVisual Moduleの出力にするかを指定する |

例えば、画像をぼかして出力する処理は、次のようにつなぎます。

```text
画像の出力 → Blurの入力 → Out
```

ノードを追加するだけでは、出力には反映されません。どの結果を使うかを接続で指定します。

## 例：単色をチェック柄に変える

[はじめに](./getting-started.md)で作成したプロジェクトを使います。

1. Visual Moduleの **Nodes** タブで **Add Effect Node...** を押します。
2. エフェクト一覧から **Checker** を選びます。
3. **Out** ノードの **Output** の選択欄で、追加したCheckerの出力を選びます。
4. **LIVE** でプレビューを表示し、Checkerのパラメータを調整します。

出力をFillへ戻すと、単色の映像に戻ります。Fillを削除する必要はありません。Outに渡す出力を切り替えて、結果の違いを確認できます。

## 接続で渡すデータ

ノード間で受け渡すのは、画像だけではありません。数値の分布であるスカラー場や、方向と大きさを持つベクトル場を出力するノードもあります。これらは、別のエフェクトの強さや変形を制御する入力として使えます。

接続するときは、出力と入力のデータ型を確認してください。型の異なる接続を許可するかどうかは、アプリの型安全に関する設定によって変わります。

## 外部へ公開する入力と出力

**Input Defs** で公開するパラメータを、**Output Defs** で出力を定義します。

配線できるカスタムパラメータは、Inノードから内部のノードへ接続します。配線しないカスタムパラメータは、ノードのパラメータへの割り当てなどに使用します。

タイムラインでは、Visual Moduleの主画像入力に下のレイヤーまでの合成結果を渡せます。処理した結果がどのように重なるかは、[レイヤーの合成設定](./timeline.md#重ね方を決める)で決まります。

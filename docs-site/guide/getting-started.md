# Glitch Studioとは？

Glitch Studioは、リアルタイムな画像・動画の加工・編集・作成を行えるフリーでオープンソースのソフトウェアです。

2019年から開発が続けられています。

::: warning
現在開発初期段階のため、不安定な他、動作しない機能が多数あります！！ また、プロジェクトファイルの互換性は現段階では一切保証されません！大事なプロジェクトで使用するのはお控えください。
:::

## サブシステム

Glitch Studioは複数の個別の概念・サブシステムから構成されています。

サブシステム間の階層構造を理解しておくと使いこなしやすくなります。

基本となるサブシステムを以下で説明します。

### エフェクト

パラメータに応じて、画像などのテクスチャデータを生成するサブシステムです。

他のテクスチャデータをパラメータとして受け入れて加工した結果を出力するものもあれば、単体で結果を生成するものもあります。

このサブシステム単体で使用することはなく、後述のVisual Moduleやタイムラインで使用します。

### Visual Module

エフェクトをグラフ構造で組み合わせることができるサブシステムです。

「必要に応じて入力を受け取り、出力を生成する」という性質から、Visual Module自体もエフェクトの一種であると捉えることができます。

このサブシステム単体で使用することも、タイムラインで使用することもできます。

[Visual Module](./visual-module.md)

### タイムライン

素材や、下層のレンダリング結果を加工し上層に出力するレイヤーなどをタイムラインに配置し動画の作成を行えるサブシステムです。

[タイムライン](./timeline.md)

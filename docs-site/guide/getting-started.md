# Glitch Studioとは？

Glitch Studioは、リアルタイムな画像・動画の加工・編集・作成を行えるフリーでオープンソースのソフトウェアです。

2019年から開発が続けられています。

::: warning
現在開発初期段階のため、不安定な他、動作しない機能が多数あります！！ また、プロジェクトファイルの互換性は現段階では一切保証されません！大事なプロジェクトで使用するのはお控えください。
:::

## 目的に合わせて読む

| やりたいこと | ガイド |
| --- | --- |
| 素材を並べて動画を作る | [タイムライン](./timeline.md)で、シーン・レイヤー・クリップと合成の基本を学べます |
| エフェクトをつないで画像処理を組む | [Visual Module](./visual-module.md)で、ノード接続と公開入出力を説明しています |
| 値を変えたりアニメーションを作ったりする | [パラメータ](./parameters.md)で、固定値・式・キー・オートメーションを使い分けます |
| 読み上げ音声と字幕を作る | [VOICEVOXレイヤー](./timeline/layers/voicevox.md)で、エンジン接続から発話の配置まで説明しています |

初めてタイムラインを使う場合は、画像を置き、その上にテキストを重ねるところから始められます。[タイムラインの記事](./timeline.md)には、操作手順と各レイヤーのガイドへのリンクがあります。

ガイド中の **Add Layer** や **Compositing** などの表記は、画面上の項目名です。開発中のため、英語表記と日本語表記が混在しています。

# はじめに

Glitch Studioは、画像・動画・音声を使って映像をつくるアプリです。ノードをつないで画像処理を組み立てる「Visual Module」と、素材を時間に沿って配置する「タイムライン」を組み合わせて制作します。

このガイドでは、Web版で新しいプロジェクトを開き、単色の映像を変えるところから始めます。

::: warning 開発中のアプリです
現在は開発初期段階です。未実装の機能や動作が不安定な機能があり、バージョン間のプロジェクトファイルの互換性も保証されません。まずは試作用の素材でお試しください。
:::

## 動作環境

デスクトップPCの最新のChromeを使用してください。画像処理にはWebGPUを使用するため、対応するGPU・ドライバー・ブラウザー環境が必要です。

[Glitch Studioを開く](https://syuilo.github.io/glitch-studio/)

## 新しいプロジェクトを開く

起動時の画面で **New project** を選びます。最初のプロジェクトには、次の内容が用意されています。

- `My Visual Module`：単色を出力する **Fill** ノードと、結果を受け取る **Out** ノード。
- `Main Scene`：そのVisual Moduleを配置した、10秒のクリップ。

すでに画像・動画・音声がある場合は、起動時の **New project from image/video/audio** から素材を選んで始めることもできます。

## 色を変えてみる

1. Visual Moduleの編集パネルで、`My Visual Module` の **Nodes** タブを開きます。
2. **Fill** ノードの **Color** を編集します。最初の色は緑です。
3. 編集パネル上部の **LIVE** を押し、プレビューで色を確認します。

Fillの出力は、最初からOutへ接続されています。色を変えると、その結果がVisual Moduleの出力になります。

::: tip LIVEとタイムライン
LIVEではVisual Moduleそのものの出力を確認します。タイムライン上での配置や重ね合わせを確認するときは、タイムラインの **Preview** に切り替えます。
:::

## 保存して、もう一度開く

上部メニューの **File → Save as...** から、保存先とファイル名を指定します。プロジェクトは `.gsproj` ファイルとして保存されます。保存先を設定したあとの更新には **File → Save** を使います。

次回は起動時の **Open project** から、保存したプロジェクトを選んで開けます。

# Timeline Audio Renderer

Timelineのクリップを指定したサンプル区間のステレオPCMへミックスします。クリップの時刻変換、所属Sceneの時刻での音量・式・キーフレーム評価、各階層の音量の適用を担当します。

素材PCMと素材長の読み出しは呼び出し側が注入します。Glitch Studioのプロジェクト・Asset一覧、デコーダー、DOM・GPU・再生時計は所有しません。プレビュー再生と書き出しは別のインスタンスで同じ処理を使えます。

Sceneの音声計画はtimeline/sharedのgetSceneAudioClipsで作成します。各階層の音量を適用してFloat32のまま加算し、子Scene単位やレイヤー単位のクリッピング・正規化は行いません。

Workerの起動、先読み・ループ再生、出力ファイルのタイムスタンプとエンコーダーへの受け渡しは呼び出し側の責務です。

# Block Glitch

画像内に矩形を散らし、それぞれの内部で画像と色チャンネルをブロックの幅方向へずらします。

- `Block Count` は生成数で、0〜128個です。中心は画面内に一様に分布し、画面端では矩形をクリップします。`Seed` を固定すると、時間や描画順にかかわらず同じ番号のブロックは同じ乱数を使います。
- `Dimension` は長辺全体を1とする基準寸法 `[幅, 高さ]` です。`Aspect Ratio Randomness` は面積を保って幅・高さを逆方向に変えます。最大設定で縦横比は基準の1/4〜4倍です。`Scale Randomness` は縦横比を保って両軸を拡縮します。最大設定で線形倍率は1/2〜2倍です。どちらも倍率の対数上で一様に分布します。
- `Angle` はブロックの中心まわりの時計回りの基準角で、`Angle Spread` の絶対値が最大偏差です。偏差は範囲内で一様に分布し、輪郭・画像シフト・チャンネルシフトに同じ角度を適用します。式と保存値では1周を1とします。
- `Max Image Shift` と `Max Channel Shift` は長辺全体を1とする最大距離です。それぞれの符号付き変位を対称な範囲から独立に抽選します。画像シフト先のGとAlphaを使い、R・Bはそこから互いに逆向きにずらします。半透明の参照先は参照先のAlphaに応じて色を混ぜます。
- 画素の重なりはブロック番号の大きいものが優先され、透明な結果も含めて上書きします。すべてのブロックが元の入力を参照し、入力接続のFit・Wrap・Filterを適用します。

# Block Glitch

画像内に矩形を散らし、それぞれの内部に入力画像の別の箇所を描き、色チャンネルをブロックの幅方向へずらします。

- `Block Count` は生成数で、0〜512個です。中心は画面内に一様に分布し、画面端では矩形をクリップします。`Seed` を固定すると、時間や描画順にかかわらず同じ番号のブロックは同じ乱数を使います。
- `Dimension` は長辺全体を1とする基準寸法 `[幅, 高さ]` です。`Aspect Ratio Randomness` は面積を保って幅・高さを逆方向に変えます。最大設定で縦横比は基準の1/4〜4倍です。`Scale Randomness` は縦横比を保って両軸を拡縮します。最大設定で線形倍率は1/2〜2倍です。どちらも倍率の対数上で一様に分布します。
- `Angle` はブロックの中心まわりの時計回りの基準角で、`Angle Spread` の絶対値が最大偏差です。偏差は範囲内で一様に分布し、ブロックの輪郭と幅方向のシフトの両方に適用します。式と保存値では1周を1とします。
- `Image Source` の既定値は `Shift` です。`Max Image Shift` で指定した範囲から、幅方向への符号付き変位を抽選します。`Random Position` では、矩形の中心に対応する参照先を入力画像全体から抽選し、中心からの相対位置を保って周囲をサンプリングします。`Max Image Shift` は `Shift` で適用されます。
- `Max Image Shift` と `Max Channel Shift` は長辺全体を1とする最大距離です。チャンネルシフトの符号付き変位は、画像の参照先とは独立に抽選します。画像参照先のGとAlphaを使い、R・Bはそこから互いに逆向きにずらします。半透明の参照先は参照先のAlphaに応じて色を混ぜます。
- 画素の重なりはブロック番号の大きいものが優先され、透明な結果も含めて上書きします。すべてのブロックが元の入力を参照し、入力接続のFit・Wrap・Filterを適用します。

# Image Stack

画像・色の配列を、出力領域内の均等な領域へ並べる。Horizontalは左から右、Verticalは上から下へ配列順に配置する。入力の追加・削除・並べ替えは通常の配列パラメータで行う。

- 初期状態は透明な入力2個、Horizontal、Gap / Paddingは0。
- Gapは領域同士の間隔、Paddingは上下左右共通の外周余白。どちらもSize Referenceで指定した出力寸法を1とし、既定はLong Side。負値は0として扱う。
- 外周余白を除いた領域から入力間の間隔を引き、残りを入力数で等分する。余白・間隔が大きすぎる場合は画像領域を0で止め、全面透明にする。
- 入力0個は全面透明。入力1個ではGapを無視し、外周余白を除く全領域へ配置する。
- 未接続・透明な入力も領域を確保する。画像内の透明余白を含めた全体を配置し、不透明部分の自動検出は行わない。
- 各領域の中央に画像を配置し、領域の縦横比を基準に入力接続のFit / Wrap / Filterを適用する。接続時の既定値は既存仕様と同じ。画像全体と透明余白を表示したい場合はContain + Transparentを選ぶ。
- 領域の外側は入力のWrapにかかわらず透明。定数色は自身の領域全体を塗る。背景色は別のエフェクトで合成する。
- 出力寸法は既存の解像度設定に従い、連結した画像の合計寸法へ自動拡大しない。自動解像度は入力のうち最大画素数の寸法を採用する。
- 入出力は乗算済みalphaのlinear sRGB・rgba16float。HDR・負のRGB・半透明を保持し、履歴には依存しない。

配列の各要素を`EffectImageInput`として受け取り、生成した参照関数で描画する。エフェクト固有の入力数上限や、多数入力のための分割描画は追加しない。

# Corner Peel

画像Aの選択した隅を対角方向へ剥がし、丸まった紙の裏面と下の画像Bを見せる。有限の矩形を半円筒へ曲げ、正面から平行投影する。角のドラッグ、透視投影、円錐モデル、物理シミュレーションは持たない。

## パラメータ

- `inputA` / `inputB`: 剥がす紙の表面と下から現れる画像。画像・色を指定でき、未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。式・キー・scalarノード接続に対応する。空間場を接続した場合は出力位置ごとの局所進捗として評価する。紙全体を同じ形で動かす場合は一様な進捗を使う。
- `corner`: `topLeft` / `topRight` / `bottomLeft` / `bottomRight`。選択した隅から反対の隅へ剥がす。
- `curlRadius`: 曲面の半径。小さいほど鋭く、大きいほど緩やかに曲がる。Size Referenceに対する距離比率。0以下は鋭い折り返しの極限として、共通単位の微小半径0.000001へ制限する。
- `backMode`: `source` / `color` / `input`。裏面の作り方。下記参照。
- `backColor`: 裏面の色または表面流用時の紙色。色・画像ノードを接続できる。
- `backInput`: 裏面専用の画像・色。未接続は透明。
- `shadowOpacity`: Bへ落とす影の濃さ。0で無効、0〜1へclampする。
- `shadowSoftness`: 影の柔らかさ。Size Referenceに対する距離比率。0でも紙の浮き上がりに伴う影の広がりは残る。負値は0へ制限する。
- `shading`: 曲面の明暗の強さ。0で無効、0〜1へclampする。固定の正面光と環境光を想定し、平らな面の明るさを保ちながら、横を向いた面を最大45%減光する。
- `sizeReference`: 半径と影幅の換算基準。紙の座標や縦横比は変更しない。

## 裏面

- `source`（Tinted Front）: Aを流用し、Back Colorの紙色へ70%寄せる。Back Colorのalphaは染色の強さであり、0ならAの色をそのまま使う。Aのalphaは維持する。
- `color`（Solid Color）: Back ColorのRGBAをそのまま裏面に使う。画像ノードを接続した場合は、その色の場を使う。
- `input`（Back Image）: Back InputのRGBAを使う。Back Colorは使わない。

全ての裏面入力を表面と同じ紙の材料座標へ貼る。折り返された面の逆参照によって、斜めの折り目に対する鏡像になる。別画像も同じ規約に従う。

Sourceモードの色は、乗算済みの表面色をF、紙色をPとすると、RGBが`F.rgb * (1 - 0.7 * P.a) + P.rgb * 0.7 * F.a`、alphaが`F.a`。透明なAを紙色で不透明にしない。Color/Inputモードは選択した裏面自体のalphaを使うため、Aが透明でも不透明な裏面を指定できる。

## 形状とアンチエイリアス

長辺全体=1の等方的な座標で、反対の隅から選択した隅へ向く実寸の対角線を軸にする。UV上の45度を固定しないため、縦長・横長の画面でも円筒の断面は歪まない。折り目は軸に直交する直線。

対角線の長さをL、半径をrとし、折り目cを進捗に応じてLから-rまで移動する。反対の隅を0とする軸に沿った材料座標uを次の形状へ写す。

- `u <= c`: 平らな表面。`x=u, z=0`。
- `c < u < c + πr`: 半円筒。`θ=(u-c)/r, x=c+r sin(θ), z=r(1-cos(θ))`。
- `u >= c + πr`: 裏返された平面。`x=2c+πr-u, z=2r`。

軸に平行な各断面と元の矩形の交差から、その断面に存在する材料範囲を求める。この範囲を曲面・反転平面にも適用し、剥がれた三角形の側辺を保つ。裏面が必ず手前に来るため、隠される表面を取り除いてから描画する。

画素を軸方向に切った4断面で被覆面積を近似積分する。各断面内は可視区間との交差長を連続的に求めるため、薄い裏面も被覆へ寄与する。表裏の外縁で被覆を二重に加えない。曲面・裏面は交差区間の重心を逆参照し、静止している表面とBは元の画素中心を読む。これにより開始直後に画像全体がぼけない。

元画像の逆参照は紙の矩形内の端画素中心までに制限し、その中で接続のFit / Wrap / Filterを適用する。形状自体が連続して元のA/Bへつながる。

## 透明度・影・出力

画像のalphaによるsource-overではなく、紙が画素を覆う面積でRGBAを置換する。透明な紙の下にBを透かさず、紙が退いた場所からBを見せる。HDR・負のRGB・半透明を保持し、曲面の明暗はRGBだけへ適用する。

影は各断面の紙の外縁から選択した隅側へ落とす近似影。浮き上がりの高さと、画面に残っている紙の範囲に応じて減衰する。影の設定を変えても紙の軌道は変わらない。外縁に対応するAのalphaで影を弱め、透明なAは影を落とさない。Color/Inputモードでも影を落とす元の被覆はAを基準とする。影はBのRGBだけを減光し、alphaを増やさない。

画像出力のみ。自動解像度はA/B/Back Inputを参照する。`transition`タグで検索できる。時間・描画履歴には依存せず、同じ進捗なら逆再生やスクラブでも同じ形になる。

## 検証

`test/corner-peel.gpu.test.mjs`で四隅、縦長・横長・正方形、有限の紙の側辺、材料座標、表裏の前後関係、各裏面モード、陰影、AA、透明度・HDR、影、端点の連続性、入力テクスチャ、Size Reference・解像度・時刻への不変性を実GPUで検証する。幾何の期待値は各面の逆投影から独立して求め、AAは高密度の点サンプルと照合する。

`CHROME_PATH`を設定して実行する。任意で`CORNER_PEEL_PREVIEW_PATH`にPNGの保存先を指定すると、同じGPU出力から4隅・5段階の進捗の比較画像を保存する。

# Blinds Wipe

描画領域を平行な帯へ分け、各帯をブラインドのように開いてAからBへ切り替える。

## パラメータ

- `inputA` / `inputB`: 画像または色。未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。式・キー・scalarノード接続に対応する。場を接続した場合は出力位置の局所進捗を使用する。
- `angle`: 帯を開く方向。上が0、右が0.25、正値で時計回り、1で1周。帯の境界線はこの方向に直交する。
- `count`: 進行方向へ射影した描画領域全幅の分割数。整数へ丸め、1〜4096に制限する。斜め方向でも帯は等方的な角度と等幅を保つ。
- `mode`: `oneSided`は各帯の負方向の端から正方向へ開く。`centered`は各帯の中央から両側へ対称に開く。
- `stagger`: -1〜1の帯間遅延。0は全帯同時。正値は進行方向の負側の帯から順に、負値は逆順に開始する。絶対値は最初と最後の帯の開始時刻の差を、1帯の開放時間に対する比率で表す。Count=1では無効。
- `feather`: 境界をぼかす全幅。`sizeReference`に対する距離比率。隣の帯の時間差を広域に混ぜないよう、実際の幅は1帯分を上限とする。

帯の局所進捗は `clamp(progress * (1 + abs(stagger)) - abs(stagger) * order, 0, 1)`。orderは各帯の順序を0〜1へ正規化した値。したがって遅延を増やしても進捗の端点で全帯が完全に閉じる／開く。

## 境界・入出力

帯の始端・終端を含めて区間平均し、線形のFeatherを適用する。ぼかし窓が隣の帯へ入る場合は、その帯固有の局所進捗を使う。これによりStaggerを設定しても帯境界に誤った周期的な切れ目を作らない。描画領域外の仮想帯は最寄りの帯と同じ順序で開く。

Feather=0でも1画素を進行方向へ射影した幅でアンチエイリアスする。帯が画素より細かい場合は1周期分を平均し、細かい位相による明滅を抑える。画像・Maskの端点は厳密で、直前直後も連続する。

主出力`output`はpremultiplied alphaのlinear sRGBを補間し、HDR・負値・透明度を保持する。`mask`はBの置換率（0=A、1=B）で、色やalphaに依存しない。配置の生成時に、使用する出力だけを確保する。Maskは16bit / 32bitに対応する。

自動解像度はA/B両方を参照する。入力のFit / Wrap / Filterは接続設定に従う。時間・履歴には依存しない。

## パラメータの再検討

中央から開く形は片側開放とは異なる見た目になるため、Openingを追加した。独立したReverseはAngleまたはStaggerの符号と重複するため追加しない。EasingはProgressの式・キーで指定できる。Countの概念を保つため帯幅を別パラメータとして重複させず、Size ReferenceはFeatherだけに適用する。

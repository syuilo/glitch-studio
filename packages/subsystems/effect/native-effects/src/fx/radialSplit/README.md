# Radial Split

画像・色の配列を均等な角度の扇形へ配置する。扇形は画面端まで続き、円形への切り抜きは行わない。初期状態は透明な入力2個、中心[0, 0]、Start Angle 0、Clockwise、Gap 0。

- Start Angleは上向きを0、時計回りを正として1で1周。先頭の扇形の開始境界を指定し、Directionの向きへ配列順に配置する。
- Centerは中央原点・右が+X・上が+Y、出力の長辺全体を1とする共通座標。画面外の中心も使用できる。長方形の画面でも角度と隙間の幅は歪まない。
- Gapは境界を挟む隙間の合計幅。各領域の境界をGap/2ずつ内側へ移す。Size Referenceの寸法を1とし、既定値はLong Side。負値は0として扱う。
- **画像の配置基準はGapを引いた後の領域。** 残った扇形と出力画面が重なる範囲の、画面の縦横に平行な外接矩形へ中央揃えでFitする。Gap・入力数・Center・Start Angleを変えると画像の位置や倍率も変わる。
- 画像自体は画面に対して正立させる。Fit / Wrap / Filterは既存の入力接続設定に従い、Fitの縦横比は各領域の外接矩形を基準にする。Containでも扇形によって画像の一部が切り取られる場合がある。
- 入力0個は全面透明。入力1個はCenter・Start Angle・Direction・Gapによらず全画面へ配置する。
- 未接続・透明な入力も扇形を確保する。画面に残る領域がない場合は透明にし、他の入力へ領域を再配分しない。
- 一定幅のGapにより中心付近に空きが生じる。入力数が多いほど中心側の見えない範囲が広がり、過大なGapでは領域全体が消える場合がある。
- 中心ちょうどには角度がないため、Gapなしでは先頭入力、Gapありでは透明とする。境界へアンチエイリアスを適用し、Gapなしでは境界に透明な筋を作らない。
- 入出力は乗算済みalphaのlinear sRGB・rgba16float。半透明・HDR・負のRGBを保持し、描画履歴には依存しない。
- 出力寸法と接続時のサンプリング既定値は既存仕様に従う。入力数固有の上限や、多数入力向けの分割描画は追加しない。

# Point Network 3D

3D空間に点を配置し、近接した点の間に線と三角形を描く生成エフェクト。
点・線・面は独立に表示できる。出力は透明背景のpremultiplied alpha・linear sRGB・rgba16float画像。
描画済みの画像を出力するため、Timelineの他のレイヤーと3Dの深度は共有しない。

## 配置と動き

- `Point Count`は0〜4096、`Seed`は32bit整数。小数の点数・接続数は切り捨てる。上限超過や負数はエラーにし、黙って点を間引かない。
- `Distribution`はBox・Sphere Volume・Sphere Surface・Plane・Grid。Extent XY/Zは各軸の全幅で、長辺全体=1の共通空間単位。
- Boxは箱の内部、Sphere Volumeは球の内部、Sphere Surfaceは球面に一様な乱数を配置する。球はExtentで各軸へ拡縮されるため、寸法が異なれば楕円体になる。PlaneはZ=0の矩形内。
- Gridは点数以上の最小の立方数に対応する格子を作り、X、Y、Zの順に点を並べる。立方数でなければ末尾が欠ける。1点は原点。乱数配置は点数を増やしても既存の点IDの位置を保つが、Gridは段数が変わると再配置される。
- Motion Amountは各軸のノイズ変位の最大振幅。Motion Frequencyは空間周波数、Motion Speedはノイズ内を進む速さで、負数で逆行できる。3成分の滑らかな値ノイズを使い、PlaneもZ方向へ変位する。
- 動きには`Time`（秒）だけを使う。自動再生するにはTimeの式に`TIME`を指定する。ctx.time・timeDelta・描画回数・過去のフレームを積算しない。
- 変位の後にScale XY/Z、Rotation X→Y→Z、Position XY/Zを適用する。角度はturn単位、+Yは上、+Zは既定カメラ側。Scaleは点の位置へ作用し、Point Diameter・Line Widthには作用しない。
- 点群の移動・回転・拡縮は`Point Cloud Transform`セクションにまとめる。`Rotation X / Y / Z`はカメラを動かさず、点群のローカル原点を中心に点・線・面を一緒に回転する。例えばRotation Yの式を`TIME * 0.05`にすると20秒で1周する。カメラの位置・注視点・投影は別の`Camera`セクションで設定する。

## 接続と三角形

各点はConnection Distance**未満**の点を距離順に最大K個（Maximum Connections per Point、0〜12）選ぶ。同距離では小さい点IDを優先する。互いを候補に含む組だけを無向の辺とするため、実際の次数もK以下になる。一方向だけが選んだ相手へは接続しない。

- Dynamicは変位・拡縮後の3D距離を使い、点が近づくと接続し、離れると切れる。
- Fixedは変位前・拡縮後の距離を使う。固定するのは動きに対する接続であり、点数・Seed・配置寸法・Scale・接続条件を変更すれば再構築する。
- カメラ・投影・Size Space・Screen Size Referenceは接続判定へ影響しない。
- 距離を保存する全体の回転・平行移動も接続判定へ影響しない。数値誤差で同距離の順位が変わらないよう、それらの変換前の座標で距離を計算する。
- Connection Fadeは接続距離のうちフェードに使う割合。距離R、設定fでは`R*(1-f)`からRに向かってsmoothstepで消える。0ならフェードなし。Fixedではフェードにも変位前の距離を使う。
- 近傍の順位が入れ替わる場合には接続が瞬時に変わり得る。履歴を持つヒステリシスや前フレームからのクロスフェードは行わない。

3点の全ての組に辺があるとき、1枚の両面三角形を作る。近接ネットワークの断片的な面であり、面の交差・重なり・穴を許す。点群を覆う閉じた表面の再構成は行わない。退化した三角形は描かない。

辺は小さいIDの端点だけ、三角形は最小IDの点だけが描き、重複加算を避ける。Face Probabilityは3点のIDとSeedから決める固定の抽選で、時刻や近傍の並び順によって再抽選しない。面の不透明度には3辺のフェードの最小値を使う。Face Shadingはカメラ方向の光を使った簡単な両面陰影。

接続の生成と線の表示は独立している。Show LinesをOFFにしても面は残る。色のalphaで点・線・面それぞれの不透明度を指定する。

## 点と線の寸法

点はカメラを向く円、線はカメラを向く帯で、球や円柱の立体メッシュではない。Point Diameterは直径、Line Widthは全幅。両者で一つのSize Spaceを共有する。

- Screen（既定）: 画面上の相対寸法を保つ。Screen Size Reference（既定Long Side）に対する比率。ピクセル固定ではなく、解像度を変えても相対寸法を保つ。
- 3D Space: 点の位置や接続距離と同じ共通空間単位。透視投影では遠いほど細くなり、平行投影ではOrthographic Sizeに従う。Screen Size Referenceは適用しない。

Size Spaceの変更時は値を換算しない。位置・接続距離・面の形状も変更しない。

## カメラ

Camera XY/ZからCamera Target XY/Zを見る。通常は+Yを上とし、真上/真下を向く場合は+Zを基準にする。視点と注視点が一致すると-Zを向く。

PerspectiveのField of Viewは描画領域の長辺方向の画角。既定は45度（0.125 turn）、Camera Zは`0.5/tan(22.5度)`で、Z=0の位置が画面の共通座標と一致する。画角は0.001〜0.499 turnへ制限する。Orthographicでは長辺方向にOrthographic Sizeの範囲を表示する。

Near Clipは0.001〜999、Farは1000で固定。点は中心がNear面より手前なら表示しない。線は透視除算前にNear面で切り、面はGPUの同次座標クリッピングを使う。Near Fade Distanceが正ならNear面から指定距離の間でsmoothstepにより表示する。カメラに近い要素が画面全体へ強く発光するのを抑える。

## 合成

- Additive（既定）: premultiplyしたRGBを加算し、alphaは被覆の和集合`a+b*(1-a)`にする。奥の要素も見え、重なるほど明るい。HDRと負のRGBを保持し、alphaだけを0〜1に制限する。
- Depth (Nearest Surface): depth bufferで最前面だけを採用する。半透明な色・距離フェードは出力のalphaへ反映するが、その奥の点・線・面を透かして重ねる方式ではない。alphaが完全に0の要素は隠面判定から除外する。

4サンプルのMSAAを使い、点の円周には解析的なアンチエイリアスも適用する。Depthでは同じ面上の線・点をわずかなdepth biasで優先する。発光のぼかしや色調整は後段のエフェクトで追加できる。

## 実行と上限

点の生成と近傍探索はCompute Pass、点・線・面の描画はインスタンス化したRender Passで行う。点数Nの全比較はO(N²)で、解像度には依存しない。Kを小さくすると近傍保持と描画の負荷が下がるが、距離の全比較は残る。点だけ表示すると近傍探索を省く。

相互近傍に限定するため、実際の辺は最大`N*K/2`、三角形は最大`N*K*(K-1)/6`。最大設定では辺24,576本・三角形90,112枚以下になる。描画候補の枠は辺`N*K`、面`N*K*(K-1)/2`あり、非該当の枠は頂点シェーダーで棄却する。予算超過時のランダムな間引きやatomic順に依存する選択は行わない。

既定値は256点・最大6接続。4096点は許容上限であり、全GPUでリアルタイムを保証する値ではない。Render Passは共通のタイル描画に対応するが、Compute Passの仕事量はタイル分割で減らない。全ての所有buffer・MSAA/depth textureをdisposeで破棄する。

## 検証

`test/point-network-3d.gpu.test.mjs`で実際のエフェクトと接続シェーダーを検査する。既知の点配置の近傍はCPUの全距離ソートと照合し、描画は単一点・単一辺・単一三角形・重なる点の解析値と比較する。時間とSeedの再現性、表示切替、寸法基準、縦横比、解像度、HDR/alpha、Nearクリッピング、最大負荷を含む。

`CHROME_PATH`を指定して実行する。`POINT_NETWORK_3D_PREVIEW_PATH`を指定すると、描画結果の比較画像も保存する。

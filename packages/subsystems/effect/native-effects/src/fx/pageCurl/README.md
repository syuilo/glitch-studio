# Page Curl

画像Aを紙のように丸めて裏面を見せながらめくり、下の画像Bへ切り替える。4辺からの一様なめくりを、正面からの平行投影で描画する。角をつまむ動作・透視投影・物理シミュレーションは持たない。

## パラメータ

- `inputA` / `inputB`: めくるページの表面と、下から現れる画像。画像・色を指定でき、未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。式・キー・scalarノード接続に対応する。空間場を接続した場合は出力位置ごとの局所進捗として評価し、紙全体を同じ形で動かす場合は一様な進捗を使う。
- `startEdge`: `right`は右端から左へ、`left`は左端から右へ、`top`は上端から下へ、`bottom`は下端から上へめくる。
- `curlRadius`: 曲面の半径。小さいほど鋭く、大きいほど緩やかに曲がる。Size Referenceに対する距離比率。0以下は鋭い折り返しの極限として、共通単位の微小半径0.000001へ制限する。
- `backMode`: 裏面の作り方。下記参照。
- `backColor`: 裏面の色または表面流用時の紙色。色・画像ノードを接続できる。
- `backInput`: 裏面専用の画像・色。未接続は透明。
- `shadowOpacity`: Bへ落とす影の濃さ。0で無効、0〜1へclampする。
- `shadowSoftness`: 影の柔らかさ。Size Referenceに対する距離比率。0でも紙の浮き上がりに伴う影の広がりは残る。
- `shading`: 曲面の明暗の強さ。0で無効、0〜1へclampする。固定の正面光と環境光を想定し、平らな部分の明るさを保ちながら、横を向いた面を最大45%減光する。
- `sizeReference`: 半径と影幅の換算基準。紙の座標や縦横比は変更しない。

## 裏面

- `source`（Tinted Front）: Aを流用し、Back Colorの紙色へ70%寄せる。Back Colorのalphaは染色の強さであり、0ならAの色をそのまま使う。Aのalphaは維持する。
- `color`（Solid Color）: Back ColorのRGBAをそのまま裏面に使う。画像ノードを接続した場合は、その色の場を使う。
- `input`（Back Image）: Back InputのRGBAを使う。Back Colorは使わない。

全ての裏面入力を、表面と同じ紙の材料座標へ貼る。折り返された面の逆参照によって、左右からめくる場合は横方向、上下からめくる場合は縦方向に反転する。別画像もこの材料座標の規約に従う。

Sourceモードの色は、乗算済みの表面色をF、紙色をPとすると、RGBが `F.rgb * (1 - 0.7 * P.a) + P.rgb * 0.7 * F.a`、alphaが `F.a`。透明なAを紙色で不透明にしない。Color/Inputモードは選択した裏面自体のalphaを使うため、Aが透明でも不透明な裏面を指定できる。

## 形状とアンチエイリアス

開始辺と反対の辺を0、開始辺をLとする共通単位の軸を使う。半径rに対し、折り目cは進捗に応じてLから-rまで移動する。材料座標uを次の形状へ写す。

- `u <= c`: 平らな表面。`x=u, z=0`。
- `c < u < c + πr`: 半円筒。`θ=(u-c)/r, x=c+r sin(θ), z=r(1-cos(θ))`。
- `u >= c + πr`: 裏返された平面。`x=2c+πr-u, z=2r`。

正面視点では裏面の方が必ず高いため、表面から裏面に隠れる区間を取り除いてから描画する。画素と各可視区間の交差面積でアンチエイリアスを行い、その重心から材料座標を逆参照する。外縁で表裏の被覆率を二重に加えない。

紙の範囲は出力サイズの有限矩形。逆参照は矩形内の端画素中心までに制限し、その中で接続のFit / Wrap / Filterを適用する。開始・終了だけ特別な画像へ飛ばすのではなく、形状自体が連続して元のA/Bに繋がる。

## 透明度・影・出力

画像のalphaによるsource-overではなく、紙が画素を覆う面積でRGBAを置換する。透明な紙の下にBを透かさず、ページが退いた場所からBを見せる。HDR・負のRGB・半透明を保持し、曲面の明暗はRGBだけへ適用する。

影は紙の外縁から開始辺側へ落とす近似影。浮き上がりの高さと、画面に残っている紙の範囲に応じて減衰させるため、両端で滑らかに消える。影の設定を変えても紙の軌道は変わらない。外縁に対応するAのalphaで影を弱め、透明なAは影を落とさない。Color/Inputモードでも影を落とす元の被覆はAを基準とする。影はBのRGBだけを減光し、Bのalphaを増やさない。

画像出力のみ。自動解像度はA/B/Back Inputを参照する。時間・描画履歴には依存せず、同じ進捗なら逆再生やスクラブでも同じ形になる。

## 検証

`test/page-curl.gpu.test.mjs`で、4辺の幾何、表裏の材料座標、各裏面モード、アンチエイリアス、透明度・HDR、影、端点の連続性、入力テクスチャ、Size Reference・解像度・時刻への不変性を実GPUで検証する。

`CHROME_PATH`を設定して実行する。任意で`PAGE_CURL_PREVIEW_PATH`にPNGの保存先を指定すると、同じGPU出力から4方向・5段階の進捗の比較画像を保存する。

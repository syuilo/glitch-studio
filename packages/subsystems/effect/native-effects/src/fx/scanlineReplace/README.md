# Scanline Replace

横帯ごとにAをBへ置き換え、切替中の帯だけ横ずれ・色ずれを加える。

## パラメータ

- `inputA` / `inputB`: 画像または色。未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。scalar場接続時は出力画素ごとの局所進捗になる。
- `bandSize`: 横帯の高さ。Size Referenceに対する距離比率。画面中央に1帯の中心を置く。非正値は0.000001として扱う。
- `stagger`: 帯ごとの切替時刻のばらつき。0は全帯が中央で同時に切替、1はseedで決まる時刻を全範囲に広げる。範囲外は0〜1へclampする。
- `softness`: 各帯の切替期間を広げる幅。空間的な輪郭のぼかしではない。正値ではsmoothstepで混合し、進捗両端へ余白を取って完全なA/Bへ連続的に繋ぐ。0以下は硬い切替になり、切替途中がないため変位・色ずれも生じない。
- `displacement`: 帯ごとの最大横ずれ距離。帯IDとseedから符号と振幅を決める。
- `chromaticShift`: 赤と青を緑から左右へずらす距離。0で色ずれを無効化する。
- `seed`: 切替順・横ずれを決める整数seed。32bit符号なし整数として扱う。
- `sizeReference`: Band Size・Displacement・Chromatic Shiftの寸法基準。

## 描画仕様

切替の重みをwとして、横ずれと色ずれは4w(1-w)で包絡する。切替前・後は元位置をそのまま参照し、局所切替の中央でだけ乱れが強くなる。AとBは互いに逆方向へ横ずれする。帯の乱数は整数帯IDとseedに固定し、時刻・描画履歴には依存しない。

横帯の境界は硬い区切りを維持する。入力のFit / Wrap / Filterは通常の接続設定に従う。入力はpremultiplied alphaのlinear sRGBとして補間し、HDR・負値を保持する。色ずれではRGBを各参照位置から取り、alphaは3位置の最大値を使用して各色の被覆を保持する。

出力は画像のみ。単一の置換率だけでは移動した参照位置を再現できないためMaskは持たない。自動解像度はA/B両方を参照する。

## パラメータの再検討

Softnessは帯の乱れが続く期間を、Chromatic Shiftは色ずれの強さを独立に調整できるため追加した。順序enum・逆順・独立したEasingは増やさず、ランダムな帯切替という役割に絞る。Softness=0の硬い切替も明示的に選べる。

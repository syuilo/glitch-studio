# Switch (Color)

`Condition` が false のフレームでは `False`、true のフレームでは `True` の画像または色を出力します。`Condition` の既定値は false で、チェックボックスや式、キーフレームで切り替えられます。両方の色入力の既定値は透明です。

自動解像度は、両入力のうち接続された画像で画素数が最大の寸法を使います。両方とも定数の場合は描画先の寸法に従います。選択した画像は、その接続の Fit・Wrap・Filter を適用してサンプリングします。

このエフェクトの描画パスは選択した入力だけを読みます。両入力の上流ノードは描画依存関係に含まれるため、切り替え先に履歴を持つエフェクトがあっても、切り替える前からその履歴が進みます。

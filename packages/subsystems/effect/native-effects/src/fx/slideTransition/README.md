# Slide Transition

静止した画像へ別の画像を滑り込ませる、または上側の画像を滑り去らせて、AからBへ切り替える。

## パラメータ

- `inputA` / `inputB`: 画像または色。未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。式・キー・scalarノード接続に対応する。ノード接続時は出力画素ごとに進捗を読み、局所的な移動・歪みとして扱う。
- `angle`: 移動する画像の実移動方向。上が0、右が0.25、正値で時計回り、1で1周。
- `mode = cover`: Aを静止させ、Bを指定方向へ滑り込ませる。
- `mode = uncover`: Bを静止させ、Aを指定方向へ滑り去らせる。

方向は長辺全体=1の等方座標で計算する。移動距離は、指定方向へ動かした出力サイズの矩形が最初に完全に画面外へ出る距離。斜め方向でも角度を歪めず、画面外での待ち時間を含めない。画像は回転せず矩形のまま動く。

## 画像の範囲・透明度

移動する画像の範囲は出力サイズの矩形とし、入力のWrapとは独立してクリップする。矩形内の素材参照には接続のFit / Wrap / Filterを適用する。境界には1画素幅の被覆率によるアンチエイリアスを適用し、境界で参照する座標は矩形内の最後の画素中心までに制限する。

画像のalphaではなく矩形の被覆率でA/Bを置換する。例えば透明なBが入ってきた領域は透明になり、下のAは残らない。このため半透明画像でも端点まで連続して完全なA/Bに繋がる。補間はpremultiplied alphaのlinear sRGBで行い、HDRや負値を保持する。

自動解像度はA/B両方を参照する。時間・履歴には依存しない。出力は画像のみ。単一のMaskでは移動した参照座標を再現できないため、scalar出力は持たない。

## パラメータの再検討

Featherは移動矩形の端と完了状態の調整が必要になり、単純なスライドの操作を増やすため追加しない。移動の緩急はProgressの式やキーで設定できるので、専用Easingも持たない。移動量は画面全体を出入りする意味に固定し、Size ReferenceやDistanceは追加しない。

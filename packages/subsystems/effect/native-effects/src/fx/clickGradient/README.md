# Click Gradient

Effect Live Previewや書き出したWeb Componentで画面を押すと、その位置から円形の帯が広がります。`Speed`は先頭が1秒に進む距離、`Width`は先頭から中心側へ続く帯の幅です。いずれも描画領域の長辺全体を1とします。

`Interpolation`はGradientと同じ補間曲線を使い、既定値は`Smoothstep`です。帯の先頭の値は1、後端の値は0です。帯の外側の値は0で、先頭には段差ができます。`Back`と`Elastic`では帯の途中で0〜1の範囲外の値も出力します。

`Duration (s)`は押下ごとの寿命です。既定値の0では、帯が描画領域を通過するまで時間方向の減衰なしで広がります。正の値では押下時点から滑らかに減衰し、指定秒数でその押下の寄与が0になります。

`Reflectivity`は出力領域の四辺で反射する帯の強さです。既定値の0では反射を無効にします。横・縦それぞれ最大1回反射し、振幅には反射1回ごとに`Reflectivity`を掛けます。たとえば0.8では、角の2回反射で振幅が0.64倍になります。描画領域外の押下では直接の帯が広がります。

- **scalar** は時間減衰と反射の減衰を掛けた帯の値です。重なった画素では、そこを通過している帯のうち最大値を採用し、同値なら新しい押下を優先します。
- **vector** は採用された帯の値の空間勾配です。長辺全体を1とする座標での偏微分を出力します。円の中心や帯の端では0です。

# Pixel Stretch

画像内の直線上の色を、境界が通過した側へ垂直に引き伸ばす。

- `position` は描画領域を進行方向へ射影した範囲での境界位置。`0` では入力のまま、`0.5` では中心を通り、`1` では全領域を引き伸ばす。範囲外の値は `0〜1` に制限する。
- `angle` は Linear Wipe と同じく境界の進行方向。`0` で上、`0.25` で右、正値で時計回り。色は進行方向の反対へ伸びる。
- 画素を境界線へ垂直に投影し、投影先が画面内の線分を外れる場合は最寄りの端点を使う。`position = 1` の境界は縦・横方向では画面の一辺、斜め方向では角の一点になる。
- 境界の参照位置は描画領域の最外周の画素中心までに収める。入力の Fit / Wrap / Filter は通常どおり適用し、premultiplied alpha・HDR・負値を保持する。

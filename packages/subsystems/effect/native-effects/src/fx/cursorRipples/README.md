# Cursor Ripples

Effect Live Preview と Web Component で、マウスの移動や最初の指のドラッグの軌跡から波を起こします。連続して取得した各位置を線分でつなぎ、線分全体にブラシを通します。速度に応じて波が強くなり、入力する強さには上限があります。領域に入った直後やタッチ開始時は位置を記録し、次の移動から波を起こします。ポインターが静止したり外へ出たりしても、既に起こった波は広がって減衰します。

- `Intensity` は変位の大きさです。`0` でゼロベクトルになります。
- `Decay` は波の減衰の速さです。`0` では自然減衰しません。
- `Radius` は軌跡に沿うブラシの影響半径です。描画領域の長辺全体を `1` とする単位で、既定値は `0.075` です。

`Displacement` は長辺全体を `1` とする等方座標の変位です。画像を歪ませるには `Vector Displacement` の `Vector` へ接続し、`Amount` を `1` にします。色ずれを加えるには `Vector Chromatic Aberration` の `Vector` へ接続し、`Amount` と `Samples` を `1`、`R Strength`・`G Strength`・`B Strength` をそれぞれ `1.1`・`1`・`0.9` にします。変位場と画像の描画領域を揃えると位置と寸法が一致します。画像の端は入力接続の `Wrap` で選べます。

高さ場は長辺128セルで、短辺のセル数は縦横比から決まります。波は内容時刻に従って1秒あたり120ステップ進みます。描画が長時間止まった場合は1フレームで進める時間を200ミリ秒までに抑えます。高さ場の勾配を補間し、配置の描画解像度の変位場にします。一時停止中は波を保持し、履歴リセットや解像度変更で水面を初期化します。Timeline と動画書き出しではポインター入力が供給されず、変位はゼロです。

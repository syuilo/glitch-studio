# Click Ripple

Effect Live Previewや書き出したWeb Componentの描画領域で、左ボタンを押すか最初の指が触れた瞬間に波紋が発生します。直近16件のうち、現在の内容時刻が押下後から`Duration (s)`の間にある波紋を評価します。押下履歴のないフレームでは、どちらの出力もゼロです。

- **Displacement** は正負の波を放射状の変位として出力します。複数の変位は加算します。`Vector Displacement`の`Vector`へ接続し、`Amount`を1にすると`Strength`で指定した変位の大きさがそのまま反映されます。
- **Mask** は波の山を0〜1で出力し、重なった場所では最大値を使います。`Color Ramp`で着色する場合は、値0に透明色を割り当てると波の外側が透過します。

距離の単位は描画領域の長辺全体を1とします。`Speed`は秒あたりの先端の移動距離、`Wavelength`は山の間隔、`Width`は先端から後方に続く帯の幅です。`Strength`は押下1件の直接波の最大変位を決め、`Mask`の強さは時間と距離の減衰で決まります。

`Reflectivity`を上げると、波がエフェクトの出力領域の四辺で同位相のまま反射します。既定値の`0`では反射せず、`0.8`では反射1回で振幅が0.8倍、角の2回反射で0.64倍になります。各波は横方向と縦方向でそれぞれ最大1回反射します。描画領域外の押下には直接波が発生します。

波紋はフレームの内容時刻と押下履歴から直接計算します。Web Componentの一時停止中は波紋の時間も止まり、`restart()`で押下履歴を消去します。

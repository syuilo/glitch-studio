# Split Transition

画面を左右または上下の二つの矩形領域に分割し、各領域の大きさに合わせて画像を配置し直しながらAからBへ切り替える。Progressを固定すれば分割画面の合成にも使える。

## 入出力と配置

- `inputA` / `inputB`は画像または色。未接続は透明で、透明な入力にも領域を確保する。
- `progress`は0で全面A、0.5でGapを除いた領域を等分、1で全面B。範囲外は0〜1に制限する。既定値は0。式・キーで制御できる全体共通の値であり、scalar場のノード接続には対応しない。
- `direction = horizontal`（Left / Right）は左にA、右にB、`vertical`（Top / Bottom）は上にA、下にBを置く。既定はHorizontal。
- `reverse`はA/Bの配置順だけを反転する。画像自体の向きと、0=A・1=BというProgressの意味は変えない。
- 各画像を自身の領域の中央に配置し、その領域の縦横比を基準に入力接続のFit / Wrap / Filterを適用する。Coverは領域を埋めて切り抜き、Contain + Transparentは全体を収め、Stretchは領域へ非等方に伸縮する。
- 入力内の透明余白も含めて配置する。領域外とGapは入力のWrapにかかわらず透明。定数色は自身の領域全体を塗る。背景色は別のエフェクトで合成する。
- 自動解像度にはA/B両方の入力を使い、出力寸法は既存の解像度設定に従う。入力の合計寸法へ自動拡大しない。
- 出力`output`はpremultiplied alphaのlinear sRGB・rgba16float。透明・半透明・HDR・負のRGBを保持し、時刻・フレームレート・履歴には依存しない。

## Gapと端点

- `gap`は透明帯の全幅。Size Referenceに対する距離比率で、既定値は0、Size Referenceの既定値はLong Side。負値は0、分割軸の全長を超える値は全長に制限する。
- 帯全体を画面外から画面外まで移動させる。中央付近では指定幅を保ち、両端では画面外へ抜けるため、Progress=0/1で余白が残らない。
- 分割軸の全長をD、制限後のGapをg、Progressをpとすると、Aの長さは`max(0, D - p * (D + g))`、Bの長さは`max(0, p * (D + g) - g)`。両画像をそれぞれの外側の端へ寄せる。
- Progressは境界の移動率であり、Bの面積率ではない。Gapがある場合、Bが現れるまでの区間とAが消えた後の区間がある。Gapが全長と等しい場合、Progress=0.5で全面透明になる。
- 領域寸法を整数に丸めず、画素との交差面積による1画素のアンチエイリアスを行う。境界画素は領域内の交差部分の中心で入力を読み、被覆率で重み付けして加算する。幅1px未満の領域も連続的に現れ、面積0の領域は入力を読まない。

# Zoom Transition

同じ中心へズームインまたはズームアウトしながら、画像Aから画像Bへ切り替える。

## パラメータ

- `inputA` / `inputB`: 画像または色。未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclamp。式・キー・scalarノード接続に対応し、場を接続した場合は出力画素ごとの局所進捗として読む。
- `center`: 長辺全体=1の共通座標。中央[0, 0]、右が+X、上が+Y。画面外の中心も指定できる。
- `zoom`: ズームの倍率（1以上）。1未満は1として扱う。1では拡大縮小せず、混合のみ行う。
- `direction = in`: Aを等倍からZoom倍へ拡大し、Bを1/Zoom倍から等倍へ拡大する。
- `direction = out`: Aを等倍から1/Zoom倍へ縮小し、BをZoom倍から等倍へ縮小する。
- `overlap`: 進捗0.5を中心とする混合期間の全幅。0〜1へclamp。0.5では0.25〜0.75の間で混合し、0では中央でカット、1では全期間で混合する。

## 変形と補間

倍率を指数補間するため、同じ進捗差は同じ倍率変化を表す。Inの場合、進捗pでの倍率はAがZoom^p、BがZoom^(p−1)。Outはその逆数。縦横へ同じ倍率を掛けるため、縦長・横長でも歪まない。

混合率はsmoothstepで補間する。開始時のAと終了時のBは等倍で、端点近傍から連続して元の入力へつながる。Overlap=0の中央カットだけは意図的に不連続になる。変形後の画像をpremultiplied alphaのlinear sRGBで補間し、透明・半透明・HDR・負値を保持する。

縮小時や画面外中心によって範囲外を参照した場合も、各入力接続のFit / Wrap / Filterに従う。エフェクト独自の矩形クリップや端延長は行わない。透明の外側を使いたい場合は接続のWrapをTransparentにする。

自動解像度はA/Bの両入力を参照する。時間・履歴には依存しない。出力は画像のみ。

## パラメータの再検討

Directionを追加し、倍率の強さを保ったままIn/Outを切り替えられるようにした。倍率を負値や1未満へ変えて方向を表す曖昧さを避ける。独立したEasingはProgressの式・キーと重複するため追加しない。倍率は無次元なのでSize Referenceを持たず、単一のMaskだけでは参照座標を再現できないためscalar出力も持たない。

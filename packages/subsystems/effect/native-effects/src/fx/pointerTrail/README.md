# Pointer Trail

Effect Live Preview と Web Component で、ポインターの移動に沿って軌跡を描きます。描画の間に複数の位置を取得したときは、連続する位置を順に線分でつなぎます。領域から出て戻ったときや、指を離して触れ直したときは軌跡が途切れます。

`Strength` は軌跡の強さ、`Radius` はブラシの半径、`Half-Life (ms)` は軌跡の強さが半分になるまでの時間です。同じフレームに届いた線分でも、先に通過した部分ほど減衰します。移動のないフレームでは経過時間に応じて残っている軌跡が減衰します。

ベクトル出力は軌跡の方向と強さを表します。スカラー出力には方向ごとの強さの絶対値を蓄積するため、往復でベクトルが相殺されても軌跡の強さが残ります。

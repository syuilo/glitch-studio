# Split Layout

任意の角度の直線で画面を二分し、各画像の中心を自身の領域の面積重心へ合わせて配置する。画像は回転・鏡像化しない。

## パラメータと領域

- `inputA` / `inputB`は画像または色。未接続は透明で、透明な入力にも領域を確保する。
- `angle`はAからBへ向かう分割線の法線方向。0は上、0.25は右、正値で時計回り、1で1周。既定値は0.25で、左にA、右にBを等分配置する。
- `offset`は中央から分割線までの符号付き距離。長辺全体=1の共通単位で、正値はAngleの方向へ線を移動してAを広げる。既定値は0。Size Referenceでは変わらず、画面外への移動も制限しない。
- `gap`は分割線を中心とする透明帯の全幅。Size Referenceに対する距離比率で、負値は0。既定値は0、Size Referenceの既定値はLong Side。画面の寸法で上限を設けない。
- 共通座標の画素位置をp、Angleの単位法線をn、Offsetをo、共通単位へ換算したGapをgとすると、Aは`dot(p,n) <= o-g/2`、Bは`dot(p,n) >= o+g/2`。残りは透明。
- Angle・Offset・Gapは式・キーで制御できる全体共通の値。画素ごとの場によるノード接続には対応しない。時刻・フレームレート・履歴には依存しない。
- トランジションの進捗や端点の補正は持たない。領域が画面外へ出ればその入力を描画せず、大きなGapで両領域が消えれば全面透明になる。

## 配置と描画

- 出力矩形と各半平面との交差領域から面積重心を求め、入力画像の中心を合わせる。画像の色・透明度・透明余白は重心の計算に使わない。
- 重心を中心として領域の全頂点を包む、画面の軸に平行な矩形を配置枠にする。その寸法を基準に入力接続のFit / Wrap / Filterを適用する。既定のCoverでは縦横比を保ち、領域全体を隙間なく埋めるため必要に応じて拡大・切り抜きする。
- Contain + Transparentは配置枠内に画像を収め、Stretchは配置枠へ非等方に伸縮する。いずれも分割領域の外を切り抜くため、Containでも画像全体が見える保証はない。定数色は自身の領域を塗る。
- 領域外とGapは入力のWrapにかかわらず透明。背景色は別のエフェクトで合成する。
- 境界は画素との交差面積でアンチエイリアスし、交差部分の重心で入力を読む。1px未満の領域やGapも描画し、Gap=0ではA/Bの被覆率の和を1に保つ。
- 自動解像度はA/B両方を参照し、出力寸法は既存の解像度設定に従う。画像出力はpremultiplied alphaのlinear sRGB・rgba16floatで、透明・半透明・HDR・負のRGBを保持する。

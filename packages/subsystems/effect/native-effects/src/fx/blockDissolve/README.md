# Block Dissolve

正方形のセルを単位として、AからBへ順次切り替える。

## 入出力

- `inputA` / `inputB`: 画像または色。未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。式・キー・scalarノードに対応。場を接続した場合は画素ごとの進捗となり、同一セル内でも異なる切替率を指定できる。
- `output`: premultiplied alphaのlinear sRGBで混合した画像。透明・半透明・HDR・負値を保持する。
- `mask`: Bへの置換率。画像の色やalphaに依存しないscalar。16bit / 32bitに対応。
- 配置の生成時に、使用する出力だけを確保する。Mask単独では画像のRender Targetや色を読む描画処理を使わない。
- 自動解像度はA/B両方を参照。素材の参照位置は動かさず、接続ごとのFit / Wrap / Filterに従う。

## セルと順序

- `cellSize`: 正方形の辺長。Size Referenceに対する比率。0以下を含む非常に小さい値は基準寸法の0.000001へ制限し、0除算を避ける。解像度に合わせた最小サイズは設けない。
- `sizeReference`: セル寸法の換算基準。縦長・横長でもセルは正方形。
- `gridOffset`: 中央セルの中心を置く共通座標。長辺全体=1、右が+X、上が+Y。Size Referenceで座標を変えない。
- `order = random`: セルの整数IDとSeedによる再現可能な順序。セルごとの乱数であり、全セルの順位を重複なしに並べ替えるものではない。
- `order = leftToRight`: 左の列から右の列へ切り替える。
- `order = topToBottom`: 上の行から下の行へ切り替える。
- `reverse`: 順序だけを反転する。どの設定でもProgressの0=A、1=Bを維持する。
- `seed`: Randomの順序に使う32bit整数。小数は整数化し、範囲外は32bitへ折り返す。方向指定の順序には影響しない。

方向指定では画面に一部でも交差する列／行を数え、各順位を0〜1の等間隔区間の中央へ配置する。ランダム順序は時刻・描画履歴・画素数に依存しない。同じ比率・基準寸法・パラメータなら解像度が変わっても同じセルと順序になる。

## Softness

`softness`は**セルごとの時間的なクロスフェード幅**であり、セル境界の空間ぼかしではない。

0では閾値を越えたセルが一度に切り替わる。正値ではsmoothstepを使い、隣り合う切替時刻のフェードが重なる。切替順序の値域に対する全幅を指定し、実際のProgress上のフェード幅は `softness / (1 + softness)`。開始・終了を含めた進捗全体へ収めるため、閾値の移動範囲を両端へ延長している。大きいSoftnessでも端点に残像や不連続を作らない。負値は0として扱う。

セルの境界は意図的に硬く保つ。空間的に滑らかな形状へ切り替えたい場合は、連続場を使うMap Transitionなどを使う。

## パラメータの再検討

逆方向を個別のOrderとして増やす代わりにReverse Orderを追加し、Randomの逆順も表現できるようにした。Grid Offsetは素材の区切りへ格子を合わせるために追加した。

格子の回転や放射状の順序は、初期版の操作を増やすため見送った。独自のイージングも設けず、Progressの式やキーで操作する。

# Double Pendulum Fractal

各画素を初期角度の異なる二重振り子へ対応させ、指定時間後の角度・角速度から模様を生成します。
振り子の棒や軌跡を描くエフェクトではなく、初期条件の平面を描きます。

参考: [The Double Pendulum Fractal](https://youtu.be/n7JK4Ht8k8M)、[元動画のソースコード](https://github.com/maksimovichsam/DoublePendulumVideo/blob/master/pendulum.py)。
運動方程式を固定刻みRK4で解き、元動画の配色は8bit量子化せず連続値で扱います。
元実装の一次の積分方法・刻み・精度とは異なるため、長時間後の画素単位の一致は保証しません。

## パラメータ

| パラメータ | 初期値 | 意味 |
| --- | --- | --- |
| Simulation Time | 0 | 初期状態からの経過秒。負値は0として扱います。式に`TIME`を指定するとアニメーションし、`TIME * 0.5`なら半速になります。 |
| Angle Center 1 / 2 (rad) | 各0 | 画面中央の初期角度。どちらも鉛直下向きからの絶対角で、下側を上側との相対角にはしません。 |
| Zoom | 1 | 初期角度の平面の拡大率。正数を指定します。 |
| Initial Angular Velocity 1 / 2 (rad/s) | 各0 | それぞれの初期角速度。符号付きです。 |
| Length Ratio | 1 | 上側の長さを1とした下側の長さ。正数を指定します。画像上の距離ではありません。 |
| Mass Ratio | 1 | 上側の質量を1とした下側の質量。正数を指定します。 |
| Gravity | 9.81 | 上側の長さを1としたモデル内の重力加速度。0なら無重力、負値なら重力方向が逆転します。 |
| Coloring | Original | Original・Angle 1・Angle 2・Angular Velocity 1・Angular Velocity 2。 |
| Color Ramp | 青→緑→ピンク | Original以外の配色。透明度・補間・色空間は共通のColor Ramp仕様に従います。 |
| Angular Velocity Range (rad/s) | 10 | 角速度配色の±範囲。`-Range → 0`、`0 → 0.5`、`+Range → 1`へ対応させ、範囲外は端の色に固定します。正数を指定します。 |
| Time Step | 0.01 | 数値積分の刻み秒。正数を指定し、描画FPSには依存しません。細かくすると計算負荷が増え、カオス領域では模様も変わります。 |
| Antialiasing | Off | 画素内の固定4点を独立に計算して平均します。積分の負荷も約4倍になります。 |

Angle Centerの入力・角度出力はrad、角速度はrad/sです。1回転=1のAngleコントロールとは単位が異なるため、Angle Centerには数値コントロールを使います。
UIの範囲は操作用であり、式の値をその範囲へclampしません。非有限値・GPUのf32で表せない値・正数が必要な場所の0以下は描画エラーにします。

共通等方座標の長辺全体=1を、Zoom=1で角度2πへ対応させます。Xは右向きにAngle 1が増加し、Yは元動画に合わせて下向きにAngle 2が増加します。
正方形では各軸が概ね−π〜π、横長2:1ではAngle 1が−π〜π、Angle 2が−π/2〜π/2になります。解像度で模様を伸縮させません。

Originalは、時刻評価後の角度から次の不透明なRGBを生成します。

```text
R = 0.5 + 0.5 * sin(angle1) * cos(angle2)
G = 0.5 + 0.5 * sin(angle1) * sin(angle2)
B = 0.5 + 0.5 * cos(angle1)
```

角度配色では`[-π, π)`をRampの`[0, 1)`へ対応させます。±πに継ぎ目があるので、滑らかな周期配色にはRampの両端を同じ色にします。

## 出力

| ポート | 型・単位 |
| --- | --- |
| Output | 乗算済みRGBA。Originalは不透明、ほかはRampの透明度を保持します。 |
| Angle 1 / 2 (rad) | scalar。`[-π, π)`へ折り返した絶対角度。 |
| Angular Velocity 1 / 2 (rad/s) | scalar。符号付き角速度。 |

データ出力は配色から独立し、未使用時は遅延確保します。データ精度設定に従ってr16float・r32floatを選び、内部の積分はf32です。
複数出力は同じ積分を共有し、単独のデータポートだけでも描画できます。
AAでは色と角速度は算術平均、角度は±πの境界で0へ反転しない円周平均です。円周上の向きが相殺された軸は固定4点の最初の値を使います。
数値テクスチャの精度への丸めにより、出力値は数学上の区間端をわずかに超えることがあります。

## 時刻・再現性・負荷

描画履歴には依存しません。各描画で0秒から整数ステップを計算し、最後の端数だけを追加して指定時刻まで進めます。
時計・前回の描画間隔・描画順序を使わず、シーク・異なるFPSでも同じパラメータを同じ経路で評価します。
すべての物理パラメータには、そのフレームで評価された値をシミュレーション全体へ適用します。過去のパラメータ変化は積分しません。

1サンプルあたり最大4096ステップです。Time Step=0.01では40.96秒までで、それを超える時刻は描画前にエラーにします。
上限に合わせて時刻を短縮したり刻みを粗くしたりしません。長い時刻を使う場合はTime Stepを大きくするか、時刻の式を調整します。
画素数・ステップ数・AAのサンプル数に比例して重くなるため、プレビュー倍率を下げて調整できます。

カオス系のため、Time Step・GPU・浮動小数点演算の差で長時間後の細部は変わります。
極端な物理パラメータには小さなTime Stepが必要で、粗い刻みでの数値的な安定性は保証しません。

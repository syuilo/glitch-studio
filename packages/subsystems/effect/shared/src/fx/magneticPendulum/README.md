# Magnetic Pendulum

各画素を磁気振り子の初期位置へ対応させ、収束した磁石の色と値を出力します。

## View

ViewはCenterとZoomをまとめた表示範囲です。回転フィールドは持ちません。

- Centerは画面中央に対応する初期位置です。長辺全体=1、右が+X、上が+Yの共通単位を使います。
- Zoom=1では画面の長辺全体が初期位置の長さ1に対応します。倍率の最小値は0.001です。
- Viewのポインタボタンでプレビュー操作を切り替えます。ドラッグで位置を動かし、ホイールでカーソル直下の点を保ってズームできます。
- 中心の数値欄と操作パッドの感度も倍率に連動します。CenterとZoomの式・キーフレームは独立して保持します。

Viewは初期位置を調べる範囲を指定するため、磁石の位置・高さ・強さや物理係数は変更しません。
内部のシミュレーションでは公開単位の0.25を長さ1へ換算しますが、この換算はViewの編集単位には影響しません。

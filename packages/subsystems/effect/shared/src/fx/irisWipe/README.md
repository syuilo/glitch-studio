# Iris Wipe

円の境界を広げる、または縮めることでAをBへ置き換える。

## 入出力と進捗

- `inputA` / `inputB`は画像または色。未接続は透明。
- `progress`は0で完全なA、1で完全なB。範囲外は0〜1へ制限する。定数・式・キーに加え、scalarノード接続による画素ごとの進捗にも対応する。
- 進捗は境界の移動を表し、Bの画面占有率ではない。時間・履歴には依存しない。
- 主出力`output`はpremultiplied alphaのlinear sRGBを補間し、HDR・負値・半透明を保持する。
- `mask`はBの置換率（0=A、1=B）。入力画像の色やalphaに依存せず、画像出力と同じ重みを返す。16bit / 32bitデータ出力に対応する。
- 両出力を遅延確保する。Mask単独では画像出力や色を読む描画処理を使用しない。
- 自動解像度はA・B両方の入力を参照する。入力のFit / Wrap / Filterは接続設定に従う。

## 中心・方向・Feather

- `center`は長辺全体=1の共通座標。中央が[0, 0]、右が+X、上が+Y。画面外の中心も扱う。
- `direction = outward`では中心側からBが広がる。`inward`では外側からBが入り、中央のAが縮む。どちらも0=A、1=B。
- 半径は中心から描画領域への最短距離〜最遠の隅への距離を基準にする。中心が画面外でも、その最短距離に到達するまでの待ち時間を進捗へ含めない。
- `feather`はSize Referenceに対するぼかしの全幅。既定は長辺基準。Centerの座標や円の縦横比はSize Referenceで変えない。
- 半径の移動範囲はFeatherの半幅だけ両端へ拡張し、端点まで滑らかに完全なA/Bへつなぐ。
- Featherはsmoothstepで補間する。0でも1画素の対角長によるアンチエイリアスを適用する。

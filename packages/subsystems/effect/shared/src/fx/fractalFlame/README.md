# Fractal Flame

複数のアフィン変換・非線形変換を確率的に選ぶIFSから、光の煙や花弁のような模様を生成します。
固定Seedの軌道をGPUで生成し、サンプルの密度と乗算済みRGBAを整数で集計します。描画履歴・時計・FPSには依存しません。

参考: Draves / Reckase, [The Fractal Flame Algorithm](https://flam3.com/flame_draves.pdf)。
アフィン変換後のvariationの加重和、軌道に沿う色位置の混合、対数密度表示を実装しています。
FLAM3のファイル互換や全variation、post/final transform、適応的な密度フィルターは含みません。

## Transforms

最大16個の変換を追加できます。初期状態は3個の変換を組み合わせた模様です。

| フィールド | 意味 |
| --- | --- |
| Weight | 変換の相対的な選択確率。0は無効、負値はエラー。正の重みだけを合計1へ正規化します。 |
| Position | アフィン変換の移動。長辺全体=1、中央原点、上が+Yの共通等方単位です。 |
| Rotation | アフィン変換の時計回りの回転。1回転=1です。 |
| Scale | X・Yの無次元の拡縮率。負値で反転、0でその軸を潰します。 |
| Shear | 無次元のX方向のshear。拡縮→shear→回転→移動の順で適用します。 |
| Color Position | Palette上の位置。0〜1へclampし、毎反復で現在の色位置と平均します。 |
| Variations | 下記8種類の混合係数。符号付きの加重和で、係数の和を正規化しません。 |

Variationsは、アフィン変換後の**同じ点**へそれぞれ適用して加算します。複数の写像を順番に合成するものではありません。

| Variation | モデル座標での写像 |
| --- | --- |
| Linear | `(x, y)` |
| Sinusoidal | `(sin(x), sin(y))` |
| Spherical | `(x, y) / r²` |
| Swirl | `(x sin(r²) − y cos(r²), x cos(r²) + y sin(r²))` |
| Horseshoe | `((x² − y²) / r, 2xy / r)` |
| Polar | `(θ / π, r − 1)` |
| Handkerchief | `r (sin(θ + r), cos(θ − r))` |
| Heart | `r (sin(θr), −cos(θr))` |

`r = length(x, y)`、`θ = atan2(x, y)`です。原論文の角度の定義に合わせ、通常の極座標と引数の順を区別します。
原点ではθ=0とし、Spherical・Horseshoeの分母には下限を設けます。
モデルの長さ1を共通空間の0.25へ対応させ、Positionだけを境界で換算します。非線形変換はこのモデル座標で計算します。

## 全体のパラメータ

| パラメータ | 初期値 | 意味 |
| --- | --- | --- |
| Symmetry | 3 | 描画時の回転対称の次数。1〜16の整数です。 |
| Mirror Symmetry | Off | 回転コピーに加えて、Xを反転した点も描きます。軌道自体を変えません。 |
| Scale | 1 | 模様全体の表示倍率。 |
| Rotation | 0 | 模様全体の時計回りの回転。1回転=1です。 |
| Position | `[0, 0]` | 模様全体の位置。共通等方単位です。 |
| Palette | 青→シアン→ピンク→金 | 軌道上の各サンプルの色。共通Color Rampの透明度・補間・色空間に対応します。 |
| Color Phase | 0 | Palette上の色位置を周期的にずらします。周期の継ぎ目を消すにはPaletteの両端を同じ色にします。 |
| Exposure | 2 | 密度へ掛ける倍率。負値は0とし、0では画像を透明にします。 |
| Gamma | 2.2 | 対数圧縮後の密度へのGamma。大きくすると薄い部分が見えやすくなります。最小0.01です。 |
| Seed | 0 | 軌道ごとの開始点と変換選択の乱数列。整数化してu32として使います。 |
| Orbit Count | 512 | 並列に計算する軌道数。1〜4096です。 |
| Iterations | 512 | 1軌道あたりの描画反復数。1〜2048です。 |
| Burn In | 64 | 描画前に捨てる過渡的な反復数。0〜2048です。 |
| Density Resolution | 512 | 正方形の集計格子。256・512・1024・2048から選びます。出力解像度とは独立です。 |
| Density Radius | 0.5 | 集計する領域の半径。共通単位で、初期値ではX・Y各軸±0.5を扱います。 |

Rotationなどへ式`TIME / 10`を指定するとアニメーションできます。変換内のパラメータにも式・キーを使えます。
Scale・Rotation・Position・Exposure・Gammaだけの変更では集計結果を再利用します。
変換・対称性・Seed・Palette・Color Phase・サンプル数・集計格子の変更では、現在の設定から軌道を再生成します。
空の変換リストと全Weight=0は透明画像・密度0を返します。

## 配色と出力

色位置は0.5から開始し、変換を選ぶたびに`(現在の色位置 + 変換のColor Position) / 2`で更新します。
各サンプルでPaletteを評価してから乗算済みRGBAを集計します。色位置の平均を最後にPaletteへ渡す近似は使いません。
Color Phase=0では色位置1をPaletteの末端として保持し、位相が非ゼロのときだけ周期的にwrapします。

点は隣接4セルへ重みを分配し、格子の再構成にも双線形補間を使います。各セルの重みとRGBAは倍率256の固定小数点です。
固定小数点への丸めによる小さな色の誤差がありますが、浮動小数点atomicの加算順序には依存しません。
色と密度の総和を補間した後で平均色を求めるため、空セルの近くで色が二重に暗くなりません。

- **Output**: 乗算済みRGBA。`L = log(1 + Exposure × Density)`、`Intensity = (L / (1 + L)) ^ (1 / Gamma)`を平均RGBAへ掛けます。背景は透明で、Paletteのalphaを保持します。
- **Density**: 色・Exposure・Gammaから独立した確率密度。総試行点数と共通単位でのセル面積で正規化し、サンプル数や対称コピーだけを増やして明るくしません。1を超えることがあります。

Densityは未使用時には確保せず、単独でも描画できます。精度設定に応じてr16float・r32floatを使います。
r16floatの範囲を超えるピークは最大有限値65504へ制限します。大きな密度を保持する場合は32bitのデータ精度を使います。
表示倍率は密度値を変えず、既に求めた場を拡大・縮小します。

## 上限・再現性

回転・鏡映コピーを含め、1回の集計で最大8,388,608点です。上限を超える設定は描画前にエラーにします。
この上限なら、全点が1セルへ集中しても各整数チャンネルがu32の範囲に収まります。
Burn Inを含む軌道のループも固定回数で終わります。数値的に発散した点は決まった乱数列で再出発し、再びBurn Inを満たした点だけを描きます。
領域外・発散・過渡的な点によって失った密度を、残りの点で埋め合わせません。

ヒストグラムは1セル20byteで、Density Resolution=512では約5MiB、2048では約80MiBです。
GPUのbuffer上限を確保前に確認し、超える場合はDensity Resolutionを下げるよう通知します。
解像度・縦横比に関係なく同じ等方座標を使いますが、密度格子の解像度を変えると細部や細い線のピークは変化します。
同じGPU・設定・Seedでは再現可能です。カオス的な軌道なので、GPUや浮動小数点演算の差で細部が変わることはあります。

# Scalar Range Limit

スカラー入力を指定範囲内に収める。Input・Min・Maxは定数またはノード出力で、すべて画素ごとに評価する。初期値はInputとMinが0、Maxが1、ModeがClamp。

| Mode | 動作 |
| --- | --- |
| Clamp | 範囲外の値を近い方の端に固定する。両端を含む。 |
| Wrap | 範囲の幅を周期に繰り返す。下限を含み、上限ちょうどは下限へ戻る。 |
| Ping-pong | 範囲の幅の2倍を周期に往復する。両端を含み、範囲内の値はそのまま返す。 |

MinがMaxを超える画素では、小さい方を下限、大きい方を上限として扱う。両者が等しい場合は、すべてのModeでその値を返す。負の入力や複数周期離れた入力にも対応する。範囲自体を0〜1には制限しない。

例えば0〜1の範囲では、1.25はClampで1、Wrapで0.25、Ping-pongで0.75となる。−0.25はそれぞれ0、0.75、0.25となる。

Remapが入力範囲から出力範囲への変換を行うのに対し、このエフェクトは範囲内の値を維持しながら境界での扱いを指定する（Wrapの上限を除く）。

## 解像度・実行

主入力はInput。自動解像度はInput・Min・Maxの全接続から画素数が最大の入力を選び、同数ならこの順で優先する。すべて定数なら描画先を使用する。Modeの切り替えでは解像度を変えない。

入力ごとのfit・wrap・filterを利用し、同じ出力位置で取得したスカラー値を加工する。入力接続のwrapは画像の参照座標を扱い、このエフェクトのWrapは数値の範囲を扱う。

出力は`enable32bitDataTextures`に従う`r16float`／`r32float`。GPUで1パス描画し、Modeごとのパイプラインを必要時に作成・キャッシュする。時刻や描画履歴には依存しない。

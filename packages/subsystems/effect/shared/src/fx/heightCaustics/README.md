# Height Caustics

高さ場の表面で平行光を屈折させ、平らな受光面へ届く光の分布を生成する。水底の光の網目、ガラス越しの集光、凸凹した透明面からの照明などに使う。流体の運動は計算せず、形と動きは上流の高さ場で指定する。

## 使い方

1. Noiseなどのscalar出力をHeightへ接続する。画像・文字を使う場合は、輝度などをscalarへ変換して接続する。
2. Height ScaleとReceiver Distanceを調整する。前者は表面の起伏、後者は光が集まるまでの距離を変える。
3. 集光が細かすぎる場合はSoftnessを増やす。粒や格子状の模様が残る場合はSamplesを増やす。
4. Outputを照明画像として合成するか、Irradianceを別のエフェクトのscalar入力へ接続する。

最初はNoiseの密度を低めにし、Height Scaleを0.02〜0.06程度から調整するとよい。Heightが一様なら、真上からの照明では一様な画像になる。アニメーションはNoiseなどの上流で作る。

## 入出力・パラメータ

| パラメータ | 初期値 | 意味 |
| --- | --- | --- |
| Height | 0 | 表面の高さを表すscalar場。定数とノード接続に対応 |
| Height Scale | 0.05 | Heightに掛ける高さ倍率。長辺全体=1の共通単位。負値で起伏が反転 |
| Receiver Distance | 0.2 | 高さ0の基準面から受光面までの距離。共通単位 |
| IOR | 1.333 | 空気から入る透明媒質の屈折率。1で法線による屈折なし |
| Light Angle | 0 | 光源の方位。右が0、下が0.25、時計回りに1周 |
| Light Elevation | 0.25 | 光源の仰角。turn単位で、0が水平、0.25が真上 |
| Light Color | 白 | カラー出力の光の色と不透明度。Irradianceには影響しない |
| Light Intensity | 1 | 両出力へ掛ける光の強度 |
| Softness | 0.004 | 受光面のGaussianの標準偏差。共通単位。0で追加のぼかしなし |
| Samples | 512 | 長辺方向の光線サンプル数。整数へ丸め、32〜1024に制限 |

- **Output**: 乗算済みRGBAの照明画像。初期値のalphaは1で、光が届かない場所は不透明な黒。Light ColorのalphaをRGBAへ適用する。HDRの集光を保持する場合は、画像の中間形式に16bit floatを使う。
- **Irradiance**: 色とalphaから独立した照度のscalar場。真上から強度1の光を平面へ当てると1になる。集光箇所は1を超える。未接続なら出力テクスチャを確保しない。

Height以外は空間全体で共通の値だが、式・automationで変更できる。自動解像度はHeightの接続を基準にし、定数なら描画先の解像度を使う。

## モデル

共通座標を`(x, y)`として、表面は`z = Height(x,y) * Height Scale`、受光面は`z = -Receiver Distance`とする。+Zは画面手前。XYの等間隔格子で高さと勾配を読み、法線`normalize(-dh/dx, -dh/dy, 1)`を求める。高さの読み取りは既存の入力のFit／Wrap／Filterに従い、勾配はHeight Lightingと同じ双線形補間の偏微分を用いる。

空気の屈折率を1とし、Snellの法則で屈折した光線と受光面の交点を計算する。各サンプルの光量は入射方向の表面への投影面積を反映する。受光位置を周囲4セルへ分配し、同じ受光領域へ到達した光を加算する。集光による明るさを、到達した光の量として扱う。

内部格子の長辺をSamples、短辺を描画領域の比率に合わせる。出力解像度を変えても同じ格子と共通距離を使うため、光の位置と広がりは変わらない。最終出力へは双線形補間で拡大・縮小する。極端に細長い領域の短辺は最低1セルとなる。

## 精度・パフォーマンス・制約

- 光の集計は32bit unsigned整数の固定小数（小数部16bit）の飽和加算。実行順に依存せず、同じ入力と設定から同じ結果を得る。時刻・前フレーム・乱数・フレーム間蓄積は使わない。
- 集計セルの照度は約65536で飽和する。固定小数へ変換する前の各光線の光量も65504以下に制限する。極端な集光では光量を保存できず、Softnessで後からぼかしても飽和前の光量は復元できない。
- 光線の到達位置は常に32bit floatで保持する。Gaussianの中間照度とIrradianceの形式は`enable32bitDataTextures`に従う。16bitの照度とカラーのRGBは最大有限値65504で制限する。
- Samplesを増やすと計算量・メモリ使用量は概ねその二乗で増える。Softnessを増やすとGaussianの参照回数も増える。強い拡散や鋭い起伏は有限の光線数で格子模様・粒が残ることがある。
- 光線を開始する範囲と受光範囲は描画領域内だけ。領域外からの光は追加せず、領域外へ届く光は捨てる。傾いた照明では端が暗くなる。入力のWrapは高さの参照だけに作用し、光線や受光面を周回させない。
- Gaussianも領域外を0として扱い、端で重みを再正規化しない。Softnessを増やすと端から光量が失われる。
- 光が当たらない向きの表面、受光面より下の表面、屈折後に受光面へ向かわない光は寄与しない。表面自身による遮蔽・再交差は検査しない。
- 単一の屈折界面と平らな受光面の近似。Fresnel反射・吸収・色分散・回折・多重散乱・ガラスの裏面は扱わない。光線の到達後のGaussianは受光面上の広がりであり、面積光源を追跡するものではない。

Receiver Distance・Light Intensityの負値は0、IORは1〜10、Light Elevationは0〜0.25、Softnessは0〜0.05に制限する。極端な式の結果で計算を発散させないよう、Height Scaleは±1000000、Receiver DistanceとLight Intensityは1000000以下に制限し、非有限の数値設定は初期値へ戻す。

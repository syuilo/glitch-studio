# Map Transition

スカラー場を「切り替わる順序」として読み、AをBへ置き換える。Mix (Color)のようにMapの値をそのまま混合率として使うものではない。

## パラメータ

- `inputA` / `inputB`: 画像または色。未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外は0〜1へclampする。scalarノードを接続すると画素ごとに進捗を指定できる。
- `map`: 小さい値から先に切り替わるscalar場。0〜1へclampして使い、毎フレームの最小・最大値では正規化しない。定数のMapは画面全体を同時に切り替える。
- `softness`: Map値域上で測った遷移の全幅。距離単位ではないためSize Referenceは持たない。負値は0として扱う。
- `reverse`: Mapの切替順を逆にする。A→Bの関係は変わらない。
- `antiAlias`: Mapと進捗から求めた閾値差の画素微分を最小遷移幅として使う。一様な進捗ではMapの勾配だけを使い、定数Mapでも空間的な進捗が作る輪郭を滑らかにする。離散セルなどを硬く切り替える場合は無効にできる。

## Softnessと端点

有効幅を `w`、反転適用後のMap値を `m`、進捗を `p` とすると、`w > 0`のMaskは `smoothstep(0, 1, p + (p - m) / w)`。閾値を `-w/2` から `1+w/2` まで動かすのと等価で、Map値が0/1でも進捗の端へ連続的につながる。大きいSoftnessでも端点の残像を生じない。

`softness = 0`でAA幅も0なら、進捗がMap値以上になった瞬間に切り替わる硬い閾値となる。同じMap値を持つ領域は一斉に切り替わり、Map値0/1の硬い切替には端点での不連続も含む。進捗0/1では常に完全なA/Bを返す。

静止Mapと一様な進捗では置換率が単調に増える。進捗やMap自体を時間変化させた場合は、その入力値をそのまま反映し、履歴に依存しない。

## 出力と用途

- `output`: premultiplied alphaのlinear sRGBでA/Bを補間。HDR・負値・透明度を保持する。
- `mask`: Bへの置換率。画像の色やalphaに依存しないscalar出力。16bit / 32bitに対応する。
- 両出力を遅延確保し、Mask単独では画像出力を作らず色を読まない。
- 自動解像度はA・B・Mapを参照し、Maskだけを使う場合にもMapの解像度を利用できる。各入力のFit / Wrap / Filterは接続設定に従う。

NoiseならまだらのDissolve、輝度ならLuma Wipe、距離場なら形状から広がるWipeになる。Mapの範囲変換・曲線調整は上流の数値加工に任せ、エフェクト固有の正規化やイージングは重複して持たない。

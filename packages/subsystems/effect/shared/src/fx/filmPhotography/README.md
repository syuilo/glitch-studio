# Film Photography

仮想カラーネガの分光感度・現像応答・色素吸収を編集し、印画紙へ焼き付けた写真の色を計算する。
実在銘柄の再現プリセットや完成画像に適用するRGBカーブではない。撮影光の推定から、感光、現像、
Beer–Lambert則による吸収、プリント、反射光の観察までを一つのエフェクト内で扱う。

## 処理の順序

1. 入力のpremultiplied linear sRGBを未乗算へ戻し、非負の入射スペクトルを推定する。
2. 入射光と三つの感光層の分光感度を積分し、Film Exposureを乗算する。
3. 各層の露光量から現像後の色素量を求める。
4. ベースと三色素の光学濃度を加算し、ネガの分光透過率を求める。
5. 黒体のプリント光源・色補正フィルター・ネガを通った光で印画紙を露光する。
6. 印画紙の現像応答から色素量を求め、白い反射基材上の色素層の往復吸収を計算する。
7. 固定の観察光下でXYZへ積分し、linear sRGBへ戻して元のalphaを乗算する。

可視域380〜780 nmを5 nm刻みの81点で計算する。現像は非負・単調な現象論的応答であり、
分子レベルの化学反応・現像時間・温度・薬液濃度を解いているわけではない。

## 操作

### 露出

| パラメータ | 既定値 | 意味 |
| --- | --- | --- |
| Film Exposure (EV) | 0 | フィルムへの露光を`2^EV`倍する。増やすとネガが濃くなり、通常は写真が明るくなる |
| Print Exposure (EV) | 0 | 印画紙への露光を`2^EV`倍する。増やすと印画紙が濃くなり、写真が暗くなる |

両方ともスカラー場のノード入力に対応する。内部で±24 EVに制限する。撮影とプリントの露出は
異なる非線形応答の前に作用するため、片方を増やして片方で補っても同じ結果にはならない。

### フィルムの三層

Red-sensitive / Cyan-forming、Green-sensitive / Magenta-forming、Blue-sensitive / Yellow-formingの
三つの構造体は同じ操作項目を持つ。名称は既定の役割であり、中心波長や色素吸収を自由に変更できる。

| パラメータ | 意味 |
| --- | --- |
| Sensitivity Center / Width | 感光特性の中心波長と標準偏差σ。FWHMではない |
| Relative Sensitivity | 当該層の感度をEVで変更。正値ほど少ない露光で色素が生じる |
| Development Gamma | 中間露光における色素濃度の傾き、`D / log10(H)` |
| Maximum Dye Density | 露光によって生成される色素の最大量。Fogは別に加算 |
| Toe / Shoulder Shape | 低露光側／高露光側で端の濃度へ近づく形。中間点の傾きは変えない |
| Fog Dye Density | 無露光でも生成される色素量 |
| Dye Absorption Center / Width | 現像色素の主吸収帯域 |
| Secondary Absorption / Center / Width | 色素の副吸収の相対強度と帯域。理想的でないCMYを表す |

感光スペクトルは基準白に対する応答を1に正規化する。帯域幅を変えても基準白への露光は変わらず、
有彩色への相対的な感度が変わる。感度の絶対倍率はRelative Sensitivityが担当する。
色素の主・副吸収を合算したスペクトルはピーク1に正規化し、色素量1がピーク光学濃度1を表す。
副吸収を変えると主吸収も再正規化されるため、単に全体の吸収倍率が増える操作ではない。

中心波長は380〜780 nm、帯域幅は5〜200 nm、Relative Sensitivityは±24 EV、Gammaは0〜10、
Maximum Dye Densityは0〜8、Toe / Shoulderは0.1〜16、Fogは0〜4、副吸収は0〜1へ制限する。
UIのスライダー範囲より広い値も式・数値入力で指定できるが、この物理・数値範囲を超える値は丸める。
Gamma=0は正の露光で一定の中間濃度、Maximum Dye Density=0はFogだけの層になる。

### ベース・プリント・印画紙

- Film Base: Neutral Densityに波長依存のStain Densityを加える。StainもGaussian吸収で、
  色の加算ではない。これは固定のベース着色であり、実フィルムの露光依存マスクではない。
- Print Light / Filtration: 1500〜20000 Kの黒体光源を使用する。温度変更はY一定で正規化し、
  光量はPrint Exposureで調整する。CMYフィルターは印画紙色素と同じ吸収形状、濃度0〜4。
- Print Paper Response: 仮想印画紙の共通Gamma・最大色素量・Toe・Shoulderを変更する。
  印画紙の分光感度・色素吸収自体は初版では固定。三色素の吸収の和は全波長で1となるため、
  等量の色素が中性濃度を作る。写真用紙の実測プロファイルではない。

ベースのNeutral / Stain Densityは0〜4、中心波長・幅はフィルム層と同じ範囲に制限する。
全ての材料・プリント設定は通常パラメータなので式・キー・automationを使える。
材料パラメータは画素ごとのノード接続には対応しない。

## 応答と校正

各層の色素量は、`x = log10(H / 0.18) + RelativeSensitivity * log10(2)`、
`m = MaximumDensity / 2`、`p = x < 0 ? Toe : Shoulder`として
`tail = m * (1 + Gamma * abs(x) / (m * p))^(-p)`、
`q = Fog + (x < 0 ? tail : MaximumDensity - tail)`とする。無露光では`q = Fog`。
`H = 0.18`かつRelative Sensitivity=0で色素量はFog+最大量の半分となる。

ネガの透過率は`10^-(Base(λ) + Σ q_i * Dye_i(λ))`。
印画紙は白い拡散反射基材上の色素層を垂直に往復する理想化モデルで、反射率は
`10^(-2 * Σ q_i * PaperDye_i(λ))`。多重散乱・表面反射・基材内の吸収は扱わない。

既定材料・既定プリント条件で入力の18%グレーが出力の18%グレーになるよう、印画紙三層への
露光倍率を一度だけ校正する。編集した材料に合わせた自動再校正は行わない。
したがって感度差・色素・ベースの変更は色かぶりや明るさの変化として残る。
入力RGBの1や18%は撮影時の絶対光量を意味せず、この基準に対する相対露光である。

## 分光再構成と限界

RGBから元の入射スペクトルは一意に復元できない。本実装は、D65と等色する滑らかな仮想白色光と、
中心420〜680 nm・幅σ=12 nmの非負Gaussian群を用意する。CIE xy上の凸包を白色点から三角形へ
分割し、各色を白色光と隣接する二基底の非負結合で表す。基底色域内ではXYZを保つが、特に
高彩度色では狭帯域なスペクトルを仮定する。この選択自体がフィルムの発色に影響する。

基準白は三つの広帯域Gaussianの混合をXYZへ合わせた仮想光源で、実際のD65のSPDではない。
観察光も同じ基準白を使う。CIE 1931等色関数はWymanほかの解析近似である。
同じRGBになる現実の光を区別する機能や、照明と物体反射率を分離する機能はない。

- RGBを0〜1へclampせず、HDRの露光量を保持する。
- 負RGBでも基底色域内のXYZは再構成する。基底色域外は白色点から凸包境界へ射影しYを保持する。
- Yが0以下の非物理的入力は無露光とする。
- 通常のJPEG・PNGをlinear化しても撮影時のトーン処理は戻らない。scene-linear素材を基準に使う。
- 材料内部は波長ごとの感度・吸収配列、現像応答として分離している。現在の操作は解析曲線の生成で、
  任意の実測曲線の読み込みUIは持たない。
- 各色の複数感度の副層、層間現像抑制、露光依存マスク、相反則不軌、粒状感、ハレーションは扱わない。
  パラメータの任意の組み合わせに対応する化学物質が実在することは保証しない。

## GPU・透明度

材料変更時のみCPUで分光係数を更新する。入射光の基底に対する感光積分を事前計算し、GPUでは
三角形の混合重みから直接各層の露光を求める。これは選んだ分光再構成に対する線形積分の厳密な
並べ替えであり、完成画像のルックアップではない。ネガ→印画紙と印画紙→RGBは81波長を直接積分する。

画像の入出力はpremultiplied linear sRGB・rgba16float、シェーダーの演算と分光係数はf32。
alphaは保持する。alpha=0のRGBは既存の非線形色調整と同様に変更せず通す。
写真として評価する場合は背景合成後に適用する。出力RGBには色域clampやsRGB encodeを行わない。
履歴・乱数・時刻・画面座標を使わないため、同じ入力の色は解像度・縦横比・描画順序に依存しない。
GPU係数とpipelineはインスタンス所有で、破棄時に解放する。

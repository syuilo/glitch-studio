# Shape SDF

楕円・角丸矩形の境界までの符号付きユークリッド距離を、スカラー場として生成する。内側は負、境界は0、外側は正。塗り・輪郭・色・透明度を含まず、0〜1への正規化・クランプも行わない。

- ShapeはEllipseまたはRectangle。Ellipseの幅・高さを同じにすると円になる。
- Positionは画面中央が[0, 0]、左下が[-1, -1]、右上が[1, 1]。画面外の位置も指定でき、画面端を形状の境界として扱わない。
- Sizeは全幅・全高。寸法・出力距離・Corner Radiusは縦横とも描画領域の高さを1とする。距離0.1は高さの10%に相当し、横方向にも同じ長さを表す。解像度や縦横比を変えても距離の単位と形状の比率を保つ。
- Rotationは形状中心を支点として、1で時計回りに1周。
- Corner RadiusはRectangleにだけ適用し、0から短辺の半分までに制限する。外寸はSizeを維持する。
- 幅・高さのいずれかが非正なら空形状とし、全画素に65504を出力する。この値は16bit/32bit floatに共通の有限な空形状の値であり、実際の距離ではない。
- 初期値はEllipse、中央、寸法[0.5, 0.5]、回転0、角丸半径0。

パラメータは画面全体で共通の値として評価する。式・automationなどによるアニメーションは可能だが、形状パラメータへのノード接続による画素ごとの変更は受け付けない。時刻・過去フレームを直接参照せず、同じパラメータなら同じ距離場を生成する。

保存形式は`enable32bitDataTextures`に従い、`r16float`または`r32float`。有限精度の画素サンプルとして出力するため、補間や後段の変形・演算後も厳密な距離場であることは保証しない。特に楕円は単に円の座標を非等方拡大せず、最近点を数値的に求める。

数学的な距離計算は`@gs/shared/gpu/shape-distance.wgsl`に置き、Timelineのシェイプ描画と共有する。Shape型・Scene・レイヤー・Bindingには依存しない。

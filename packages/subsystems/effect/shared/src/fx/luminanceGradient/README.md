# Luminance Gradient

colorの画像を輝度へ変換し、ガウスぼかしを適用してから、その勾配を2次元のvectorとして出力します。明るくなる方向を向きとし、単位距離あたりの輝度変化が急なほど長くなります。明るさが一定の領域は、白でも黒でもゼロベクトルです。

輝度は作業空間のlinear sRGBから`L = 0.2126 R + 0.7152 G + 0.0722 B`で求めます。sRGB表示値への変換や、RGB・輝度・ベクトルの0〜1への制限は行いません。HDR・負値を保持します。

## パラメータ

| パラメータ | 仕様 | 既定値 |
| --- | --- | --- |
| Input | 定数の色・式・画像のノード接続。定数は全域で勾配0 | 透明な黒 |
| Blur Radius | ガウスぼかしの標準偏差sigma。Size Referenceの基準寸法に対する割合。0以下でぼかしなし | 0.01 |
| Size Reference | Blur Radiusの基準寸法。Height・Width・Short Side・Long Side | Long Side |
| Strength | 勾配に掛ける倍率。負値で暗くなる方向へ反転し、0で出力0 | 1 |
| Normalize | ゼロ以外の勾配を長さ1に揃えてからStrengthを掛ける。ゼロはそのまま | オフ |
| Alpha Mode | Include Alpha / Ignore Alpha | Include Alpha |

Include Alphaは乗算済みRGBから輝度を求めます。通常の透明画像では黒背景に合成した明るさに相当し、透明度の変化も勾配へ含みます。alpha=0かつRGBが非ゼロの発光成分も保持します。

Ignore Alphaは入力画像の各画素を未乗算RGBへ戻してから輝度を求めます。同じ色でalphaだけが変わる半透明領域は一様な輝度になります。alphaが0の画素は、発光成分も含め輝度0と定義します。完全透明な場所の隠れた色の推定・補完は行わないため、完全透明との境界には勾配が生じる場合があります。alphaで正規化したぼかしではなく、変換済みの輝度をぼかします。

## 座標・サンプリング

出力は+Xが右、+Yが上です。長辺全体=1の共通座標に対する偏微分を返すので、同じ傾斜は解像度や縦横比によらず同じ値になります。Size Referenceを変えても勾配の単位は変わりません。ベクトルの長さは輝度の変化率であり、変位として利用する場合はStrengthや接続先のAmountで調整します。

入力の原寸で輝度へ変換し、水平・垂直に分離したガウスぼかしを行います。ぼかしの範囲は各軸±3sigmaです。通常は原寸の画素間隔以下で標本化し、大きい範囲では各軸最大65点に制限します。有限個のサンプルによる近似なので、大きい半径で細かな模様が残る場合があります。

Fitは最終的な輝度場の参照時に適用し、ぼかしのsigmaを事前に入力座標へ換算します。Stretchで縦横比を変えた場合も、出力側で等方的なぼかしになります。原寸で処理するため、Coverで画面外に隠れた色もぼかしへ寄与します。

各パスで入力のWrapを使います。Clampは端の延長、Repeatは繰り返し、Repeat Mirroredは鏡像、Transparentは領域外の輝度0です。中間画像は原寸の領域に保持するため、Transparentで素材の矩形の外へぼかしの裾を拡張する処理は行いません。境界の勾配を含めて滑らかにしたい場合は、素材の内側に透明な余白を用意します。

最終的な勾配は、共通の`readGradient_luminance`で補間された輝度場を解析的に微分します。入力のFilterがLinearの場合に勾配を計算し、Nearestの場合はScalar Gradientと同じく0です。ぼかしなし・Include AlphaはRGB toのLuminanceとScalar Gradientを組み合わせた処理に対応しますが、輝度変換を入力原寸で行うため、異なる解像度への再描画を挟む構成とは画素単位の結果が異なり得ます。

## 実行・利用例

自動解像度はInputに従い、定数の場合は描画先に従います。出力はデータ精度設定に応じた`rg16float` / `rg32float`、中間の輝度は`r16float` / `r32float`です。画像の色精度を32bitへ変更するものではありません。

画像入力では輝度変換・水平ぼかし・垂直ぼかし・勾配の4パスを使い、Blur Radiusが0以下の場合はぼかしの2パスを省略します。定数入力は中間画像を新たに確保せず、出力の1パスだけです。中間画像は入力寸法が変わったときに再確保し、破棄時に解放します。GPU上で同期的にコマンドを記録し、統計・タイル描画に対応します。時刻・描画履歴・乱数への依存やCPUへの読み戻しはありません。

- Vector Field Visualizationへ接続すると、方向と大きさを矢印で確認できます。
- Vector Displacementへ接続すると、輝度を高さとした傾斜に応じて画像を変形できます。
- Vector MathのRotateで0.25 turn回すと、等輝度線に沿うベクトルになります。
- Vector Lengthへ接続すると、明暗の境界の強さをスカラー場として取り出せます。

## 検証

`CHROME_PATH`を設定して、リポジトリルートから`node --test packages/subsystems/effect/shared/test/luminance-gradient.gpu.test.mjs`を実行します。16bit/32bit、一定色、共通単位の傾斜、RGBの輝度係数、HDR・負値、透明度、正規化、ぼかし、Size Reference、Fit/Wrap/Filter、入力寸法や時刻の変更後の再現性を実際のWebGPUで検証します。

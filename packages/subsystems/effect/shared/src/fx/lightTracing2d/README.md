# 2D Light Tracing

入力画像を2Dの光源・遮蔽物として扱い、光の広がりと影を描画する。出力は黒背景の不透明な画像。入力図形の色と輪郭は保持し、透明領域に照明を加える。

- 完全透明な画素は空間。不透明な色は発光・遮蔽し、不透明な黒は発光せず遮蔽する。
- 発光量は乗算済み入力のRGBを使う。αを再乗算しない。半透明な画素はαに応じて発光が弱くなるが、光の透過は計算しない。
- Alpha Threshold以上かつαが0より大きい画素を物体とする。閾値未満の画素は照明計算では光源・遮蔽物にならないが、元の図形として出力には残る。
- Emission Strengthは周囲へ放つ光の強度。入力図形自体の色は変えない。0では入力を黒背景に重ねた結果になる。
- Absorptionは距離に対する指数減衰。距離の単位は画面の最短辺を2とする等方的な座標で、解像度に依存しない。
- Ray Countは各点の方向サンプル数。増やすとノイズが減り、負荷が増える。Max Stepsは各レイの最大反復数で、足りない場合は本来届く光が欠ける。
- Resolution Scaleは照明の計算解像度だけに適用する。入力図形・遮蔽物・距離場は出力解像度を維持し、細い線を縮小で失わない。拡大時は補間元までの遮蔽を確認する。ただし狭い隙間など、計算点が置かれない領域の照明は再現できない。
- Seedは方向サンプルの乱数を変える。時刻・描画回数・前フレームを使わず、同じ入力と設定なら同じ結果になる。

GPUでは入力とseedを同時に描画し、JFA+1で最寄りの物体画素を求める。その結果から歩幅用の距離場を作り、各照明計算点から層化した方向へsphere tracingを行う。物体付近では画素境界を順に越え、最初に当たった物体の発光色を取得する。レイが画面外に出た場合は終了し、入力接続のwrap設定で照明空間を周回させない。

seedは補間せず整数画素で読む。16bit floatでも大きな画素座標を正確に保持するため、座標を1024進数の上下2桁へ分割してRGBAに保存する。距離場と照明場を含む内部データの保存精度は`enable32bitDataTextures`、入力画像の中間描画と最終出力は`intermediateTextureFormat`に従う。

JFAは近似距離変換であり、追加パスと控えめな歩幅でも全ての形状で光漏れがないことを保証しない。単一フレームの直接照明だけを計算し、反射光・屈折・多重散乱・フレーム間蓄積は扱わない。周囲の光の場そのものを表示する演出的な2D照明であり、3D空間の空気の散乱を解くものではない。

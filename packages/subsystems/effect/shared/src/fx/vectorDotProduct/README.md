# Vector Dot Product

2つのvector入力A・Bから`A.x * B.x + A.y * B.y`を画素ごとに計算し、scalarの場として出力します。定数・ノード接続に対応し、両入力の初期値は`[0, 0]`です。

内積は負値や1を超える値もそのまま出力し、方向の正規化や値域の制限は行いません。同じベクトル場を両入力へ接続すると長さの二乗になります。単位ベクトルとの内積はその方向への成分を取り出すために利用できます。

Vector Mathは常にvectorを出力し、このエフェクトは常にscalarを出力します。出力型ごとにエフェクトを分けることで、内積を常にscalarのポートへ接続できます。

主入力はAです。自動解像度はA・Bの接続のうち画素数が最大の入力に従い、同数ならAを優先します。すべて定数なら描画先を使用します。各入力のfit・wrap・filterを利用します。出力は`enable32bitDataTextures`に従う`r16float`／`r32float`です。GPUで1パス描画し、時刻や描画履歴には依存しません。

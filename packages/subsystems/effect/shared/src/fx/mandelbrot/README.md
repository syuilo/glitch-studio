# Mandelbrot

`Reference Center`のReal・Imaginaryを十進文字列で指定し、`View / Center Offset`を加えた点を表示の中心にします。Reference CenterはJavaScriptのnumberへ変換する前の桁を保存します。通常のパン・カーソル位置を固定したズーム・式・キーフレームは、既存のViewで操作できます。

深い場所を指定するときはReference Centerへ対象の座標を入力し、Center Offsetを`[0, 0]`にしてください。Center Offsetは通常の数値なので、大きな移動量を蓄積した状態では、それより極端に小さなパンを表現できません。基準中心の自動的な書き換えは、式・キーフレームの意味を変えるため行いません。

Zoomの操作範囲は0.1〜1e30、描画側の範囲は0.001〜1e300です。Maximum Iterationsは1〜65536回です。高精度化と反復数は別の設定であり、有限回で未発散だった点を集合の内部とは断定しません。

## 描画

Zoomが64未満では通常のf32直接反復を使います。それ以上では、表示の中心についてCPUで高精度の基準軌道を準備し、GPUで画素ごとの差分を反復します。

通常描画と高精度描画のpipelineは分け、通常描画からは多倍長演算をコンパイル時に除きます。高精度描画は初回のシェーダーコンパイルにも時間がかかります。描画負荷は画素数・反復数・AA・場所に依存するため、プレビュー解像度とMaximum Iterationsを調整してください。

自動タイルレンダリングの計算量ヒントは、描画と共通の反復数（最大65536回）にAAの標本数（1または4）を掛けます。Reference Centerは十進文字列のまま学習条件に含め、基準中心・View・通常／摂動の切替などが変わった場合は再計測します。通常描画と高精度描画の速度比を固定値で仮定せず、それぞれの実測で調整します。CPUで準備する基準軌道のprecisionBitsは、GPUの固定48bit演算に対する計算量へ加算しません。Coordinate Offsetをテクスチャから読む場合は、入力内容の変化を識別できないためヒントを返しません。

```text
Z[n+1]  = Z[n]² + C
dz[n+1] = 2 Z[n] dz[n] + dz[n]² + dc
```

基準軌道はBigIntの二進固定小数点で計算します。精度はZoom・長辺の画素数・最大反復数から決め、最低128bitと余裕の桁を確保します。基準中心の各成分は±1e12以内です。十進文字列は符号・小数・指数表記を受け付け、仮数と十進指数の大きさはそれぞれ4096桁・4096以内です。

GPUでは実部・虚部をそれぞれ48bitの仮数と整数指数に分けます。加算・乗算・丸めはu32の整数演算で行い、WGSLの浮動小数点の再結合やsubnormalの扱いに依存しません。画素間隔をf32に実体化せず、1e300のような倍率でもアンダーフローを防ぎます。最初の画素位置・回転も48bitで計算し、摂動へ渡す前の座標誤差を抑えます。

基準軌道との打ち消しが強い場合と、基準点が先に発散した場合にはZ0へrebasingします。発散半径との差もCPUで高精度に求め、R=2を僅かに超える値を丸めで未発散にしないようにしています。TIAと最終的な色・ノルムの計算にはf32を使います。有限の精度と反復数での描画であり、全ての境界で数学的な正確さを保証するものではありません。

## 準備と出力

基準軌道の計算は`prepare()`で開始し、loading・ready・errorを通知します。256反復ごとにワーカーへ制御を戻し、View変更・AbortSignal・破棄で古い要求を中断します。完了済みの軌道は直近2条件を保持し、同じ中心・精度・反復上限・発散半径では再利用します。色・回転・Coordinate Offsetの変更だけでは再計算しません。

TIAは各反復の軌道を使うため、Series ApproximationやBLAによる反復の省略は行いません。既存のRamp、透明度、固定4点AA、未発散標本を除いた数値平均を維持します。Escape IterationsとSmooth Iterationsの出力は、大きな反復値の区別と有限範囲を保つため常にr32floatです。他のデータ出力はデータ精度の設定に従います。

基準軌道は入力だけから決定します。時計・描画順・前フレームには依存せず、キャンセル済みの結果は公開しません。

## 検証

`test/mandelbrot.test.mjs`で解析的な周期軌道・十進中心の桁・準備の競合と中断を確認します。`CHROME_PATH`を設定した`test/mandelbrot.gpu.test.mjs`では、十進350桁の直接反復を独立した参照解として、実際のWebGPUの発散回数・Smooth Iterations・TIA・AA・疎な出力を確認します。整数演算自体もBigIntの厳密な加算・乗算と比較します。`MANDELBROT_BENCHMARK=1`を追加すると、128x72での初回準備を含む描画と再描画の経過時間を出力します。

# Decoder Corruption

空間予測と残差の復元を意図的に食い違わせ、動画の復号エラーのようなブロック崩れ、色の破綻、模様の引き伸ばしを作る。実際の圧縮ビット列や特定のコーデックを再現するものではない。現在の入力と設定だけで描画し、過去のフレームや描画順には依存しない。

## 処理と責務

- `_def_.ts`：エフェクトと設定項目。既存のglobから自動登録される。
- `partition.ts`：再同期区画、四分木によるブロック分割、復号順序の作成。画素・GPU・上位ドメインの状態を参照しない。
- `_impl_.ts`：仮想画像の寸法、入力種別ごとのpipeline、GPUバッファ、描画手順の管理。
- `common.wgsl`：uniform、サンプルの型、色変換、決定的な乱数。
- `capture.wgsl`：入力の面積サンプリングとYCbCrへの変換。
- `decode.wgsl`：予測方式の選択、残差の加工、復元済みの隣接画素からの誤差伝播。
- `output.wgsl`：復元した色の補間、細部の合成、元のalphaを保持した出力。

他のエフェクトの実装には依存しない。Visual Moduleとタイムラインのエフェクトレイヤーから、通常の画像加工エフェクトとして使用できる。

## 座標と分割

`Maximum Block Size`は、最大の予測ブロックの一辺を画面短辺の百分率で指定する。最大ブロックは仮想画像上の16×16サンプルで、`Subdivision Levels`は0〜4段階。8×8、4×4、2×2、1×1へ四分割でき、最小の一辺は最大ブロックの1/16となる。`Block Split Probability`は各親を分割する確率。分割は入力の内容には依存せず、座標・寸法・Seedから決まる。

仮想画像の論理寸法はアスペクト比を保った浮動小数点の値で保持する。中央の再同期区画の中心を画像中央へ固定し、画像を覆うまで両側へ同数の区画を追加する。区画数を常に奇数に保つため、Block Sizeを変更して区画数が増減しても格子が半区画ずれない。葉の識別子も中央区画からの相対座標で作り、中央付近の分割や乱数パターンを維持したまま拡縮する。

計算領域だけを区画単位で広げ、四辺の不足部分は画像端の色で埋める。取得と出力は同じ中央基準の座標変換を使う。出力解像度やプレビュー倍率によって、ブロックの相対寸法や分割を変えない。

取得時の面積サンプリングは、入力の実効解像度とfitから分割数を求める。各軸の上限は8であり、極端な縮小に対する厳密な積分ではない。取得・出力のどちらも生成入力関数を使い、定数・テクスチャの両方で入力接続のfit/wrap/filterを適用する。fitの基準は仮想画像ではなく実際の出力寸法。

## 予測と誤差の伝播

`Resync Width`と`Resync Height`は、再同期区画の寸法を最大ブロックの個数で指定する。区画ごとに1 workgroupを割り当て、その中だけを順番に復号する。四分木の葉は左上・右上・左下・右下の順に処理し、上辺・左辺の必要な画素が必ず復元済みになるようにする。

区画の上辺・左辺では元画像を参照するため、別のworkgroupの完了順には依存しない。区画内では葉を復号するたびにstorage barrierを通し、次の葉から書き込み結果を読めるようにする。区画ごとに破損区間の状態も初期化する。

予測は横・縦・周辺の平均色・平面状の4種類。`Prediction Mode`がAutomaticなら、元の入力上の最大4×4点で輝度・色差の予測誤差を比較して方式を選ぶ。1×1・2×2の葉ではその葉の全画素を使い、同じ画素の重複評価はしない。固定指定の場合も、正しい残差を作る側と復号側は最初に同じ方式を使う。

基本の復元は`元画像 − 元の周辺画素からの予測 ＋ 復元済みの周辺画素からの予測`。破損のないブロックでも、周辺がすでに壊れていればその誤差が入る。`Prediction Error Retention`は、周辺画素の誤差を予測へ引き継ぐ割合。0なら周辺の誤差を引き継がず、1なら減衰させない。

## 破損と復旧

`Corruption Burst Probability`は、破損区間の外で各葉が新しい破損を開始する確率。`Burst Length`を中心とした約0.5〜1.5倍の葉数だけ、共通の破損設定を継続する。区画の終端で残りは打ち切られる。

- `Prediction Mode Error Probability`：破損開始時に予測方式を食い違わせる確率。選ばれた方式から1〜3種類ずらすため、破損時は必ず別の方式になる。
- `Reference Shift`：予測に使う上辺・左辺の参照位置を、各葉の一辺を単位としてずらす。参照はその辺の中で制限し、端を引き伸ばす。
- `Luminance Error`・`Chroma Error`：破損の開始時だけ、輝度・色差へ誤差を注入する。その後は隣接画素を使う予測によって伝播させる。
- `Residual Corruption Mode`・`Residual Corruption`：残差の欠落・符号反転・増幅を選び、元の残差からその状態へ補間する。Mixedは破損区間ごとに方式を選ぶ。
- `Residual Noise`：破損中の葉へ、仮想画像上の2×2サンプルごとに輝度・色差の誤りを加える。
- `Block Recovery Probability`：葉を元画像から復元し直す確率。破損区間を終了し、その葉への周辺からの誤差も断ち切る。他の場所からの伝播まで止めるものではない。

乱数は座標・ブロック寸法・Seedと用途ごとのsaltで決める。時間変化にはSeedなどへの式・オートメーションを使う。フレーム番号や経過フレーム数で状態を更新しない。

## 細部と透明度

元のサンプルはYCbCrとcoverageを1画素16バイト、復元サンプルはYCbCr・葉の寸法・残差倍率を1画素32バイトのf32/u32 storage bufferで保持する。色差は0を中心とする符号付きの値。復元時に輝度を0〜1、色差を−0.5〜0.5へ制限し、誤差の発散を抑える。

`Preserve Input Detail`は初期状態で有効。復元した仮想画像へ`元の高解像度画像 − 未圧縮の仮想画像`を加える。残差を壊した葉では、この高解像度の差分にも同じ残差倍率を掛ける。欠落させた細部をそのまま戻したり、反転した残差へ正常な細部を重ねたりしないための処理。

補間は同じ葉の内側に制限し、異なるブロック間の破損をぼかさない。比較する未圧縮画像にも同じ補間を適用する。細部保持を無効にすると、仮想画像を復元・拡大した色をそのまま使う。

取得時はpremultiplied RGBAを平均してから色を取り出す。周辺の誤差を参照するときは元のcoverageでも重み付けし、透明部分の破損色を伝播させない。最終出力のalphaは元の入力位置の値を保持し、RGBの復元後に一度だけpremultiplyする。

`Corruption Burst Probability`が0なら、取得・復号を省略して元の入力を返す。

## 調整の例と計算量

- 広いピンク・緑の変色：Chroma ErrorとPrediction Error Retentionを上げ、Burst Lengthや再同期区画を大きくする。
- 横方向へ伸びた帯：Prediction ModeをHorizontal、Residual Corruption ModeをDropにし、Residual CorruptionとReference Shiftを上げる。
- 細かなブロック崩れ：Subdivision LevelsとBlock Split Probabilityを上げ、Residual Noiseを加える。
- 正常な小領域が混ざる映像：Block Recovery Probabilityを上げる。

最大ブロックを小さくすると仮想画像全体のサンプル数が増える。細分化を増やすと予測選択と同期の回数、ブロック記述バッファの容量が増える。記述バッファは現在指定された深さでの最大葉数だけを確保し、浅い設定で4段階分の容量を予約しない。再同期区画を大きくすると1 workgroupの逐次処理が長くなる。GPUバッファやdispatchの上限を超える設定は描画エラーとし、出力解像度によって精度を黙って落とす処理は行わない。

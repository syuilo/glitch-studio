# Streamlines

現在の`Vector`のベクトル場を固定し、格子状のseedから前後へ追跡した流線を描きます。時間とともに移動する粒子の軌跡ではありません。描画ごとに計算を完結し、履歴・時刻・フレームレートを暗黙に参照しません。

## 設定

長さ・間隔・太さは、Size Referenceで指定した基準寸法を1とする単位です。既定値はLong Sideで、例えばLine Widthの0.003は基準寸法の0.3%です。各図形の描画と追跡を同じ座標で行い、解像度や縦横比で線幅・矢尻を歪ませません。

- `Vector`: 定数・式・ベクトル場の入力。接続のfit・wrap・filterは共通の入力参照で維持します。自動解像度もこの入力に従います。
- `Seed Density`: 基準寸法あたりのseed数。1〜64の整数で、もう一方の軸にも同じ間隔でseedを置きます。seed配置は中央基準で、乱数や履歴を使用しません。1なら中央のseedを含みます。
- `Maximum Length`: seedから片方向へ追跡する最大距離。前後を合わせた最大長はこの値の2倍です。
- `Step Size`: RK2による追跡の刻み幅。最小0.00001で、方向を正規化して一定距離ずつ進みます。小さくすると細かな曲がりを追いやすくなります。
- `Maximum Steps`: 片方向の最大ステップ数。1〜2048で、距離の上限より先にこの回数に達した場合も追跡を終了します。
- `Minimum Magnitude`: 元のベクトルの大きさがこの値以下なら追跡を停止します。0では厳密なゼロだけが停止対象です。中点で停止域や90度以上の方向反転を検出した場合も、その刻みで追跡を終了します。急な曲がりが途切れる場合はStep Sizeを下げてください。
- `Line Width`: 線・点の太さ。0なら出力は透明です。
- `Arrow Spacing`: 流線上の矢尻の間隔。最小0.001で、seedから前後とも半間隔の位置を起点に配置します。後方へ追跡した部分の矢尻も、元のベクトルの向きを示します。
- `Arrow Size`: 矢尻の長さ。0なら矢尻を描きません。隣接する矢尻と過度に重ならないよう、Arrow Spacingの40%を上限とします。
- `Maximum Magnitude` / `Ramp`: 各描画位置の元のベクトルの大きさをMaximum Magnitudeで割り、Rampを参照します。同じ流線上でも場の大きさに応じて色が変わります。Maximum Magnitudeの最小値は0.000001です。追跡は方向を正規化するため、この設定は流線の長さを変えません。
- `Overflow Color`: Maximum Magnitudeを厳密に超えた描画位置の色。上限と一致する値はRampの位置1を使用します。
- `Zero Color`: ゼロの位置の色。前後とも追跡できなかったseedは点として描き、厳密なゼロならこの色を使います。停止しきい値以下の非ゼロのseedはRampで配色します。色を透明にするとゼロの点を隠せます。
- `Direction Space`: Vector Componentsでは成分の向きをそのまま使い、(1, 1)は画面上で45度です。Image Displacementでは各軸が−1〜1の座標での変位方向として縦横比を反映します。大きさの配色・停止しきい値は常に元の成分で計算します。

## 描画と制約

1. compute shaderでseedごとに前後を独立に追跡し、折れ線の座標と有効点数をstorage bufferへ保存します。画面外へ向かう最後の区間は画面端で切り、そこで終了します。
2. 各線分・矢尻・停止したseedを、距離に基づくアンチエイリアス付きの被覆マスクへ描画します。MAX合成で和集合を取り、継ぎ目や同じ経路の重複で透明度を累積させません。
3. 被覆マスクのある画素だけでVectorを再参照して配色し、乗算済みRGBAを出力します。色は画素位置の場を読むため、太い線では幅方向にも色が変化する場合があります。ゼロのseedの点には専用色を使用します。

入力参照はcomputeと配色の両方でLOD 0です。被覆率は浮動小数点の場ではなく8bit RGBAマスクに保存します。CPUへGPUデータを読み戻しません。

格子状のseedは流線自体の均等配置を保証しません。同じ流線を複数回たどることや、線の密集・未描画の領域が生じる場合があります。近接線の抑制や閉路検出は行わず、最大距離・最大ステップ数で計算を制限します。閉じた場では同じ経路を周回することがありますが、被覆率は累積しません。線の密度や総延長はベクトルの大きさを表しません。

点bufferは`seed数 × 2方向 × (有効な最大ステップ数 + 1) × 8byte`です。設定変更では容量が不足したときに拡張し、有効点数を毎回書き直します。GPUのbuffer・dispatch・draw上限を超える設定はエラーにします。密度や最大ステップ数を下げるなどして調整してください。

# JPEG glitch

8×8 DCTの係数を加工してJPEG破損を模す画像エフェクト。実際のJPEGバイト列を生成・破損・復号する処理ではなく、量子化係数と復号時の誤りをモデル化する。入力は通常の`ShaderInput`で、定数・テクスチャ・入力接続のfit/wrap/filterに対応する。

## 処理と責務

- `_def_.ts`：エフェクトとパラメータの定義。既存のglobによって自動登録される。
- `_impl_.ts`：仮想解像度、入力種別ごとのpipeline、計算バッファと描画手順を管理する。
- `common.wgsl`：uniform、DCT基底、Annex Kの量子化表、ジグザグ順、MCU構成、決定的な乱数。
- `encode.wgsl`：入力の面積サンプリング、YCbCr変換、色差の間引き、細部保持用の未圧縮サンプルの保存、DCT・量子化。
- `scan.wgsl`：MCUの走査順でDC誤差・配置ずれを持続させ、再同期区間の先頭で初期化する。
- `decode.wgsl`：配置ずれによる係数の参照先変更、AC破損、DC誤差の加算、逆量子化・IDCT。
- `output.wgsl`：復元した成分の補間・RGB変換、細部の合成と、元のalphaを使った出力。

係数と復元した成分はf32のstorage bufferで保持する。計算途中の係数は符号付きであり、通常の画像用の値域を超えるため、画像用の中間テクスチャには保存しない。画像出力は`intermediateTextureFormat`に従う。

## 仮想解像度とMCU

`blockSize`は輝度の8×8ブロックの一辺をSize Referenceの基準寸法の百分率で指定する。既定値はLong Side。例えば2なら、選択した基準寸法は仮想画像上の400サンプルとなる。仮想寸法はアスペクト比を保った浮動小数点の値で、計算領域だけMCU単位に切り上げる。端の不足部分は入力の端を延長する。出力解像度やプレビュー倍率から、ブロックの大きさ・乱数の配置を独立させる。

4:4:4では1 MCUにY・Cb・Crの8×8ブロックを各1個持つ。4:2:0では1 MCUが仮想画像の16×16領域を覆い、Yの8×8ブロック4個と、2×2ずつ間引いたCb・Crの8×8ブロックを各1個持つ。Yは左上・右上・左下・右下の順に走査し、その後Cb・Crを処理する。

入力の実効解像度とfitから、各仮想サンプルを覆う範囲の分割数を求める。premultiplied RGBAを平均してからunpremultiplyし、透明画素の黒が色に混ざることを避ける。分割数の上限は各軸16であり、極端な縮小に対する厳密な面積積分ではない。

GPUバッファまたはdispatchの上限を超える仮想画像は描画エラーとする。出力によってブロックの大きさが変わるフォールバックは行わず、`blockSize`を大きくして計算量を減らす。

## 元画像の細部の保持

`preserveDetails`を有効にすると、元画像へJPEG処理の差分を加え、仮想解像度への縮小で失われる細部を保持する。初期値は無効で、従来の仮想画像を復号する出力を維持する。

比較用の画像には、8bitへの丸め・DCT・量子化より前の成分サンプルを保存する。量子化なしのDCTとIDCTの組み合わせは同じサンプルへ戻るため、追加の変換は不要。比較用バッファは有効時だけ仮想画像全体のサイズで確保する。

復号画像と比較画像の両方へ、同じブロック配置ずれと補間を適用する。さらに、高解像度の元画像も同じMCUの参照元から読み、MCU内の座標を維持する。これにより、移動前の細部がずれた画像に重ならない。RGBの合成は`移動後の元画像 + (JPEG処理後の画像 - 移動後の未圧縮の縮小画像)`で行い、その後に値域制限とpremultiplyを行う。

元画像の細部を残すため、JPEGだけで画像全体を復号した場合と同じ見た目にはならない。量子化・係数破損・DC誤差の差分は保持するが、縮小や色差の間引きによる細部の消失を補う。

## 破損のモデル

DCの発生率は各成分の8×8ブロックごとに適用する。輝度と色差に別々の振幅を設定でき、平均色の誤差を8倍してDC係数の誤差に変換する。伝播が無効ならそのブロックだけに加算し、有効なら同じ成分の後続ブロックへ引き継ぐ。`dcRetention`は同じ成分の次のブロックへ進むごとの保持率で、1なら減衰しない。伝播はDC差分の誤復号を、復元済みDCに対する累積誤差として表現する。

ACの破損はブロックの発生率と係数の発生率を分けて指定する。ジグザグ番号1〜63で対象の出力周波数を選び、欠落・符号反転・増幅・周波数ずれのいずれかを適用する。Mixedでは係数ごとに方式を選ぶ。増幅にはゼロ係数を非ゼロにする誤差も含む。周波数ずれはDCを除く63係数で循環し、加工前の係数を参照する。

配置ずれの発生率はMCUごとに適用する。1回の発生で指定した上限までの正負のずれを加え、そのずれを後続MCUでも保持する。参照は同じ再同期区間内で循環し、輝度と色差をまとめて移す。

再同期が有効なら指定数のMCUごとにDC誤差と配置ずれをゼロへ戻す。無効なら画像全体を1区間として走査する。再同期は状態を戻す処理であり、すでに壊した係数の修復や、その地点での新たな破損の禁止ではない。

乱数はSeedとブロック／MCU番号、用途ごとのsaltだけで決める。機能の切り替えで別機能の乱数位置を変えず、前フレームの履歴や描画回数にも依存しない。時間変化が必要ならSeedなどに式・オートメーションを設定する。

## 透明度と無効化

色だけをJPEGとして処理し、最終出力のalphaは元の入力位置の値を保持する。配置ずれによってalphaは移動しない。RGBを復元してから一度だけpremultiplyし、完全に透明な画素は透明黒として出力する。

Quantizationを無効にすると成分と係数の整数化を省くが、仮想画像へのリサンプリング・色差の間引き・IDCT後の値域制限は残る。`preserveDetails`が無効ならその縮小画像を拡大して出力し、有効なら元画像の細部を加える。入力を完全にそのまま通す場合はエフェクト自体を無効にする。

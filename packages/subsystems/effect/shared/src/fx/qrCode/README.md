# QR Code

文字列をQR Code Model 2へ符号化し、中央に配置した正方形の画像として出力する。Position / Rotationは持たない。

## 符号化と描画

- Contentは空白・改行も含めてそのまま符号化する。空文字は透明出力。日本語・絵文字はUTF-8で扱う。
- Error CorrectionはL / M / Q / H、既定値はM。自動で別の訂正レベルへ引き上げない。
- Versionは0がAuto、1〜40は型番固定。整数以外や範囲外、指定型番の容量超過はエラーを通知する。入力を修正すれば復帰する。内容の切り詰めや別の内容への置き換えはしない。
- `uqr`で符号化した最終マスと描画上の役割を`rg8uint`へ格納する。Rは暗部=1 / 明部=0、Gはセル=0 / 検出パターン=1。1マス1 texel、左上原点・行優先。7×7の検出パターン内の明部も同じ役割を保持し、周囲のseparatorとは区別する。
- 符号化・転送はContent / Error Correction / Versionが変わる場合のみ。画像・色・形状・寸法の変更では再符号化しない。履歴には依存せず、Web書き出しにも符号化処理を同梱する。
- SizeはQuiet Zoneを含む一辺の基準寸法に対する比率。Size Referenceの既定値はLong Side。Quiet Zoneはマス単位の非負整数（四捨五入）、既定値は4。マスは縦横同じ寸法で描く。
- QRコード領域外は透明。明部・余白・中央画像の下地にはLight Colorを使う。色はノード接続可能で、既存のFit / Wrap / Filterに従う。出力はpremultiplied alphaのlinear sRGB・rgba16float。HDR・負値も保持する。

## デザイン

- セルは四角・角丸四角・円・ひし形・斜め連結（↘ / ↗）。Cell Scaleは0〜1、Roundnessは0〜1で最大まで丸める。
- 角丸はIndividual CellsとConnected Cells。Cell Scale=1で接している場合に、Connected Cellsは凸角・凹角を丸め、斜めにしか接しないマスをつながない。Cell Scale<1では隙間を保ち、個々のマスを丸める。
- 検出パターンは7×7の領域全体で描き、外枠・中心それぞれの形・角丸・色を指定する。外枠は7マス、内側は5マス、中心は3マスの寸法を基準とする。
- 斜め連結は、選んだ向きで対角に隣接する暗いセルの中心を丸い端の線分で結ぶ。孤立セルは円。Cell Scaleは線の太さと点の直径をセル幅の比率で指定し、Roundness / Rounded Cornersは使わない。三隅の検出パターンへは連結しない。
- 右下などの位置合わせパターン・タイミング・形式情報も含め、三隅の検出パターン以外にはすべてセル設定を適用する。
- 機能パターンも装飾するため、ひし形・細い斜線・小さな円などは、型番や内容、デコーダーの検出方法によって読み取れない場合がある。最終的な出力で読み取りを確認する。
- Anti-aliasは2×2の被覆評価。各マスの境界を独立にぼかす方式と異なり、連続した暗部に継ぎ目を作らない。

## 中央画像

- Enable Center Imageで有効化する。Imageは通常の色・画像入力で、透明な定数も使える。
- Image SizeはQuiet Zoneを除いたQRコード本体に対する幅・高さの比率（0〜1）。どちらかが0なら画像とくり抜きの両方を無効にする。
- Image Paddingはマス単位の余白。画像の矩形に余白を加え、その領域に重なるマスを外側へ丸めて丸ごと消す。くり抜きは画像のalphaに依存しないため、透明な画像でも下にマスは残らない。
- 消した領域の下地はLight Color。画像はセル境界へ拡大せず、指定した矩形へ配置する。入力のFitはこの矩形の縦横比を基準とし、Wrap / Filterも適用する。
- 大きなくり抜きは機能パターンも消し得る。装飾・低コントラスト・小さなマス・縮小・くり抜きの組み合わせによって読み取り可否が変わるため、使用する最終画像で確認する。

符号化は[uqr](https://github.com/unjs/uqr)（MIT、Nayuki由来）を使用する。テストでは独立した[jsQR](https://github.com/cozmo/jsQR)で内容の復元も確認する。

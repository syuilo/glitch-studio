# Liquid Glass

背景画像と任意のスカラーマスクから、丸みのある縁・背景の屈折・ぼかし・色分散・表面の揺らぎ・光沢を持つガラスを描画する。背景を含む加工済み画像を出力する。ぼかし・色分散・揺らぎの初期強度は0。

- **Background**: 屈折させる背景。主入力・自動解像度の基準として使う。各参照位置に接続のfit/wrap/filterを適用する。
- **Mask**: 0〜1のスカラー場。0は背景をそのまま返し、1はガラスを適用する。0.5の輪郭から縁を作り、最終合成には元の連続値を使う。初期値は0。画像の輝度を使う場合はRGB toを経由する。画像を直接スカラーへ接続すると、他のスカラー入力と同様にR成分を読む。
- **Bevel Width**: 輪郭から内側へ丸みを付ける幅。0では縁の丸みを付けない。表面の揺らぎは独立して適用できる。
- **Surface Height**: 縁の丸みによる表面の盛り上がり。0では縁の屈折・光沢がなくなる。色味と表面の揺らぎは残る。
- **Refraction Strength**: 表面の法線に応じた背景の参照位置の変位量。正は縁で拡大する向き、負は逆向き。屈折率ではない。
- **Blur Radius**: 屈折した背景をぼかす円盤の半径。0で無効。マスクと表面の光沢はぼかさない。
- **Blur Samples**: ぼかしに使う背景のサンプル数。4〜64。式などから奇数を渡すと近い偶数へ丸める。増やすとぼかしの品質と描画負荷が上がる。
- **Dispersion**: RGBの屈折量の差。赤・緑・青の変位量をそれぞれ`1 - Dispersion`・`1`・`1 + Dispersion`倍にする。0で無効。屈折が0の場所では色分散も起きない。
- **Waviness Amplitude**: 表面の高さの揺らぎの振幅。0で無効。マスクの形状は変えず、屈折と光沢の法線を変える。
- **Waviness Scale**: 揺らぎの空間的な大きさ。大きくすると広く緩やかな模様になる。同じ振幅でも小さくすると表面の傾きが強くなる。
- **Waviness Speed**: `Time`に掛ける速度。0で静止、負で逆再生する。
- **Waviness Seed**: 表面の模様を決める整数seed。
- **Time**: 揺らぎを評価する時刻（秒）。初期値は0。式`TIME`を指定すると再生時刻に連動する。描画回数やfpsには依存しない。通常のパラメータとしてキャッシュの更新へ伝わるため、停止中やシーク後も正しく再評価される。
- **Highlight Strength**: 方向性のある白い光沢と、斜めの面で強まる縁の反射の強度。
- **Light Direction**: 光源方向のXY成分。+Xは右、+Yは上。Z成分は0.8に固定する。
- **Tint**: 表面へ重ねる色付き被膜。αが被膜の不透明度。αを0にすると色味を加えない。

幅・高さ・変位量・ぼかし半径・揺らぎのスケールは画面の最短辺を2とする等方的な座標で指定する。内部のマスク・距離場・seedは出力解像度を維持し、データ形式は`enable32bitDataTextures`に従う。画像出力は`intermediateTextureFormat`に従う。背景のRGBAを乗算済みのまま変位・平均し、被膜と反射もpremultiplied alphaで合成するため、透明背景にも表面を描画できる。

GPUではマスクを描画し、隣接画素の値から0.5の輪郭位置を補間してseedを作り、JFA+1で最寄りの輪郭を求める。その近似符号付き距離から楕円の1/4断面の高さを作り、縁の幅に応じた中央差分で法線を計算する。揺らぎには、座標・Time・seedから評価する大小2つの3D value noiseと解析的なXY微分を使う。輪郭で揺らぎの高さを0へ落とす際は、その包絡の微分も含めて縁へつなぐ。背景の参照位置を法線で変位させ、光沢・色味を加えて元のマスクで背景と合成する。同じ入力・Time・設定なら描画順序・前フレームによらず同じ結果になる。

ぼかしは黄金角で配置した対称なサンプル対を、ガウス重みで平均する近似。時刻や画素ごとの乱数でサンプル位置を変えず、アニメーション中のちらつきを防ぐ。色分散は各参照位置の乗算済みRGBを取り出し、αは3つの参照の最大値を使う。透明な境界で色分散を保持するための被覆率の近似であり、波長ごとの透過率を厳密に表すものではない。

JFAは近似であり、輪郭は出力画素で離散化される。細い形・鋭い角・内側で縁同士が接する部分では断面や法線が滑らかにつながらない場合がある。画面外の輪郭は推定せず、切り取り位置に新しい縁は作らない。一様なマスクは輪郭のない平面になる。広いマスクのグラデーションは被覆率として扱い、自由な高さマップには変換しない。

背景平面の変位による2.5Dの屈折近似で、3Dの入射・出射や多重反射を追跡しない。大きなぼかし半径と少ないサンプル数では模様が残る場合がある。背景の参照はぼかしだけなら`Blur Samples`回、色分散も有効ならその3倍になる（ぼかし無効時は1回または3回）。背景だけが変化する場合も、描画時には距離場を再計算する。

# Liquid Glass

背景画像と任意のスカラーマスクから、丸みのある縁・背景の屈折・光沢を持つガラスを描画する。背景を含む加工済み画像を出力する。

- **Background**: 屈折させる背景。主入力・自動解像度の基準として使う。各参照位置に接続のfit/wrap/filterを適用する。
- **Mask**: 0〜1のスカラー場。0は背景をそのまま返し、1はガラスを適用する。0.5の輪郭から縁を作り、最終合成には元の連続値を使う。初期値は0。画像の輝度を使う場合はRGB toを経由する。画像を直接スカラーへ接続すると、他のスカラー入力と同様にR成分を読む。
- **Bevel Width**: 輪郭から内側へ丸みを付ける幅。0では平面として扱う。
- **Surface Height**: 表面の盛り上がり。0では法線が正面を向き、屈折・光沢がなくなる。色味は残る。
- **Refraction Strength**: 表面の法線に応じた背景の参照位置の変位量。正は縁で拡大する向き、負は逆向き。屈折率ではない。
- **Highlight Strength**: 方向性のある白い光沢と、斜めの面で強まる縁の反射の強度。
- **Light Direction**: 光源方向のXY成分。+Xは右、+Yは上。Z成分は0.8に固定する。
- **Tint**: 表面へ重ねる色付き被膜。αが被膜の不透明度。αを0にすると色味を加えない。

幅・高さ・変位量は画面の最短辺を2とする等方的な座標で指定する。内部のマスク・距離場・seedは出力解像度を維持し、データ形式は`enable32bitDataTextures`に従う。画像出力は`intermediateTextureFormat`に従う。背景のRGBAを乗算済みのまま変位させ、被膜と反射もpremultiplied alphaで合成するため、透明背景にも表面を描画できる。

GPUではマスクを描画し、隣接画素の値から0.5の輪郭位置を補間してseedを作り、JFA+1で最寄りの輪郭を求める。その近似符号付き距離から楕円の1/4断面の高さを作り、縁の幅に応じた中央差分で法線を計算する。背景の参照位置を法線で変位させ、光沢・色味を加えて元のマスクで背景と合成する。時刻・描画順序・前フレームを使わない。

JFAは近似であり、輪郭は出力画素で離散化される。細い形・鋭い角・内側で縁同士が接する部分では断面や法線が滑らかにつながらない場合がある。画面外の輪郭は推定せず、切り取り位置に新しい縁は作らない。一様なマスクは輪郭のない平面になる。広いマスクのグラデーションは被覆率として扱い、自由な高さマップには変換しない。

背景平面の変位による2.5Dの屈折近似で、3Dの入射・出射や多重反射を追跡しない。ぼかし・色分散・表面の揺らぎは含まない。背景だけが変化する場合も、描画時には距離場を再計算する。

# Displacement Transition

同じベクトル場を使って画像AとBを逆方向へ歪ませながら切り替える。

## パラメータ

- `inputA` / `inputB`: 画像または色。未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。式・キー・scalarノード接続に対応する。
- `displacement`: 長辺全体=1の共通単位を使う変位ベクトル。右が+X、上が+Y。既定値は[0.1, 0]。定数ベクトルなら平行移動、場を接続すると局所的な歪みになる。
- `strength`: 変位に掛ける無次元倍率。既定値1。負値はA/Bそれぞれの変位方向を反転し、0は画像の変形を無効にする。
- `mixWidth`: 進捗0.5を中心とした混合期間の全幅。0〜1へclampする。0は中央でカット、1（既定）は全期間でsmoothstep補間する。

## 動き・座標・混合

進捗をpとした変位の強度包絡は`16*p²*(1-p)²`。中央で1、両端で0になり、両端での傾きも0になる。Aを変位の正方向、Bを逆方向へ同じ量だけ動かす。最大変位は`displacement * strength`で、進捗0.5に生じる。

ProgressとDisplacementはどちらも変形前の出力位置で読む。Progressに場を接続した場合は画素ごとの局所進捗となり、同じ画像の中で異なる強度や混合率を使える。

変位ベクトルには色変換・alpha乗算・0.5の減算を行わない。共通単位から画像参照座標への換算だけを行い、縦長・横長でも同じ変位を保つ。範囲外参照は入力接続のFit / Wrap / Filterに従う。

画像の補間はpremultiplied alphaのlinear sRGBで行い、HDR・負値・半透明を保持する。端点では元の参照位置を直接返し、端点近傍も包絡によって連続して元画像へ戻る。時間・履歴には依存しない。

自動解像度はA/B両方を参照する。画像のみ出力し、Maskは持たない。

## パラメータの再検討

Mix Widthは歪みの最大量を維持したまま切替タイミングを調整できるため追加した。A/B別の方向倍率や回転は上流のベクトル加工と組合せで拡張できるため初期版には含めず、対向する同量の変位に意味を固定した。包絡形状の選択や専用Easingも追加しない。

Displacementは空間データなので、Size Referenceを変位へ掛ける設定は設けない。Maskだけでは変形した参照座標を再現できないため、scalar出力も設けない。

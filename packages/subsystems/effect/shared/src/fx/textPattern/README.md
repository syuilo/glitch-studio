# Text Pattern

フォントAssetから文字列を描画し、横・縦へ反復配置する生成エフェクト。各文字のTracking・Translation・Opacity・Scale・Rotation・Colorを、定数またはノード入力で指定できる。

- Sizeは出力の高さに対するフォントサイズ。Scaleはキャッシュ済みの字形に適用する独立した倍率で、負値は両軸を反転する。
- Repetitionsは横・縦の反復回数。四捨五入し、1以上として扱う。横の反復間には空白を一つ入れ、縦には改行を含む文字列全体を繰り返す。自動折り返し・自動縮小は行わない。
- フォント本来の各書記素の送り幅を使い、入力の前後の空白・空行を保持する。Alignmentは横反復後の各行に適用し、Position Yは配置枠を含むブロック全体の中央を指定する。
- AlignmentのDistributeは、各行の先頭・末尾の配置枠を画面の左右端へ合わせ、文字間に同量の余白を配分する。空白・反復区切りも一文字として数え、1文字だけの行は中央へ置く。字形のサイズは変えず、幅に収まらない場合は字間を詰めるため重なり得る。Position Xで全体を平行移動できる。ノード入力の基準位置にもこの配置を使う。
- TrackingはSizeに対する追加字間の比率。0で追加なし。Left・Center・Rightでは正値で広げ、負値で詰める。各文字の後ろへ加算し、後続文字へ累積する。入力・反復区切りの空白も評価し、行末には追加しない。改行ごとに累積をリセットし、字間を反映した行幅でAlignmentを保つ。Scaleによって字間は変わらない。
- Distributeでは、各間隔のTrackingから行内の平均値を差し引き、先頭・末尾の配置枠を固定して内部の間隔だけを変える。一様な値は相殺されるため、定数のTrackingでは配置が変わらない。ノード入力で場所ごとに異なる値を与えると、両端を保ったまま字間の疎密を変えられる。1文字・2文字だけの行もTrackingでは動かない。Translation・Scale・Rotationによる変形は通常どおり適用する。
- すべてのノード入力を、Trackingも変形も適用する前の各文字の配置枠の中心（出力座標）で一度だけ読む。fit・wrap・filterは既存のShaderInputと同じ。字間変更後の位置・変形後の位置・描画先の各画素では読み直さない。
- ScaleとRotationは同じ配置枠の中心を基準とする。拡縮、回転、移動の順に適用する。Translationは±2で画面幅・高さ一つ分、Rotationは1で時計回り180度となり、Transformと共通の規約を使う。
- Opacityを0〜1へ制限し、Colorの透明度と乗算する。背景は透明で、重なる文字は行・横反復・文字の順にpremultiplied alphaでsource-over合成する。画面外だけを切り取り、画面外から移動してくる文字も残す。
- カラー画像の輝度を使う場合は、上流でRGB toのLuminanceなどへ変換する。scalar入力は他のエフェクトと同様にR成分を読む。

日本語・英数字を中心とした書記素単位の独立描画を行う。Intl.Segmenterで結合文字・ZWJ絵文字をまとめるが、書記素間のカーニング・合字・文脈依存の字形置換・双方向組版・縦書きは行わない。絵文字も字形のalphaマスクとして指定色で描く。フォント未選択時はsans-serifを使う。

Effect subsystem共通の`text-font-loader.ts`がWorkerのFontFaceSetへの登録・読み込み世代・状態通知を担当する。Text Patternはフォント・文字列・Sizeが変わったときだけビットマップアトラスを再生成し、配置変更では基本位置・行範囲のバッファだけを更新する。毎フレームの入力評価とTrackingの累積はCompute shaderで行い、各行を独立して並列処理する。空白は評価点として残すが、面積0の四角形として描画を省く。字形の変形と合成はインスタンシング描画で行う。GPUからCPUへの読み戻しや前フレームへの依存はない。

大きなScaleではビットマップの拡大によるぼけが生じる。必要な画質に応じて基準のSizeを大きくしてScaleで縮小する。GPUのアトラス寸法・文字バッファ・dispatch上限を超える設定は描画エラーにする。

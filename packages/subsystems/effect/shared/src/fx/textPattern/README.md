# Text Pattern

フォントAssetから文字列を描画し、横・縦へ反復配置する生成エフェクト。各文字のTranslation・Opacity・Scale・Rotation・Colorを、定数またはノード入力で指定できる。

- Sizeは出力の高さに対するフォントサイズ。Scaleはキャッシュ済みの字形に適用する独立した倍率で、負値は両軸を反転する。
- Repetitionsは横・縦の反復回数。四捨五入し、1以上として扱う。横の反復間には空白を一つ入れ、縦には改行を含む文字列全体を繰り返す。自動折り返し・Tracking・自動縮小は行わない。
- フォント本来の各書記素の送り幅を使い、入力の前後の空白・空行を保持する。Alignmentは横反復後の各行に適用し、Position Yは配置枠を含むブロック全体の中央を指定する。
- すべてのノード入力を、変形前の各文字の配置枠の中心（出力座標）で一度だけ読む。fit・wrap・filterは既存のShaderInputと同じ。変形後の位置や描画先の各画素では読み直さない。
- ScaleとRotationは同じ配置枠の中心を基準とする。拡縮、回転、移動の順に適用する。Translationは±2で画面幅・高さ一つ分、Rotationは1で時計回り180度となり、Transformと共通の規約を使う。
- Opacityを0〜1へ制限し、Colorの透明度と乗算する。背景は透明で、重なる文字は行・横反復・文字の順にpremultiplied alphaでsource-over合成する。画面外だけを切り取り、画面外から移動してくる文字も残す。
- カラー画像の輝度を使う場合は、上流でRGB toのLuminanceなどへ変換する。scalar入力は他のエフェクトと同様にR成分を読む。

日本語・英数字を中心とした書記素単位の独立描画を行う。Intl.Segmenterで結合文字・ZWJ絵文字をまとめるが、書記素間のカーニング・合字・文脈依存の字形置換・双方向組版・縦書きは行わない。絵文字も字形のalphaマスクとして指定色で描く。フォント未選択時はsans-serifを使う。

Effect subsystem共通の`text-font-loader.ts`がWorkerのFontFaceSetへの登録・読み込み世代・状態通知を担当する。Text Patternはフォント・文字列・Sizeが変わったときだけビットマップアトラスを再生成し、配置変更では基本位置のバッファだけを更新する。毎フレームの入力評価はCompute shader、字形の変形と合成はインスタンシング描画で行う。GPUからCPUへの読み戻しや前フレームへの依存はない。

大きなScaleではビットマップの拡大によるぼけが生じる。必要な画質に応じて基準のSizeを大きくしてScaleで縮小する。GPUのアトラス寸法・文字バッファ・dispatch上限を超える設定は描画エラーにする。

# Pixelate Transition

Aを粗いモザイクへ変え、Bへ切り替えながら細部を戻す。画像出力のみを持つ。

## パラメータ

- `inputA` / `inputB`: 画像または色。未接続は透明。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。式・キー・scalarノードに対応する。場の接続時は出力画素ごとの進捗になり、格子の大きさと混合率が局所的に変化する。
- `maximumCellSize`: 最大時の正方形セルの辺長。Size Referenceに対する距離比率。0以下では画像をモザイク化せずに混合する。
- `peakPosition`: モザイクが最大になる進捗。元画像との連続性を保つため0.001〜0.999へ制限する。セル辺長は開始から最大点まで、最大点から終了まで、それぞれsmoothstepで増減する。
- `mixWidth`: Peak Positionを中心とするA/B混合期間の全幅（進捗単位）。期間の両端は0〜1へ切り詰める。混合はsmoothstepで、0では最大点でAからBへカットする。
- `gridOffset`: 格子を素材に合わせる位置。長辺全体=1、右が+X、上が+Yの共通座標。ここに1セルの中心を置く。Size Referenceでは変わらない。
- `samples`: セル平均の標本数。1〜64。1では中心だけを読み、複数ではセル内の等面積領域の中心を平均する。小数は整数へ丸める。品質と描画負荷を調整するための詳細設定。
- `sizeReference`: セルの寸法換算基準。同じ距離を縦横へ適用するため、縦長・横長でもセルは正方形。

## 描画

各セルで同じ入力位置を読むため、モザイクは単なるクロスフェードと異なる画像内容の平均になる。格子の成長に伴うセル境界の移動・再配置は表現の一部。セル寸法を画素数で丸めず、同じ縦横比なら解像度によらず同じ共通位置を参照する。

両端では元画像をそのまま返す。端点近傍でもセル寸法が0へ近づくため、最後のフレームだけ細部が戻る補正を行わない。有限精度を避けるため、共通距離で1e-7以下のセルは元の参照位置を使う。

入力のFit / Wrap / Filterに従う。平均と補間はpremultiplied alphaのlinear sRGBで行い、HDR・負値・透明度を保つ。時間・履歴・乱数には依存しない。自動解像度はA/B両入力を参照する。

## パラメータの再検討

素材への位置合わせ用Grid Offsetと、単一標本では失われる細部の平均品質を選ぶSamplesを追加した。Rotation・非正方形セルは初期の用途に不要な操作を増やすため設けない。進捗の緩急は式やキーで扱えるので独立Easingを持たない。scalar Maskだけでは画像の平均参照を再現できないため、Mask出力も設けない。

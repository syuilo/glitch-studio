# Radial Wipe

中心の周りを回る扇形でAをBへ置き換える。

## 入出力と進捗

- `inputA` / `inputB`は画像または色。未接続は透明。
- `progress`は0で完全なA、1で完全なB。範囲外は0〜1へ制限する。定数・式・キーに加え、scalarノード接続による画素ごとの進捗にも対応する。
- 進捗は境界の移動を表し、Bの画面占有率ではない。時間・履歴には依存しない。
- 主出力`output`はpremultiplied alphaのlinear sRGBを補間し、HDR・負値・半透明を保持する。
- `mask`はBの置換率（0=A、1=B）。入力画像の色やalphaに依存せず、画像出力と同じ重みを返す。16bit / 32bitデータ出力に対応する。
- 両出力を遅延確保する。Mask単独では画像出力や色を読む描画処理を使用しない。
- 自動解像度はA・B両方の入力を参照する。入力のFit / Wrap / Filterは接続設定に従う。

## 中心・開始角・方向

- `center`は長辺全体=1、中央[0, 0]、右が+X、上が+Yの共通座標。画面外も指定できる。
- `startAngle`は0が上、0.25が右、正値で時計回り、1で1周。
- `direction = clockwise`は開始角から時計回りに、`counterclockwise`は反時計回りにBを広げる。
- `both`は開始角の両側へ対称に開く。進捗0.5で両側90度ずつ、合計180度になる。
- 開く角度は進捗に比例し、画面外の中心でも角度の全周を基準とする。Invertは持たない。

## Feather

`featherUnit`で`feather`の解釈を選ぶ。

- `distance`（既定）: Size Referenceに対する距離比率。同心円上の弧長でぼかしの全幅を測るため、中心から離れても同じ距離幅になる。既定は長辺全体=1。
- `angle`: turn単位（1で1周）の全幅。外側へ行くほど距離としてのぼかし幅が広がる。Size Referenceは適用しない。

始端・終端の両方を、角度区間の平均被覆率でぼかす。孤立した境界のFeatherは線形のランプになり、細い扇形では両端のぼかしが自然に重なる。0でも画素の角度幅に応じたアンチエイリアスを行う。

周期の継ぎ目を含めて平均するため、0/1の端点へ連続的につながり、開始線に硬い継ぎ目を残さない。ぼかし幅が1周以上なら全周の平均としてMask=Progressになる。向きが定まらない中心点も同じ平均値を使う。

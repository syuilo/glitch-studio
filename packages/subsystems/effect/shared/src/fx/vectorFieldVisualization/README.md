# Vector Field Visualization

`Vector`の2成分ベクトル場を、正方形のセルに配置した矢印で可視化します。定数・式・ノード入力を受け取り、自動解像度はVectorの接続、定数の場合は描画先に従います。

矢印の軸の中点はセル中心に固定し、ベクトル方向の端に矢尻を付けます。セル中心の値をサンプリングするため、セル内の平均や流線ではありません。ゼロベクトルは丸い点として描き、短い矢印では矢尻も連続的に縮みます。

- `Density`: 短辺全体に入るセルの密度。最小1で、中央原点の格子を配置します。長辺には同比率でセルが増え、画面端には部分的なセルが残る場合があります。式では小数も使用できます。
- `Maximum Magnitude`: 長さ・Rampの位置1・オーバーフロー判定で共有するベクトルの大きさ。最小0.000001です。各成分そのもののユークリッド長を使い、描画先の縦横比では変えません。
- `Line Width`: セル幅に対する線の太さ。点の直径も同じ値です。有効範囲は0〜0.5で、0なら矢印と点を描きません。
- `Ramp`: `length(Vector) / Maximum Magnitude`を0〜1へ制限して参照し、矢印全体を同じ色で描きます。非ゼロの小さな値は位置0に近い色、上限と一致する値は位置1の色です。既存のColor Rampと同じ補間方式・色空間・透明度の規則を使用します。
- `Zero Color`: 入力が厳密に(0, 0)の場合の点の色。既定は白で、透明度も設定できます。表示上は点に見える微小な非ゼロ値にはRampを使います。
- `Overflow Color`: 大きさがMaximum Magnitudeを厳密に超えると、Rampの代わりに使う色です。長さは上限で固定します。
- `Direction Space`: `Vector Components`では成分の向きを画面上で保ち、(1, 1)は45度になります。`Image Displacement`では各軸が−1〜1の位置座標における変位方向を示し、縦横比を反映します。変わるのは方向だけで、大きさの基準・長さ・色は変わりません。
- `Grid Width`: セル幅に対するグリッド線の太さ。有効範囲は0〜0.5で、既定の0ではグリッドを描きません。
- `Grid Color`: グリッド線の色と透明度。交差点でも重ねて濃くならないように描画します。

線の太さと丸い端を含む最大外形をセル幅の80%に収めます。軸の長さは`(セル幅 × 0.8 − 線幅) × min(大きさ / Maximum Magnitude, 1)`です。点の太さを維持するため、外形全体の長さには線幅が加わります。矢尻もこの範囲内に収まり、セル境界で隣の矢印を切る処理は不要です。

入力は共通の`read_vector`でセル中心から読み、接続のfit・wrap・filterを維持します。セル中心への量子化がimplicit LODに影響しないよう、参照はLOD 0です。1回のfragment描画で距離に基づくアンチエイリアスを適用し、透明背景へ乗算済みRGBAを出力します。CPUへの読み戻し・履歴・時刻への暗黙の依存はありません。

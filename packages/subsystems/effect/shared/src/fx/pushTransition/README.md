# Push Transition

画像Bが画像Aを押し出すように、両方の画像を同じ方向へ移動して切り替える。

## パラメータと入出力

- `inputA` / `inputB`: 画像または色。未接続は透明。自動解像度には両入力を使う。
- `progress`: 0で完全なA、1で完全なB。範囲外はclampする。一定値なら画像全体を平行移動し、scalar場を接続すると出力画素ごとの局所進捗として扱う。式・キーによる制御も可能。
- `angle`: 画像の進行方向。0は上、0.25は右、正値で時計回り、1で1周。
- `output`: premultiplied alphaのlinear sRGB画像。透明度・HDR・負値を保持する。参照位置も移動するため、単純な置換率のMask出力は設けない。

## 移動と境界

描画領域を進行軸へ射影した全幅だけ両画像を移動する。Aは元位置から進行方向へ退出し、Bは反対側から元位置へ入る。境界はその方向に垂直な直線で、1画素の射影幅によるアンチエイリアスを行う。上・右・下・左では通常の画面同士の押出しになる。

斜め方向では、有限矩形2枚を移動するだけでは描画領域に隙間ができる。この隙間は画像の端を延長して埋める。移動後の参照位置を描画領域の端画素中心までに制限した後、接続ごとのFit / Wrap / Filterを適用する。端点では元位置をそのまま参照し、端延長は適用しない。

移動量と角度は長辺全体=1の共通座標で計算し、縦横比によって方向を歪めない。移動の全幅は描画領域から決まるため、距離やSize Referenceの設定は持たない。時刻・履歴・フレームレートには依存しない。

## パラメータ再検討

Gapは隙間の背景という別仕様を必要とし、Featherは隣接した画面の押出しをぼかす操作になるため追加していない。境界のAAは常時有効。進行の緩急はProgressの式やキーで指定できるため、Easingもエフェクト内では重複して持たない。

# Baker's Map

画像を引き伸ばして切り分け、積み直す標準的なBaker's mapを反復する。折り返しによる鏡映は行わない。入力画像全体を出力領域へFitした長方形が写像の定義域となり、画素単位の並べ替えは行わない。

- Inputは色の定数または画像。出力はlinear sRGBの`rgba16float`で、乗算済みalpha・負値・1を超える値を維持する。
- Iterationsは0〜16回、初期値3。式・キーからの値も最も近い整数へ丸め、範囲内へ制限する。0回ではAxis・Directionによらず通常の入力参照と一致する。
- DirectionはForwardまたはInverse、初期値Forward。Inverseは写像を逆方向に適用する。
- AxisはForwardで引き伸ばす方向、初期値X。Xでは横に2倍・縦に半分へ伸縮し、左半分を下・右半分を上に積む。Yでは写像全体を反時計回りに90°回し、縦に2倍・横に半分へ伸縮して、下半分を右・上半分を左に積む。単なるXY交換はInverseと重複するため使用しない。

各軸を内部で0〜1へ正規化し、X・Forwardの写像を`B(x,y) = (2x-k, (y+k)/2), k=floor(2x)`と定義する。+Yは上。解像度やfpsによって反復数・分割位置は変わらず、長方形でも縦横それぞれの全体に対する同じ分割を行う。外部へ独自の座標単位を公開しない。

出力位置から逆向きに座標だけを反復し、最後に一度だけInputをサンプリングする。GPUの1パスで描画し、時刻・描画履歴を持たない。Input接続のFit・Wrap・Filterを維持する。切断位置の不連続な微分を避けるためLOD 0を使う。

反復数が増えると帯の幅が指数的に細かくなり、画素より小さい構造は解像度・フィルター・浮動小数点精度によって潰れたりちらついたりする。有限解像度でのサンプリングには情報損失があるため、Forwardの出力にInverseを接続しても入力の完全復元は保証しない。

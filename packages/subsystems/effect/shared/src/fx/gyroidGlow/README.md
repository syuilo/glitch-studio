# Gyroid Glow

入り組んだ発光する膜と、その中を移動する発光球を生成する。入力画像は不要。膜の陰関数に近いほど光を強く加算する描画で、表面との衝突・遮蔽・吸収を計算するものではない。

| パラメータ | 初期値 | 意味 |
| --- | --- | --- |
| Time | 0 | 膜の流れ・回転・発光球の移動を進める秒数。式に`TIME`を指定すると再生時刻に追従する |
| Camera XY | [0, 0] | 固定した3D空間内のカメラ位置。共通単位で右が+X、上が+Y |
| Camera Z | 0.8 | カメラのZ位置。+Zは基準面の手前側。視線は常に−Z方向 |
| Zoom | 1 | 長辺基準の画角の拡大率。大きいほど狭い範囲を拡大する |
| Rotation | 0 | 構図の時計回りの回転。1で1周 |
| Near Emission Fade Distance | 1 | カメラ付近で膜の発光量を抑える距離。共通単位で指定し、0で抑制を無効にする |
| Near Fold Fade Distance | 0 | カメラ付近で膜のうねりを弱める距離。共通単位で指定し、0で抑制を無効にする |
| Fold Frequency | 1 | 膜の基準周波数0.6に対する倍率。画角とは独立して構造を細かくする |
| Fold Amount | 1 | 膜のうねりの強さ。0でうねりを消し、傾きによる平面状の分布にする |
| Sheet Tilt | [0.3, 0.9] | 膜の陰関数へ加えるX・Y方向の傾き。位置・角度ではなく無次元の係数 |
| Glow Width | 1 | 膜からの発光が広がる幅の倍率。0で膜の発光を消す |
| Sheet Strength | 1 | 二乗によるコントラスト処理前の膜の発光量。0で膜の発光を消す |
| Color Mode | Cosine | Cosineの周期配色、またはColor Rampによる自由な配色 |
| Color Ramp | 紫・シアン・橙・ピンク・紫 | Color Rampモードで使う配色。補間方式・補間色空間・各stopの色とalphaを編集できる |
| Color Frequency | 1 | 空間に沿って配色が繰り返す頻度の倍率。0ではColor Phaseで選んだ一色を使う |
| Color Phase | 0 | 両Color Modeに共通の配色位相。1で一巡する。一般的な色相回転ではない |
| Orb Color | 白 | 発光球のlinear RGB色。ノード接続可。alphaは発光量へ一度だけ乗算する |
| Orb Strength | 1 | コントラスト処理前の発光球の光量。0で発光球を消す |
| Exposure | 0 EV | コントラスト処理後・トーン処理前のRGBを`2^EV`倍する |
| Tone Mapping | Soft Shoulder | `1-exp(-RGB)`でハイライトを圧縮。HDRでは圧縮しない |
| Compositing | Opaque | 黒背景でalpha=1。Emissionでは同じRGBをalpha=0の発光として出力する |
| Maximum Steps | 120 | レイを進める最大反復回数。1〜2048 |
| Maximum Trace Distance | 7 | カメラからレイに沿って描画する最大距離。共通単位で指定し、0で発光を消す |

Timeは明示的な通常パラメータで、描画時刻や前フレームを直接参照しない。停止・逆再生・シークでも同じ設定から同じ結果を得る。動きを個別に分離する設定は持たない。

3D空間はエフェクト内で固定し、原点はZ=0の基準面の中央、右が+X、上が+Y、手前が+Z。初期カメラは`[0, 0, 0.8]`から−Z方向を見る。Zoom=1・初期カメラ位置で基準面に見える長辺全体を1と定義し、X・Y・Z・距離で同じ単位を使う。この単位と基準面は、カメラの移動、Zoom、解像度、縦横比によって変更しない。Timelineのカメラとは独立したエフェクト内の空間で、Size Referenceは持たない。

投影では画面位置を長辺基準の共通座標へ換算し、Rotationで回転、Zoomで除算してから、`normalize(vec3(画面位置, -0.8))`をレイの方向にする。長辺側の画角はZoom=1で約64°。初期設定では正方形の基準面の端は各軸±0.5、横長2:1ではXが±0.5・Yが±0.25、縦長1:2ではXが±0.25・Yが±0.5になる。縦横比を変えると短辺側の見える範囲が変わり、構造は歪まない。同じ縦横比で解像度だけを変更しても構図を維持する。

Camera XY/Zは視点の平行移動で、膜・配色・発光球の座標はカメラに追従しない。Near Fold Fade Distanceが正の場合は、カメラ付近のうねりの抑制範囲だけがカメラに追従する。Z=0を通り抜けても視線は−Zのまま。Zoomは画角だけを変え、Rotationは移動先のカメラを中心に構図を時計回りに回す。基準面の手前側でCamera Zを増やすとその面に見える範囲が広がるが、距離1の尺度自体は変わらない。

Maximum StepsとMaximum Trace Distanceのどちらかへ先に達した時点でレイを終了する。描画距離はZ軸方向の深度ではなく、カメラから正規化したレイに沿って進む長さ。最後の区間は最大距離で切り詰め、膜には区間の割合を、発光球には実際の区間長を適用して、範囲外の発光を加えない。距離0はOpaqueで不透明な黒、Emissionで透明な黒になる。

どちらの上限も、減らすと奥の膜・発光球や明るさが変化するため、純粋な画質設定ではない。距離だけを伸ばしても反復数が足りなければ奥へ届かず、距離で終了している場合は反復数を増やしても変わらない。軽量化にはエフェクト共通の解像度倍率も利用できる。

膜の模様用座標は、固定したワールド位置`[X, Y, Z]`から`[2X, 2Y, 1.6 - 2Z]`へ換算する。膜の陰関数は、周波数を指定したうねりにFold Amountを掛け、模様用座標に対する`0.45 * (x * Sheet Tilt.x + y * Sheet Tilt.y) + 0.6`を加える。傾きの符号を反転すると、その軸に対する傾斜の向きが反転する。Fold AmountとSheet Tiltがともに0なら空間的に一様な場になる。

Near Emission Fade DistanceとNear Fold Fade Distanceは独立した設定で、片方だけ、両方、どちらも無効の組み合わせを選べる。距離はカメラからレイに沿った共通単位で、0なら抑制なし、正なら距離0で係数0、指定距離で係数1になる線形のフェードを適用する。指定距離より遠くでは通常の値を使う。Zoomや解像度によってフェード距離の単位は変わらない。

Near Emission Fade Distanceは膜の発光だけに適用する。各積分区間の中央で評価し、歩幅・配色の参照位置・発光球には適用しない。Near Fold Fade Distanceは各サンプル位置でFold Amountへ掛け、Sheet Tiltと陰関数の基準値は維持する。形状に加えて歩幅も変わるため、膜と発光球の描画へ影響する。Fold Amount=0ならうねりの抑制距離を変えても結果は変わらない。

Near Fold Fade Distance=0なら、カメラ移動によって膜自体の形状は変化しない。正の場合は同じワールド位置でもカメラとの距離に応じてうねりが変化する。初期設定は発光の抑制だけを有効にする。

Glow Widthは陰関数の0から離れるにつれて減衰する発光の幅であり、画面上の距離や膜の厚さではない。幅を広げると中心の発光ピークを保ったまま周囲が明るくなり、総光量は増える。歩幅の計算には使わないため、Glow Widthを変えてもレイの到達位置や発光球の描画は変わらない。非常に狭い幅では光る領域をサンプルできず、細部が欠けることがある。

Sheet StrengthやGlow Widthが0でも膜による歩幅の計算は残るため、発光球の描画もFold Frequency・Fold Amount・Sheet Tilt・Maximum Stepsの影響を受ける。発光球の位置はTimeを`t`として、共通単位で`[0.55 sin(0.21t), 0.25 cos(0.17t) + 0.225, -0.4 - 0.2 sin(0.13t)]`。Orb Colorのノード入力は画面座標で一度参照し、その画素のレイ全体へ適用する。3Dの材質テクスチャではない。入力の解像度は出力の自動解像度へ使わない。

Color Rampはレイの各地点で評価してから光を加算する。膜の奥行きによって異なる色が混ざり、完成画像の明るさへ後から色を割り当てる処理とは異なる。参照位置は模様用座標での`(z * 0.2 + 流動後のx * 0.05) * Color Frequency - Color Phase`の小数部分で、0〜1を繰り返す。継ぎ目を滑らかにしたい場合は0と1に同じ色を置く。Color Frequency=0では`fract(-Color Phase)`の色になる。

Rampの補間には共通のColor Ramp実装を使い、補間後の乗算済みlinear RGBを発光量として加算する。stopのalphaはその色の発光量を減らし、出力の被覆率は変えない。HDR・負値も加算途中で保持する。単一stopなら単色、全stopのalpha=0なら膜は発光しない。CosineモードではRampの配色設定は描画へ影響しない。stop数や補間方式によって、各地点の配色を求める計算量も変わる。

発光球の光量は`Orb Color * Orb Strength`で指定し、膜と発光球の合計光量を二乗してコントラストを付ける。そのため最終色はピッカーの色と必ずしも一致せず、Strengthを2倍にしても最終光量が2倍になるとは限らない。負の色成分は加算途中で保持し、合計の二乗によって出力は非負になる。光量を線形に調整したい場合はExposureを使う。

出力はlinear sRGB・rgba16float。エフェクト内ではガンマ変換を行わず、表示側でsRGB encodeする。Soft Shoulderの出力は0〜1へ収束し、HDRは1を超える値を保持する。保存形式の有限上限65504だけで制限する。

Emissionは通常のsource-overでも背景へ光を加えられる。膜の透過率を表すalphaやSDF・深度の出力は持たない。通常の色パラメータのalpha=0は発光量0だが、接続された画像が既に持つalpha=0の発光RGBは保持する。

数値パラメータの非有限値・f32で表せない値は既定値へ戻す。カメラ位置の各成分は±1000、Maximum Trace Distance・Near Emission Fade Distance・Near Fold Fade Distanceは0〜1000、Zoomは0.01〜100、Fold Frequencyは0.01〜16、Fold Amountは0〜16、Sheet Tiltの各成分は±16、Glow WidthとColor Frequencyは0〜100、両Strengthは0〜1000、Exposureは±20へ制限する。Maximum Stepsは1〜2048へ制限して整数に丸める。RotationとColor Phaseは1周で折り返す。スライダー範囲はMaximum Trace Distanceが0〜30、Near Emission Fade DistanceとNear Fold Fade Distanceが0〜10で、描画時の上限はいずれも1000とする。

`CHROME_PATH`を指定し、`node --test packages/subsystems/effect/shared/test/gyroid-glow.gpu.test.mjs`で実際のWebGPUによる検証を実行する。任意で`GYROID_GLOW_PREVIEW`へPNGの保存先を指定すると初期設定の描画を保存する。`GYROID_GLOW_VARIATIONS_PREVIEW`には配色・形状・カメラ・描画距離・近傍フェードを比較する10枚の作例の保存先を指定できる。

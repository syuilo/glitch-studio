# Cell Sort

入力を等サイズの長方形セルに分割し、行または列ごとに画像片をソートする。Pixel Sortを含む他エフェクトの実装には依存しない。登録は既存の`_def_.ts`・`_impl_.ts`のglobで行う。

## 格子と端セル

FrequencyとSize Referenceでセルの幅・高さを指定する。両軸で同じ基準寸法を使い、解像度だけを変えても相対的な寸法を保つ。中央原点・+Yが上の格子座標にPhaseを加え、1で1セル周期となる。Horizontalは左から右、Verticalは上から下に並べる。格子の回転・Adaptive分割・画面全体を一列にする並べ替えは行わない。

画面と交差するセルは、端で一部が欠けていてもすべて対象とする。欠けたセルも本来の寸法を持ち、交換時に伸縮しない。画面外の入力参照はMirror Repeatで描画領域内へ折り返す。反射は入力接続のFitより前に描画領域の座標へ適用し、その後は接続のFit・Wrap・Filterで入力を読む。素材テクスチャ自体の端を反射の基準にはしない。

セル全体を交換してから画面で切り取るため、端へ移った画像片の一部が隠れ、内側へ移った端セルの反射部分が見えることがある。画面内の画素の個数や色分布の保存は保証しない。

## 解析とソート

Samples Per Cellは1〜256、既定値16。セルを指定数の等面積領域へ分け、その中心でpremultiplied RGBAを読み、平均色を求める。解析位置と個数は出力解像度に依存せず、反射部分も同じ重みで含める。有限個のサンプルによる推定であり、細い模様を必ず検出できるわけではない。

Luminance・Red・Green・Blue・Saturationは、平均premultiplied RGBを平均alphaで割った代表色から求める。Luminanceの係数は`(0.2126, 0.7152, 0.0722)`、SaturationはHSVの`(max-min)/max`。Alphaは平均alphaそのもの。Customは元セルの同じ位置でCustom Sort Keyのscalar入力を等重みで平均する。制御用の場も画面外では同じMirror Repeatを使う。

Threshold Min/Maxの範囲は両端を含み、上下限が逆なら交換して使う。範囲外・解析上完全透明・NaNキーのセルは固定し、ソート区間の境界とする。残りの連続したセルだけを指定方向・順序で安定ソートする。同じキーでは昇順・降順とも元の順序を保つ。閾値は式で0〜1の外にも設定でき、HDRや任意値のCustomキーも扱える。

Average Color for Moved Cellsは既定で無効。有効なら、最終的な参照元が配置先と異なるセルだけを、移動元の平均premultiplied RGBAで塗りつぶす。元の位置に残ったセルは画像の細部を保つ。Amountによる合成は行わない。

## GPU処理

- `common.wgsl`：uniform、統計とソート項目の型、セル番号の対応。
- `sampling.wgsl`：描画領域を基準にしたMirror Repeat。解析と出力で共用する。
- `analyze.wgsl`：セルごとの平均色・キー・対象判定を計算する。
- `sort.wgsl`：行・列ごとに区間番号を付け、二つのstorage bufferを交互に使って並列mergeする。
- `shader.wgsl`：参照元セルの番号から元画像の参照位置を求め、細部または平均色を描画する。
- `_impl_.ts`：格子計算、入力種別ごとのpipeline、GPUリソース、各dispatchのエンコードを担当する。

統計は32byte/セル、ソート用bufferは各12byte/セル。ソート中は区間・キー・元のセル番号だけを転送し、RGBAは元の統計に保持する。CPUへの読み戻しは行わない。各merge段階に別のuniform領域を割り当て、投入前の書き換えによる干渉を防ぐ。

格子がGPUのbuffer・dispatch上限を超える場合はFrequencyを下げるようエラーを返す。出力解像度に合わせてセル数やサンプル数を自動削減しない。格子の個数が変わった場合にbufferを作り直し、入力の定数／テクスチャ構成ごとにpipelineを保持する。

描画履歴・時刻・フレーム番号に依存しない。動画でキーの大小が逆転した瞬間に画像片が入れ替わり、移動の補間や時間方向の平滑化は行わない。

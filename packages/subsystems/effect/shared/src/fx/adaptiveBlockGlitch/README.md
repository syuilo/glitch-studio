# Adaptive block glitch

入力の色・透明度の変化に応じて四分木で大小のブロックを作り、葉ごとに位置ずれ、色の誤差、RGBの位置ずれ、平坦化を加える。解析用の縮小画像を出力へ使わず、入力を直接参照して細部を保持する。他のエフェクトの実装には依存しない。

## 処理

- `_def_.ts`：設定と入出力。既存のglobから自動登録される。
- `_impl_.ts`：階層の配置、統計バッファ、入力種別ごとのpipeline、階層ごとの集約pipelineと描画手順。
- `common.wgsl`：uniform、統計の型、座標変換、ブロック単位の乱数。
- `analyze.wgsl`：最小セルのpremultiplied RGBAを規則的にサンプリングし、平均と分散を計算する。
- `reduce.wgsl`：4個の子の統計を統合し、親の統計を作る。
- `shader.wgsl`：閾値に応じた葉の選択、破損の適用、輪郭線の描画。

統計は1セルあたり平均と分散の各vec4、合計32バイトのf32 storage bufferで保持する。最深階層を計算した後、子から親の順にdispatchする。同じバッファでも階層ごとに領域を分け、各dispatchの出力は次のdispatchが参照する。集約対象の階層はpipelineのoverride定数で固定し、エンコード中のuniform書き換えは行わない。

解析の分散はWelford法で計算する。親では子の分散と子同士の平均色の差を統合する。平坦な入力に丸め誤差から不要な細分化が発生しにくくするため、E[X²]-E[X]²は用いない。

## 分割と座標

左上を原点とし、画面短辺が1となる座標で正方形グリッドを定義する。`maxBlockSize`はSize Referenceで選んだ寸法に対する最大ブロックの一辺の百分率（既定値Long Side）、`subdivisions`は最大8回の四分割の深さ。最小ブロックの一辺は`maxBlockSize / 2^subdivisions`となる。画像を覆うグリッドの余りは解析時だけ端の値で埋める。

分割判定には`RGBの平均分散 + alphaの分散`を用い、その値が`threshold²`以下なら分割を止める。統計の入力は各成分を0〜1に制限したpremultiplied RGBAで、色だけでなく透明部分の輪郭も分割へ影響する。最深階層まで進んだら閾値によらず停止する。

最小セル内のサンプル数は各軸1〜8。有限個のサンプルによる推定なので、極端に細い線や高周波の模様を必ず検出できるわけではない。Seedを変えても解析位置や分割条件は変わらない。

解析グリッドとブロックの一辺は出力解像度に依存しない。解析と出力は同じ生成入力関数を使い、fitの基準には実際の出力寸法を渡す。定数入力とテクスチャ入力の両方に対応し、変形後の範囲外参照は入力接続のwrap/filterに従う。

GPUバッファやdispatchの上限を超える場合はエラーとする。最大ブロックを大きくするか分割階層を減らすことで計算量を下げる。出力ごとに自動で解析精度を変えるフォールバックは行わない。

## 破損と透明度

葉の座標・深さ・Seedから用途別の乱数を生成する。葉ごとに破損の有無、変位、色の誤差、赤・青の参照位置を決める。位置ずれとチャンネルずれは葉の一辺を単位とするため、ブロックの大きさに応じて破損の規模も変わる。

平坦化が無効なら元の細部を維持し、有効なら変位を加えた葉の中央の色を使う。画像の端で一部しか見えない葉は、見えている範囲の中央を使う。

色の加工はunpremultiply後に行い、最終的に一度だけpremultiplyする。`preserveAlpha`が有効なら元の入力位置のalphaを保持し、無効なら変位後の中央チャンネルのalphaを使う。`strength`による元画像との合成はpremultiplied RGBAで行う。

輪郭線は全ての葉へ適用する独立した表示設定で、幅は葉の一辺に対する割合。alphaを変えずRGBを暗くし、出力1画素分の幅でアンチエイリアスする。輪郭線が0で、破損確率または強度が0なら解析を省略して元の入力値を返す。

描画履歴やフレーム番号には依存しない。時間変化にはSeedなどへの式・オートメーションを使う。

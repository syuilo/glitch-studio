# Image Morph

現在のInput A・Input Bから双方向の対応を推定し、両方を中間形状へ変形してpremultiplied RGBAを混合する。手動ガイドや学習済みモデルは使用しない。過去の描画・時刻・フレーム番号には依存せず、他のエフェクト実装を参照しない。既存の`_def_.ts`・`_impl_.ts`のglobで登録する。

## 入出力と操作

- Input A / Input B：色入力。定数とテクスチャを扱い、入力ごとのFit・Wrap・Filterを最終出力の描画領域で評価する。自動解像度とバイパスの主入力はInput A。
- Progress：0〜1、既定値0.5。対応するA上の位置pとB上の位置qを、`(1-t)p + tq`の中間位置へ運ぶ。
- Warp Strength：0〜2、既定値1。0では通常のクロスフェード、1では推定した形の変形、1を超えると変形を誇張する。
- Link Blend to Progress：既定で有効。色の混合率をProgressへ連動させる。有効ならProgress=0でA、1でBを直接読み、Warp Strengthにかかわらず端点の元画像を正確に返す。
- Blend：連動を解除した場合の混合率、0〜1。Aの色を保持したまま中間形状へ運ぶなど、形と色を別々に操作できる。
- Search Range：0〜0.5、既定値0.2。対応推定の最大変位。描画領域の長辺全体=1の共通単位。0では変形しない。探索は局所的な近似であり、この範囲全体の最適解を保証しない。
- Smoothness：0〜1、既定値0.05。近傍の変位へ揃える正則化の強さ。大きくすると面として動き、小さくすると細部の変位を許す。
- Confidence Guard：既定で有効。低信頼な対応の変位を弱め、逆写像の解が不安定な場所は変形を抑えてクロスフェードへ戻す。解除すると信頼度で変位を減衰させず、不安定な変形も残す。
- Analysis Resolution (Short Side)：解析画像の短辺の論理画素数。既定値128。出力の解像度から独立している。式では4以上の有限値を指定し、GPUのtexture寸法上限を超える場合はエラーにする。
- Pyramid Levels：最大階層数、1〜6、既定値4。各段で縦横を半分にし、短辺が4未満になる階層は作らない。
- Iterations Per Level：各階層の探索回数、1〜32、既定値8。前半は解析1画素、後半は0.5画素の近傍を探す。

| 出力 | 型 | 意味 |
| --- | --- | --- |
| Output | color | 変形・合成した画像 |
| Warp A | vector | 出力位置からInput Aを参照する逆変位 |
| Warp B | vector | 出力位置からInput Bを参照する逆変位 |
| Confidence | scalar | 双方向の対応と逆写像の整合性を合わせた0〜1の指標 |

Warpは速度ではなく、このProgress・Warp Strength・Confidence Guardで実際の描画に使用する変位。中央原点・右が+X・上が+Y・長辺全体=1の共通単位で、`参照位置 = 出力位置 - Warp`と定義する。Vector DisplacementのAmount=1へ接続できる。WarpとConfidenceは未接続時には確保・描画しない遅延出力。使用中のポートだけを出力し、WarpやConfidenceだけが接続される場合も動作する。

## 対応の推定

1. 最終出力と同じ描画領域で両入力を解析画像へ取得する。解析画素の4点でpremultiplied RGBAを平均する。
2. 4点平均で画像ピラミッドを作る。解析画像の論理寸法を維持し、textureの実寸だけを切り上げる。内部参照はclampし、入力接続のWrapと混同しない。
3. 最も粗い階層のゼロ変位から始める。各階層で、現在の変位・ゼロ・近傍の変位・近傍平均・現在の変位からの8方向の候補を比較する。
4. 最終フローに対して、見た目の一致とA→B→Aの往復誤差から信頼度を求める。

候補の誤差は3×3のRGBAパッチで計算する。各点でpremultiplied RGBをalphaで割った可視色を比較し、色差へ両者のalphaの小さい方を0〜1へ制限して掛け、alpha差の二乗を加える。完全透明のRGBは比較せず、透明度の輪郭も対応付けへ含める。色を0〜1へ制限しない。

パッチ誤差へ、近傍平均からの変位差の二乗をSmoothnessで重み付けして加える。弱いゼロ変位の優先度も持たせ、平坦な場所で無意味な変形を作らない。同点では現在の候補を保つ。A→BとB→Aは独立して推定し、元画像の同じ位置へ定義した二つの場を一つのRGBAデータtextureのxy・zwへ保持する。

近傍の値は必ず前のdispatchのtextureから読み、二枚を交互に使用する。階層の拡大時も変位は共通空間単位のままで、2倍しない。毎回ゼロから始めるため、入力・設定・出力寸法が同じなら描画順や時間間隔に依存しない。

## 中間形状と逆写像

入力上の位置sに定義された対応変位Fに対して、中間位置pは`p = s + kF(s)`。A側のkは`Progress × Warp Strength`、B側は`(1-Progress) × Warp Strength`となる。Confidence Guardが有効なら、Fを入力位置における信頼度で減衰させる。

この式を出力位置ごとに減衰Newton法で12回反復して逆に解く。Fを出力位置で単純に読む近似にせず、非一様な拡縮でも中間位置に対応する入力位置を求める。ヤコビアンは解析1画素幅の中心差分で計算し、特異に近い場合は残差方向の更新へ戻す。更新量を制限して数値的な発散を抑える。

解の残差が解析0.5〜2画素なら信頼度を減らし、向きが反転する・入力の描画領域外へ出る場合も不確かな解として扱う。Guardが有効なら、その逆変位をゼロへ近づける。最終的なConfidenceは両入力側の値の小さい方。これはopacityではなく、画像のalphaへ追加乗算しない。

逆写像も解析解像度で求め、逆変位のtextureを出力解像度へ線形補間する。その位置で元のInput A・Bを参照し、RGBAをまとめてBlendで混合する。解析用の縮小画像を色の出力には使わない。画面外の入力参照は各接続のWrapに従う。

## GPUリソースと制約

解析用の色・フロー・逆変位は`enable32bitDataTextures`に従ってrgba16floatまたはrgba32floatを使う。信頼度はrg16float/rg32floatとr16float/r32float。画像出力は`intermediateTextureFormat`、公開Warpはrg16float/rg32float、Confidenceはr16float/r32floatとなる。32bitモードでは共通のdevice設定がfloat32-filterableを提供する。

各階層に二つの色textureと二つのフローtexture、最も細かい階層に双方向の信頼度・中間逆変位・中間信頼度を保持する。解析解像度・階層数・必要なuniform容量が変わったら作り直す。階層・反復ごとに別のuniform領域を保持し、コマンド投入前の上書きで他のpassの設定を変えない。CPUへの画像・フローの読み戻しは行わない。

自動対応は色・局所模様に基づく近似で、目や口などの意味的な特徴は認識しない。無関係な画像、反復模様、大きな回転・遮蔽・折り重なりでは誤対応や二重像が残る。見えていない内容の生成や穴埋め、全体最適や常に一意な逆写像は保証しない。動画では毎時刻の二入力から推定し、時間方向の平滑化は行わない。高品質設定では解析・探索負荷が増える。

## 検証

`CHROME_PATH`を指定して`node --test packages/subsystems/effect/shared/test/image-morph.gpu.test.mjs`を実行する。実際のWebGPUで端点・独立Blend・premultiplied alpha・Fit・既知の平行移動・共通単位・解像度独立性・描画履歴からの独立・遅延出力・16bit/32bitの出力を検証する。公開WarpをVector Displacementへ接続した再構成も確認する。

逆写像は、既知の非一様なアフィン変位を直接与え、対応推定とは独立に中間拡縮の逆とConfidence Guardの有効・無効を検証する。

`IMAGE_MORPH_BENCHMARK=1`も設定すると、1920×1080出力・解析短辺128・4階層・各8反復で計測する。初回を除く3回について、CPUのコマンド生成からGPU完了までを測り、画素のCPU読み戻しは含めない。

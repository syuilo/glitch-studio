# Card Flip

中央を軸に厚みのないカードを180度回転させ、表のAから裏のBへ切り替える。カードの外側には独立したBackgroundを表示する。

## パラメータ

| 名前 | 意味 |
| --- | --- |
| `inputA` | 回転前の表面。画像または色。 |
| `inputB` | 回転後の裏面。終了時に表示したい向きの画像または色。 |
| `background` | カードの投影範囲外に表示する画像または色。画面に固定され、カードと一緒には回転しない。 |
| `progress` | 0でA、0.5で真横、1でB。0〜1へclampし、回転角は進捗に比例する。 |
| `flipDirection` | 手前へ出てくる辺。`left` / `right` / `top` / `bottom`。 |
| `perspective` | 遠近感の強さ。0で平行投影、1で最大。0〜1へclampする。 |
| `shading` | 固定の正面光＋環境光による陰影。0で無効、1で最大。0〜1へclampする。 |

A / B / Background / Progressはノード接続に対応する。Progressに空間場を接続した場合は出力位置ごとに局所進捗を評価する。1枚の平らなカードとして動かす場合は一様な進捗を使う。イージングは式やキーフレームで指定する。

## 回転と透視投影

左右方向は中央の縦軸、上下方向は中央の横軸で回転する。Flip Directionは回転開始時にどの辺が手前へ出るかを指定する。Bは裏面に貼る際に回転方向の材料座標を反転させ、回転後には左右・上下とも元画像と同じ向きになる。

カードは出力と同じ縦横比の矩形。共通空間単位の長辺全体=1で計算し、寸法と遠近感が解像度によって変わらないようにする。中心は固定し、見えているカードの投影が出力の外へはみ出した部分はクリップする。軸・支点・カメラ位置を別々に設定するパラメータは持たない。

手前へ出る辺の方向の材料座標をu、回転軸と平行な材料座標をv、進捗をp、Perspectiveをkとすると、`θ=πp`として次の位置へ投影する。

```text
z = u sin(θ)
x = u cos(θ) / (1 - kz)
y = v / (1 - kz)
```

`k <= 1`かつ`|u| <= 0.5`なので、分母は0.5以上となり、カードがカメラ面を横切らない。描画時は投影された位置から材料座標を解析的に逆算する。

## 真横・輪郭・縮小

Progressが0.5のときは面積が0となり、Backgroundだけを表示する。側面や厚み、自動クロスフェードは持たない。例えばAとBをMixした結果をBackgroundへ接続すれば、真横で透明になる動作を避けられる。

回転によって縮む方向は、画素とカードの投影区間の交差幅を解析的に求める。透視投影による斜辺はその幅を4分割して被覆率と重心を求める。1px未満の細いカードも面積に応じて連続的に消える。

画像入力は接続のFit / Wrap / Filterを適用して出力解像度のカード面へ取り込み、面積平均のmipmapを生成する。逆投影の解析微分と最大16倍の異方性フィルタを使ってカード面を再サンプリングし、縮小時の細部のちらつきを抑える。面への貼り付けには接続のFilter設定を使い、回転した面自体の再サンプリングには線形・mipmap補間を使う。輪郭の外へはカード面の端の色を延長して補間する。

定数色には縮小画像を確保しない。一様な進捗では見えている面だけを更新し、端点・真横では更新を省略する。縮小画像は必要になった時点で確保し、エフェクトの破棄時に解放する。開始・終了時は接続入力を直接読み、元画像をそのまま保つ。

## 色・透明度・出力

カードが画素を覆う面積に応じてRGBAを置換する。カード内部の透明な画素にBackgroundをsource-overで透かす処理は行わない。輪郭ではpremultiplied alphaのままカードと背景を補間する。

ShadingによるRGBの倍率は `1 - shading * 0.45 * (1 - |cos(θ)|)`。正面の色は変えず、真横に近づくほど最大45%減光する。alphaは変更せず、負のRGBとHDRを保持する。背景への影・反射・ハイライトは持たない。

画像出力のみ。`transition` / `transform` / `composite`タグを持つ。自動解像度はA / B / Backgroundを参照する。時間・履歴に依存せず、スクラブや逆再生でも同じ入力と進捗から同じ結果を生成する。

## 検証

`test/card-flip.gpu.test.mjs`で、全方向の端点・真横、Bの向き、透視投影、輪郭と1px未満の被覆、透明度・HDR・陰影、縞模様の縮小、テクスチャ入力・局所進捗・接続設定、解像度と再生順序への不変性を実際のWebGPUで検証する。

`CHROME_PATH`を設定して実行する。任意で`CARD_FLIP_PREVIEW_PATH`へPNGの保存先を指定すると、同じGPU出力から4方向・5段階の進捗の比較画像を保存する。

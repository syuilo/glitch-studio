# VHS Playback

現在の入力画像からNTSC VHSの記録信号を生成し、テープ・ヘッドの読取異常を加えてから復調する画像加工エフェクト。輝度をFM変調し、カラーアンダー信号と混合した**実数のヘッド出力信号**を処理する。出力のRGBへノイズ帯や変形を重ねる方式ではない。

Custom Node Graph Effectとタイムラインのエフェクトレイヤーで利用できる。既存の`_def_.ts`／`_impl_.ts`のglobで登録する。他のエフェクトの実装・上位ドメイン・素材のデコーダーへは依存しない。

## 対象と近似

NTSCの通常再生を対象とし、入力は1フィールドの走査中に一定とみなす。525/59.94方式の262.5Hで時計を進め、計算領域には末尾の半ラインを覆う263行を確保する。フィールドの有効240行から補間して画像を再構成するため、入力の縦横比を維持したまま任意の出力解像度を使用できる。4:3への変形・クロップは行わない。

各物理要素は次の範囲でモデル化する。

- 輝度：linear sRGBからsRGB伝達特性の映像信号へ変換してYIQ行列を適用し、Gaussianで約2.4 MHzの帯域を近似。一次の高域強調とクリップを通し、同期先端3.4 MHz・白ピーク4.4 MHzのFMへ変調する。厳密なNTSC色度・伝達特性への変換や、特定機種の非線形エンファシス特性は再現しない。
- 色：輝度より狭い約0.3 MHzの帯域、約629 kHzのカラーアンダー搬送波、ヘッドごとに逆方向のライン位相回転を使用する。
- テープ・ヘッド：記録トラックと読取ヘッドの幅を等しいものとして重なりから振幅を求める。時間軸の乱れ、走査中の時刻ドリフト、ヘッド切替の時刻差・接触低下を加える。材料点の面内変形を逆算し、有効なヘッド間隔によるWallaceのスペーシング損失をFIRで近似する。磁性体の履歴・飽和、ヘッドの詳細なギャップ形状や接触圧力は扱わない。
- 再生：共通の実数信号から複素FIRで輝度FMと色信号を分離する。FMは隣接サンプルの位相差から復調し、録画時の高域強調を逆フィルタで戻す。
- 欠損補償：輝度FMの包絡が閾値より低い区間を復調前に1H前の信号で置き換える。連続欠損では補償した信号を再利用する。最初の行には前フィールドの履歴がない。
- 同期と色補正：復調した水平同期パルスから受像側のライン位相を推定する。カラーバーストから色相・ACCのゲインを求め、バーストが弱いときは色を消去する。長期間のサーボ履歴やフィールドをまたぐPLLの状態は保持しない。

PAL、SP/EPによるプロファイルの切り替え、隣接トラックの別フィールドの混入、走査時刻ごとの動画入力、動きによるインターレース、特殊再生、コンポジット出力のY/C再分離、CRTの表示特性は対象外。

## 設定

| 設定 | 意味 |
| --- | --- |
| Time (s) | 仮想テープの再生位置。**動かす場合は式に`TIME`を指定する**。0では静止する。 |
| Tape Damage | テープ表面の磁性層の欠損を表すスカラー入力。0で正常、1で記録信号が消失する。既定値は0。画像・ノイズなどのノードを接続でき、RF信号を減衰させる。 |
| Tape Surface Length (s) | 傷・隙間・変位の各マップに共通するテープ範囲の横幅を、走行時間で指定する。既定値4秒、範囲0.05〜60秒。縦幅は有効記録幅10.07 mm。 |
| Tape Surface Offset (s) | 各マップに共通する中心のテープ長手方向の位置。0はTime=0のフィールド走査中心で、正の値では後の再生位置へ移動する。 |
| Tape Displacement | 録画時の材料点が再生時にどこへ移動したかを表す前方変位のベクトル場。Xは長手方向、Yはテープ幅方向の上。公開値はテープ領域の長辺全体=1の等方単位。既定値[0,0]。 |
| Tracking Offset (Tracks) | トラック幅を単位にした横断方向のずれ。読取振幅とテープ上のヘッド位置の両方へ反映する。±1以上では、その位置の記録トラックとの重なりがなくなる。 |
| Track Alignment Error (Tracks) | フィールドの走査開始から終了までに変化する横断量。Offsetと組み合わせ、読めない区間の位置・幅が決まる。 |
| Time Base Error (μs) | 相関を持つ読取時刻の揺れ。実際のRF信号を読む時刻を変動させる。 |
| Scan Timing Drift (μs / Field) | フィールド内の読取時刻誤差の変化量。正なら走査後半ほど記録信号を先に読む。 |
| Head Contact | RF信号の読取振幅。低下しても画像の明るさを直接減らさず、電気的雑音に対するS/Nが悪くなる。 |
| Head Separation (FM Wavelengths) | ヘッドと磁性面の有効な隙間を、基準3.9 MHzのFM波長に対する比率で指定するスカラー場。0で接触、1で基準波長1つ分。既定値0、範囲0〜1。 |
| Head Switching | 次の垂直同期の約6.5H前でヘッドを切り替える。下端付近に接触低下が生じる。 |
| Head Timing Difference (μs) | ヘッドAからBへ切り替えた際の読取時刻の差。次のフィールドでは逆方向へ切り替える。 |
| Dropout Rate (/s) | 1Hごとの発生確率を`Rate × H周期`として設定する、平均欠損開始数。1Hあたり最大1事象。 |
| Dropout Duration (μs) | 欠損の長さの基準値。各事象は0.5〜1.5倍の長さを持ち、行の境界をまたぐ。 |
| Dropout Depth | 欠損中の読取振幅の減衰。1で中心区間の信号がなくなる。 |
| RF Noise Floor (dB) | 正常な輝度FMの振幅1に対する電気的雑音の振幅。読取信号の減衰後に加算する。 |
| Dropout Compensation | 輝度FMの1H欠損補償。色信号は置き換えない。 |
| Chroma Correction | バーストに基づく色相補正とACCの強さ。色消去はバーストの強さから常に判断する。 |
| Time Base Correction | 受像側の遅い水平同期追従から、各行で測定した同期位置への補正へ移行する。ライン内の伸縮を完全に補正するTBCではなく、位相補正のみ。同期が検出できない区間では推定時計を維持する。 |
| Seed | テープの損傷、走行の乱れ、電気的雑音の再現を固定する。 |

数値は有限値を必要とし、Time・Seed・Tape Surface Offset以外の数値パラメータはUIの範囲へ制限する。Tape DamageとHead SeparationはGPUで0〜1へ制限する。Tape Displacementの成分はクランプせず、小変形で逆写像できる範囲を対象とする。損傷を0にしても、正常なVHSの帯域制限・記録処理は残る。入力とのブレンドは後段のノードなどで行う。

## テープ表面の傷マップ

`Tape Damage`は色ではなく0〜1のスカラー場。白黒画像なら黒が正常、白が完全な欠損を表す。色画像を接続した場合は通常のスカラー入力と同じくR成分を読み、色変換・追加のalpha乗算はしない。輝度やalphaから傷を作る場合は、上流のノードでスカラーへ変換する。強度・反転・ぼかしなども上流で加工できる。

マップの横はテープの長手方向、縦は幅方向であり、映像の画面座標とは異なる。NTSC SP相当の走行速度33.35 mm/s、走査角約5.97°、有効記録幅10.07 mmを使い、Timeで進むテープを斜めのヘッド軌跡が横切る。フィールド内の走査長は長手方向で約96.3 mmとなるため、傷の一部が画面の複数行へ現れ、Timeの進行につれて交差位置が変わる。

テープ面の局所座標は右が長手方向の+X、上が幅方向の+Y。フィールド内の走査に沿って右下へ進み、次のフィールドではテープ送り分だけ+Xへ移る。Tracking OffsetとTrack Alignment Errorはトラックの法線方向へ、時間軸誤差は走査軌跡に沿ってヘッドの参照位置を移動させる。座標は内部だけで使用し、公開するマップの範囲・位置は秒で指定する。

Fitは映像出力ではなく、`走行速度 × Tape Surface Length`と有効記録幅から求めたテープ範囲の縦横比を基準にする。既定値の4秒では133.4×10.07 mm。出力解像度や縦横比を変えても同じテープ表面を参照する。入力接続のFit／Wrap／Filterを利用できる。

- マップ全体を指定範囲へ対応付ける場合はFitを`Stretch`にする。
- 有限の傷を配置する場合はWrapを`Transparent`にする。範囲外の損失は0になり、傷を通過すると正常なテープへ戻る。
- 周期的な傷には`Repeat`／`Repeat Mirrored`を使う。`Clamp`はマップ端の損失を延長する。

ヘッドが読んだ傷の強さをDとすると、トラッキング・接触・ランダム欠損による読取振幅へ`1−clamp(D,0,1)`を乗算する。その信号へヘッド間隔のフィルタを適用してから電気的雑音を加える。輝度FMとカラーアンダーを混合したRF信号に作用するため、既存の1H補償・同期回復・バースト補正がそのまま働く。D=0.5は信号振幅が半分になることであり、映像の明るさが半分になることではない。出力alphaは既存のAlpha Modeに従う。

傷と隙間は、逆写像した材料点を参照する。マップ自体は再生成・蓄積せず、同じ入力・Time・設定ならシーク後も同じ位置を参照する。

## 有効な隙間と面内変形

Head Separationは、接触状態を考慮した結果の有効な隙間を直接指定する。自由状態の凹凸の高さから接触圧力や隙間を求める処理は行わない。隙間d、ヘッドとテープの相対速度vに対する振幅応答は`H(f)=exp(−2π|f|d/v)`とする。基準波長`λ_ref=v/3.9MHz`は約1.49 μmなので、入力gを`d=g×λ_ref`として扱う。テープの走行速度33.35 mm/sと、ヘッドの相対速度約5.8 m/sは区別する。波長比のスカラー場にすることで、出力サイズやマップ範囲を変えても同じ隙間を保ち、16bitでも微小な距離を表せる。

隙間は65段階の129タップのFIR係数へ補間する。0は恒等変換でフィルタを省略し、正の区間では周辺のRFサンプルを参照する。係数は指数的な周波数応答の逆変換にHann窓を掛けた近似で、約0.63〜4.4 MHzのRF帯域では理想値からの誤差を0.5 dB以内で検証している。窓掛けによるDCゲインの低下を再正規化するとRF帯域の損失を打ち消してしまうため、再正規化しない。隙間がフィルタ範囲で緩やかに変化する近似を用いる。

Tape Displacementは`F(q)=q+u(q)`という前方変形として定義する。ヘッド位置pに対して`F(q)=p`を満たす材料点qを最大10回の固定点反復で求め、その位置の傷・隙間と記録信号を読む。変位の成分値は入力のFitで拡縮せず、共通単位からテープ領域の長辺の物理長へ一度だけ換算する。例えば既定の4秒の範囲では[0.0001,0]が長手方向の13.34 μmに相当する。

材料点の移動を記録トラックの接線・法線へ分解し、接線成分はRF信号の読取時刻、法線成分はトラックとの重なりへ反映する。周波数も含めてRFを再サンプリングするため、場所ごとに異なる伸びは復調後の明るさや同期へ影響し、TBCによる補正も同じ同期信号から行われる。Preserve Coverageではalphaも同じ記録位置から読む。

初期モデルは変位の勾配が小さく、反転・重なりのない場を想定する。逆写像の残差が20 nm以内へ収束しない区間、または現在の1フィールドの信号範囲外を読む区間は、RF信号を失ったものとして扱う。任意の折れ返り・自己接触の解決や、変形の妥当性の全面的な検証は行わない。トラックを横断した分は現在のトラックの信号損失とし、隣接フィールドの実画像を混ぜる処理や局所回転によるアジマス損失は対象外。

## 透明度

VHSの映像信号にはalphaがないため、用途に応じた2つのモードを明示する。

- **Preserve Coverage**：coverageを別経路で保持するGlitch Studio向けの拡張。色のフィルタをcoverageで正規化し、完全透明な画素へ雑音色を生成しない。読取時刻と同期回復に対応する位置へalphaも移動する。画像とブランキングの境界ではcoverageの混合を分け、半透明にしただけで録画色が変わらないようにする。
- **Composite on Background**：背景色へ合成し、不透明な映像として録画する。背景色自身のalphaは黒の上へ合成して扱う。信号欠落やブランキングも不透明な出力になる。

通常のShaderInputとして定数・テクスチャを受け取り、入力のFit／Wrap／Filterを使用する。面積サンプリングと走査線の補間はpremultiplied alphaで行い、色の演算が必要な境界だけunpremultiplyする。

## 処理と責務

- `_def_.ts`：エフェクトの入出力、パラメータ。
- `signal.ts`：信号・テープ幾何の定数、仮想テープ位置、各ラインの走行状態とテープ面のヘッド軌跡、傷マップの座標変換、FIR係数。GPU・画像・プロジェクト状態を知らない。
- `head-spacing.ts`：Wallaceのスペーシング損失を近似するFIR係数の生成。
- `_impl_.ts`：ShaderInputの構成、GPUリソースと各passの管理。ステージごとに必要なバッファだけをbindする。
- `common.shader.ts`：CPUと共有する定数・色空間関数・共通WGSLの合成。バッファ配置は共通のビルド時ローダーに任せる。
- `common.wgsl`：信号バッファ、色変換、決定的な乱数、サンプル参照。
- `record.wgsl`：入力取得、帯域制限、エンファシス、FM位相の積分、記録RFの生成。
- `tape-surface.wgsl`：材料点の逆写像、トラッキング・磁性層欠損・有効な隙間の評価。
- `playback.wgsl`：間隔に応じたテープ読み取り、RF分離、1H補償、復調、同期と色の補正。
- `output.wgsl`：有効画像の再構成、coverageの位置変換。

内部は1Hにつき512サンプルのベースバンドと2048サンプルのRF（約32.22 MS/s）を使用する。すべてf32のstorage bufferで保持し、符号付き信号や位相を画像テクスチャの0〜1へ丸めない。逆写像後の読取位置・振幅・隙間も別のバッファへ保持し、129タップの各参照で逆写像を繰り返さない。バッファは1インスタンスにつき約30.2 MBで、出力解像度とは独立。最終画像の形式は`INTERMEDIATE_TEXTURE_FORMAT`に従う。映像入力の2構成と表面入力の8構成は別々にキャッシュする。

FMの積分はworkgroup内の並列scanと行間の積分に分け、行境界でも位相をつなぐ。搬送波の位相はCPUで周期へ折り返し、長時間の絶対時刻をGPUのf32で位相へ変換しない。

時間は59.94 Hzのフィールド境界へ量子化する。欠損は仮想テープ上の位置へ固定し、電気的雑音はフィールドと信号サンプルから決める。傷マップの繰り返しはFit適用後のUVでCPU側の倍精度により折り返し、非繰り返しのマップでは走査範囲全体が画像の外へ出た場合だけ遠方の座標を制限する。前回描画の出力・描画回数・`timeDelta`・出力FPSを使わず、同じ入力・Time・Seed・設定ならシークや描画順によらず同じ結果になる。入力の縮小に使う面積サンプリングは各軸8点が上限で、極端な縮小の厳密な積分ではない。

## 検証

`test/vhs-playback.test.mjs`は走行モデルの再現性、トラックの重なり、切替点、テープ面の変位方向、傷マップの長時間・負の座標の折り返し、FIR係数を確認する。`test/vhs-playback.gpu.test.mjs`はChromeのWebGPU上で変調・復調、色の帯域差、振幅変動への耐性、1H補償、同期補正、透明度、出力解像度・形式に加え、定数／テクスチャの傷入力、有限な傷の通過とOffset・シーク、トラッキングによる交差位置の変化、傷マップのFitが出力縦横比へ依存しないことを確認する。

`test/vhs-head-spacing.test.mjs`はFIRの周波数応答を物理式と比較し、GPUテストでも実際のreadTapeへ正弦波を入力してRF振幅を測る。表面の全8入力構成、変形からのトラッキング回復、TBC、伸長によるFM周波数変化、alphaの追従、複合した表面状態のシーク再現も確認する。

GPUテストには`CHROME_PATH`が必要。任意で`VHS_PLAYBACK_PREVIEW`へPNGの出力先を指定すると、元画像・通常の再生・劣化した再生・隙間と面内変形の再生を並べた確認画像を保存する。

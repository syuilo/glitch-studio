# Content error propagation

入力画像の内容に沿って、局所的な色の誤差を双方向へ伝播させるエフェクト。元画像を変形・縮小して出力するのではなく、内容に沿って移動する誤差の場だけを生成し、高解像度の入力へ加算する。描画履歴には依存しない。

## 処理の構成

- `_def_.ts`：エフェクトとパラメータの定義。既存のglobによって自動登録される。
- `_impl_.ts`：解析領域、pipeline、テクスチャと各反復の描画手順を管理する。
- `common.wgsl`：uniform、premultiplied alphaの変換、決定的な乱数と発生源の色の誤差。
- `capture.wgsl`：方向と境界を解析するための入力画像を取得する。
- `propagation.wgsl`：構造テンソルによる方向の解析、誤差の初期化、1ステップの伝播。
- `output.wgsl`：元の入力へ伝播した誤差を加算し、元のalphaを保持して出力する。

解析用の入力、方向の場、2枚の誤差の場を保持する。内部テクスチャは`enable32bitDataTextures`に従って`rgba16float`または`rgba32float`を使用し、サンプラーによる補間で読む。方向と誤差は符号付きのデータであり、画像のalphaとしては解釈しない。画像出力は`intermediateTextureFormat`に従う。

## 解像度と入力

解析画像の短辺を`analysisResolution`で固定し、長辺は出力の縦横比に合わせる。論理寸法は浮動小数点で保持し、テクスチャの寸法だけ切り上げる。最終出力と解析テクスチャの寸法を区別することで、出力解像度だけを変更しても発生源の位置、距離、半径、方向が変わらないようにする。

発生源の間隔、方向の解析半径、伝播距離は画面短辺に対する割合で指定する。両軸の距離の単位を揃えるため、縦横比が変わっても発生源が楕円になったり、方向が歪んだりしない。

`ShaderInput`の生成参照関数を使い、定数・テクスチャの両方でfit/wrap/filterを適用する。fitの基準は解析用の切り上げ後の寸法ではなく、最終出力の寸法。解析画像は各セル4点のpremultiplied RGBAを平均して取得する。極端な縮小に対する厳密な面積積分ではない。

解析テクスチャがGPUの寸法の上限を超える場合は描画エラーとし、`analysisResolution`を下げる。出力の寸法によって解析解像度を無断で変えるフォールバックは行わない。

## 方向と境界

未乗算のRGBとalphaの勾配から2×2の構造テンソルを計算し、近傍5点を重み付きで平均する。最大固有値の固有ベクトルを境界の法線、直交する軸を輪郭に沿う方向とする。RGBとalphaを使うことで、同じ輝度の色同士の境界や透明な図形の輪郭も方向に反映できる。

固有値の分離度とコントラストを方向の信頼度として用い、平坦な領域や複数の方向が混在する領域では`angle`の固定方向へ戻す。`following`で内容に追従する割合を調整する。`flowMode`は輪郭に沿う方向、輪郭を横切る方向、固定方向の3種類。方向は向きのない軸であり、両方向から誤差を受け取る。

経路の中点で方向を再評価し、曲がった輪郭へ追従する。移動区間を4分割してRGBとalphaの変化を調べ、`boundaryThreshold`を超える変化に対して透過率を下げる。小さいステップの差分は解析画像の1サンプル分へ換算し、透過率も移動距離に合わせて適用する。これにより反復数を増やすだけで境界を通りやすくなることを抑えるが、細い境界の検出や経路の近似は反復数・解析解像度に依存する。

## 誤差の発生と伝播

短辺基準のセルごとに確率的に発生源を置く。円形の発生領域をセル内でずらし、周囲の8セルも調べることでセル境界による切断を避ける。`sourceSize`はセル間隔に対する円の直径の比率。発生源の色はRGB、全チャンネル共通の明るさ、Yを変えない色差の3種類から選ぶ。

誤差の場のRGBには色の差分を到達強度で重み付けした値、Aには到達強度を保存する。初期誤差に入力のalphaを適用し、完全に透明な場所からは発生させない。

各反復では中央と経路の両方向から取得した誤差を比較し、最も強い到達誤差を採用する。中央も保持することで発生源とすでに到達した経路が残り、反復ごとの加算による発散や逆向きの誤差の打ち消しを避ける。2枚のテクスチャを交互に読み書きし、同じテクスチャを同じpass内で読み書きしない。

最大伝播距離を反復数で割った距離だけ各ステップを進める。減衰は`retention^(1 / steps)`とし、全距離を進んだときの保持率を設定できる。距離0または保持率0では伝播を省き、発生源だけを出力する。反復数は1〜256で、実際の到達距離や強さは境界・画像端・補間によって短く、小さくなる場合がある。

## 決定性と出力

Seedとセル座標だけで発生位置と誤差を決め、毎回その描画の入力から解析・初期化を行う。前フレームの誤差、経過時間、描画順には依存しない。アニメーションさせる場合はSeedなどのパラメータに式・キー・オートメーションを設定する。

最終出力は元画像のRGBへ誤差だけを加算する。alphaをそのまま保持し、必要なunpremultiplyとpremultiplyを一度ずつ行う。強度、発生率、発生サイズが0なら入力をそのまま返し、誤差が到達していない画素も元の入力を返す。解析画像は方向と誤差の生成にのみ使用するため、解析解像度を下げても元画像全体の細部を縮小しない。

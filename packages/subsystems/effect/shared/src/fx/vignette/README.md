# Vignette

楕円の外側ほど入力画像のRGBを暗くする。alphaは変更せず、透明な領域へ黒を描き足さない。画像の歪みや周辺ぼかしは行わない。

## パラメータ

- Inputは画像または色定数。自動解像度はInputを基準とし、定数入力では描画先を使う。入力接続のFit・Wrap・Filterは通常の規則に従う。
- Strengthは0〜1へ制限する。0で入力を保持し、1ではMaskが1の場所が黒になる。初期値は0.5。
- Centerは画面中央が[0, 0]、右が+X、上が+Yの共通座標。描画領域の長辺全体が1で、Size Referenceを変えても位置は変わらない。初期値は[0, 0]。画面外も指定できる。
- SizeはMaskが0.5となる楕円の全幅・全高。両成分が同じなら円となり、縦横比に合わせた引き延ばしは行わない。初期値は[0.8, 0.8]。どちらかの成分が非正なら保護する領域がないものとして全画素のMaskを1にする。
- Rotationは中心を支点として1で時計回りに1周する。初期値は0。
- FeatherはMaskが0から1へ変化する遷移の全幅。楕円の内外へ半分ずつ広がる。負の値は0として扱い、初期値は0.4。楕円の実際のユークリッド距離を使うため、長軸・短軸で幅が変わらない。Featherが楕円に対して大きい場合、中心も減光対象になり得る。
- SizeとFeatherはSize Referenceの基準寸法に対する比率。初期値はLong Side。位置の座標単位は切り替えない。

Input以外は画面全体で共通の値として評価し、式・キーによるアニメーションに対応する。履歴・乱数・描画順序へ依存しない。

## 減光と出力

楕円までの符号付き距離d（内側が負）と遷移幅wから、`Mask = smoothstep(-w/2, w/2, d)`を求める。wは換算後のFeatherと`fwidth(d)`の大きい方で、Featherが0でも画素に応じたアンチエイリアスを行う。wも0ならdが0以上の場所を1、それ以外を0にする。寸法が非正の空領域は常にMask=1。

主出力Outputはpremultiplied RGBへ`1 - Strength * Mask`を掛け、入力alphaをそのまま返す。Maskは中央側が0・周辺側が1のscalar出力で、Strength・入力色・入力alphaに依存しない。Strengthが0でも作用範囲を他のエフェクトへ利用できる。

Maskは未使用時に確保しない。使用時も画像と同じ1パスで生成し、`enable32bitDataTextures`に応じたr16float／r32floatで保存する。中間のSDFテクスチャは作らず、距離計算のみを`@gs/shared/gpu/shape-distance.wgsl`から利用する。

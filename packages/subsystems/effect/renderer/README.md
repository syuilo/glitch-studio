# Effect Renderer

エフェクトの実行インスタンスとGPU出力を管理する。ノード・Visual Module・レイヤーなどの配置や式のスコープは呼び出し側が所有する。

`effect-parameter-value.ts`は評価済みの通常パラメータを`ShaderInput`へ変換する。素材・Playerの参照は通常パラメータに含めない。`effect-static-settings.ts`が保存済みの静的設定IDから借用リソースを解決し、`EffectRenderer`は`init.resources`へ渡す。Playerは現在のフレームを返す関数として渡すため、選択は固定でも内容は更新される。デコーダー・非同期準備・キャンセル・世代管理は維持する。

画像は`GPUTexture | null`、動画・フォント・LUTは`FileSource | null`として渡す。画像のGPU転送は呼び出し側がリソース解決前に完了させる。画像のnullは未選択だけを表し、選択済みの画像にテクスチャがなければ読み込み失敗として通知する。素材IDや寸法のメタデータは解像度計画・リソース解決側で扱い、エフェクト実装にはファイルの読み取り口だけを渡す。

解像度は出力確保と初回の式評価より前に呼び出し側が決定し、コンストラクターへ必ず渡す。寿命中は固定し、変更時は`EffectRenderer`自体を破棄・再作成する。出力の途中交換や解像度未確定の状態は持たない。自動解像度の優先順位は、`intrinsicResolutionSetting`で指定した素材メタデータ、`resolutionInputParameters`で宣言した接続の計画寸法、描画先の順。配列・構造体は配下の全接続を調べ、最大画素数の幅・高さを使う。同数では定義・保存順で先頭を優先する。定数には固有寸法がない。GPUテクスチャ・現在のPlayerフレーム・式の評価結果から寸法を決めない。

原寸には全体の描画倍率、入力には上流で適用済みの倍率を使い、`auto`・`context`ではさらに自身の倍率を掛ける。各段階で四捨五入・最低1pxとし、GPU上限を検証する。`customAbsolute`は全体倍率だけを適用する。

静的設定と借用リソースはコンストラクターで受け取り、寿命中は変更しない。静的設定の変更時は呼び出し側が`EffectRenderer`自体を破棄・再作成し、新しいリソース世代を後段のキャッシュへ伝える。借用した素材は破棄しない。Visual Moduleでは通常パラメータの値だけの編集を除き、全エフェクトを再作成する。

フォント・LUT・Video Frameのローダーは生成時に素材を固定する。フォントとLUTは一度だけ読み込み、Video Frameは同じ素材への時刻要求だけを更新する。素材変更に対するローダー内の切り替え・再解決は行わず、インスタンス破棄後の非同期結果を無視する。

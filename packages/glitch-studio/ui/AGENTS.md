# Glitch Studio UI

## Rules

- これは動画編集ソフトです。Webサイトではないので、HTMLをセマンティックにしたりアクセシビリティを考慮する必要はありません。
	- スクリーンリーダーに対応することはありませんし、検索エンジン最適化を行うこともありません。
- コンポーネント以外は、基本的にdiv、span、buttonなど限られたタグを使う。
- aria属性・role属性は付けない。
- 特別な理由がない限りoverflow: hidden;ではなくoverflow: clip;を使う。
- styleタグ内でCSSを一行にまとめて書かない。
- 必ずCSS Modulesのクラス指定でセレクタを使用する。divやspanなどタグ名のセレクタを使わない。
- title属性を使わない。v-tooltipディレクティブを使用する。
- 属性が多い場合は一行にせず、複数行にする。
- Vueコンポーネントのテストで特定の要素を参照する必要があるときは、その要素に`test-`から始まる識別用data属性(例: `data-test-my-element`)を付けて参照する。特定のHTMLクラス名、内容、翻訳に依存したテストを書かない。

# タイムライン

タイムライン上に複数のレイヤーを配置して、動画を作成できます。

動画ファイルを開いて新規プロジェクトを作成すると、プロジェクトfpsを動画の推定フレームレートに合わせます。小数fpsは丸めずに保持し、可変fpsの動画では先頭付近のフレーム時刻から求めた代表値を使います。フレームレートを取得できない場合は既定の60fpsを使います。既存プロジェクトへの動画追加ではプロジェクトfpsを変更しません。

通常のシーク・コマ送りは、プロジェクトfpsにプレビュー倍率を掛けた実効fpsのフレーム単位で行います。手動シークは最寄りの境界、再生中の画像は音声時計の現在位置以前の境界で描画します。音声時計と保存済みのクリップ・キーフレームの時刻は丸めません。fps変更時は停止位置を新しい境界へ揃えます。目盛り・シークバーでShiftを押してクリック／ドラッグを開始すると、フレーム境界と目盛りへの吸着を解除して従来の整数ms単位で精密シークできます。操作開始時のモードを終了まで保ち、停止中の編集・再描画にも精密位置を引き継ぎます。通常シーク・コマ送り・再生開始で通常モードへ戻ります。

再生中は毎RAFで音声時計を読み、表示対象のプレビューフレームが変わった時だけ描画を要求します。RAFの経過時間では別途FPS制限しません。音声時計は`getOutputTimestamp()`の`contextTime`と`performanceTime`から現在の出力位置を補間し、音声デバイスの更新間隔による重複表示やフレーム飛びを防ぎます。音声のバッファリング中とAudioContext停止中は再生位置を保持します。編集・手動シーク・Worker復帰による明示的な再描画は、同じフレームでも省略しません。

動画フレームの検索時だけ、素材トラックの時刻精度へ要求時刻を揃えます。例えば1ms精度のWebMでは、60fpsの16.666...msを17msとして検索し、元動画と同じFPSでも一枚前の映像を重複して使う問題を防ぎます。精密シーク・書き出し・固定フレームの確定でも同じ読み出し規則を使います。逆再生の境界は丸めた後で排他的に扱い、映像の開始・終了は丸め前の要求時刻で判定します。プロジェクトの時刻・音声時計・保存する素材時刻は変更しません。

ブラウザー版・Electron版ともに、最終画像をGPUフレームキャッシュに保存します。環境設定のレンダリング欄で編集ウィンドウごとの上限（既定2GiB、0で無効）を変更できます。上限は解像度と保存形式から求めた推定容量で管理し、LRUで削除します。目盛り下の緑の帯は現在のScene・描画設定で再利用できるフレームを表します。精密シークは検索・保存を行わず、既存キャッシュは保持します。編集・Scene切替・描画設定変更では全消去します。書き出しでは使用しません。

キャッシュ範囲・フッターの使用率・シークの待機表示は、Workerから最後に受信した状態を使います。Workerは約100ms間隔で変更を確認し、変更時だけ通知します。UI側では編集・設定変更時にキャッシュ状態を消したり、UIの編集世代で通知を選別したりせず、次の通知までの表示の遅れを許容します。Worker破棄時だけ通知済みの状態を解除します。実際のキャッシュ削除と再利用の判断はWorkerが担当します。

BAKEボタンは、現在位置を最寄りのプレビューフレーム境界へ揃え、Scene終端まで一度だけ描画を進めます。現在のプレビュー設定を使い、通常再生と音声を止め、再生ヘッドとプレビューを更新します。UIが既存の`frameRendered`通知を待ってから次のフレームを要求するため、軽いフレームは設定fpsを超えて進み、重いフレームも間引きません。キャッシュ済みかどうかはレンダラーに委ねます。最後に通知された推定使用率が90%を超えたら、描画中の一枚の完了後に自動停止します。判定は表示用に丸める前の比率で行い、90%ちょうどでは継続します。開始時も最後の通知で判断するため、編集で実際のキャッシュが空になっていても、次の通知までは以前の高い使用率で停止する場合があります。キャッシュ無効時は開始できません。

BAKEの再押下は描画中の一枚が完了してから終了し、その位置で停止します。通常の再生・シーク・編集・設定変更・Scene切替・Visual Module Live Previewへの切替・書き出し開始・描画エラー・Worker破棄ではBAKEを中止し、元の位置や再生状態には戻しません。中止後に遅れて完了したフレームから次の要求を送ることはありません。BAKEの実行状態は保存・Undo/Redoの対象にしません。

VOICEVOXの発話は`subtitleDuration`に字幕長のモードを保持する。`fill`は次のキーまで、`specified`は整数msの指定長（0は非表示）、`speech`は生成音声長に整数msの`extensionMs`を加えた長さ。未生成のspeech字幕は次のキーまで仮表示し、生成後は音声長に追従する。字幕開始は発話キーのScene時刻に固定し、次のキー・クリップ境界で表示だけを打ち切る。モードの変更は発話設定画面だけで行い、指定終端が見える字幕帯の右端ドラッグは長さだけを変更する。字幕長と延長量の変更では音声を再生成しない。

- レイヤーは独立した表示名・パラメータ・キー・合成設定を所有し、グループ以外の時間情報は `clips` が所有します。クリップのIDは同じレイヤー内で一意です。空レイヤーを許可し、最後のクリップを削除してもレイヤーやキーを削除しません。
- 全クリップの配置は `startMs >= 0`・`durationMs >= 1` です。開始・長さ・終了は安全な整数ミリ秒です。通常再生の動画・音声素材は有限の素材範囲 `[sourceInMs, sourceOutMs)`、符号付きの `playbackRate`、`loop: boolean` を持ちます。固定表示の動画は `sourceTimeMs >= 0`、その他の種類は `contentOffsetMs >= 0` を持ち、素材範囲・内容オフセットは有限な小数ミリ秒を保持します。表示区間は `[startMs, startMs + durationMs)` です。同じレイヤー内で接触は許可し、重複は許可しません。未使用の素材範囲は衝突判定に含めません。
- 配置位置・キーの位置・共通移動量は最寄りの整数msに丸め、長さの上限は素材や空き区間を超えない整数msに制限します。ドラッグは開始時の状態と累積移動量から計算します。小数の内容オフセットを整数化したり、再生・評価時刻や素材の時間情報にこの丸めを適用したりしません。素材終端の演算誤差は素材長制限の共通処理だけで扱い、表示区間の重複判定には許容誤差を設けません。
- レイヤー設定・音量・モジュール引数のキーと式は、所属Sceneの時刻で評価します。式には `TIME` / `TIME_MS` を公開し、`PROGRESS` や `END_TIME` / `END_TIME_MS` は公開しません。タイムラインのキーはScene上の絶対時刻で、正規化・終端基準・繰り返し・時間伸縮に対応しません。
- キーフレームのコピー＆ペーストはコピー元と同じScene・レイヤー・パラメータのIDパスに対して行います。先頭をシーク位置（最寄りの整数ms）に合わせて全キーの間隔・値・補間を維持し、新しいIDを発行します。同じレーンの同時刻キーが一つでもある場合は全体を貼り付けず、既存キーを上書きしません。配列・構造体内の別レーンも同じルートの変更案へまとめ、一回のUndo/Redoで扱います。未設定のモジュール引数は貼り付け時に既定Bindingを独立して保存し、共有定義を変更せず、Undoで未設定へ戻します。
- 生成系・画像・Scene参照の内容時刻は `contentOffsetMs + sceneTime - startMs` です。子Sceneに渡す時刻、Visual Module内部の `TIME_MS` に使います。通常再生の動画・音声の素材時刻は、正方向では `sourceInMs`、逆方向では排他的な `sourceOutMs` を原点に、経過時間と符号付き倍率の積を加えます。ループ周期は `(sourceOutMs - sourceInMs) / abs(playbackRate)` で導出し、丸めずに経過時間を折り返します。モジュール内部の `END_TIME_MS` は `contentOffsetMs + durationMs`、`PROGRESS` は `(sceneTime - startMs) / durationMs` です。子Scene内のレイヤーは子Sceneの時刻で評価します。
- ローカルX軸目盛りは各クリップの表示区間に内容時刻で表示します。キーフレームのローカルスナップは、所属レイヤーの各クリップの目盛りをScene時刻に変換し、最寄りの整数msを使います。空白区間にはローカル目盛りを表示せず、キー自体はScene上の絶対時刻を保ちます。
- Visual Moduleの定義・参照はレイヤー所有で、動画・画像・音声のAsset参照とScene参照、動画の `audioEnabled`、動画・音声の素材範囲・倍率・ループ設定 はクリップ所有です。同じモジュールや子Sceneを参照していても実行状態をクリップごとに分離し、区間外では評価せず破棄します。
- クリップがない区間はレイヤーをスキップします。有効なクリップが透明な出力を返す場合は合成を行い、`replace` なら下層を透明に置き換えます。
- クリップの移動は配置開始だけを変更します。生成系・画像・Scene参照の左トリムは開始・長さ・内容オフセット、右トリムは長さだけを変更します。通常再生の動画・音声のトリムは倍率と方向に応じた素材範囲の端を変更します。逆再生の左トリムは素材終端、右トリムは素材開始を動かします。ループ中は全体終端を固定して1周分のトリム範囲を変え、追加の右下ハンドルは周期を保って全体長を変えます。周期以上の全体長を許可し、1周分に戻すとループを解除します。生成系（画像・Visual Module）の左延長は未対応です。動画・音声の素材使用範囲は素材長、全クリップの表示区間は隣のクリップで操作を制限します。ループでは表示長が素材長を超えても構いません。複数移動は全対象に共通の移動量を使い、押し出しや追い越しを行いません。
- 動画・音声の倍率変更は素材範囲と配置開始を保ち、全体長を倍率比で伸縮します。非ループでは素材範囲から長さを再計算し、整数msに収まらない端数だけを切り捨てます。素材範囲自体は削りません。ループでは全体長も同じ比率で伸縮します。隣のクリップとの衝突・1ms未満の配置は操作全体を拒否し、キーは動かしません。UIは百分率と逆再生スイッチで入力し、変更後の長さを確認してから一回のCommandで適用します。
- クリップ移動には所属レイヤーの区間内のキー（配列・構造体内のキーとVOICEVOXの空本文を含む発話キーも対象）が追従します。所属は操作開始時の半開区間を優先し、どの区間にも入らないキーだけは終了時刻が一致するクリップに追従します。ドラッグ中に接触・離脱しても対象は変えません。トリムやクリップ削除ではキーを動かさず、トリムで区間外になったキーも特別扱いしません。
- 追従と通常キー・発話キーのドラッグや時刻入力は、同じレーンの非移動キーに対して100msの間隔を残し、追い越しを禁止します。操作開始時から100ms未満なら元の間隔を下限にし、開始位置へ戻せるようにします。全クリップ・キーの制約を交差させて同じ移動量を適用し、選択キー同士の間隔は維持します。部分選択の時間伸縮も非選択キーへの同じ制約を使います。追加・貼り付け時に100ms間隔を強制する仕様ではありません。
- UIの`timeline-clip-move.ts`が追従対象と移動範囲を計算し、`timeline-keyframe-move.ts`がルートBinding・発話の更新案を作ります。Commandは全件検証後にクリップとキーを適用し、未設定の引数を独立したBindingとして保存します。履歴は元の未設定状態と計算済みの最終値を保持し、マージ後のUndo/Redoでもクリップと変更したパラメータ・発話を通知します。評価はScene時刻のままで、区間外のキーとの補間や区間前から続く発話の再生位置は保持しません。
- Sceneの長さはグループの子孫を含む全クリップの終了時刻の最大値、空なら0です。子Scene編集で親クリップの長さは変えず、子の終了後は透明・無音です。キーだけではSceneの長さを延長しません。
- 背景ダブルクリックで追加するクリップは標準5秒で、次のクリップと動画・音声の素材長までに制限します。素材変更は同じ種類に限り、開始を保ちます。動画・音声は素材範囲を先頭からに戻し、倍率を1、ループをfalseへ戻し、動画の固定表示も解除します。その他の種類は内容オフセットを0に戻します。動画・音声の長さは新素材長を次のクリップまでで制限し、画像・Sceneの表示長は維持します。
- Asset一覧から素材自体を短く差し替えた場合も、トリム後の区間が新しい素材長に収まれば修復を許可します。変更前の区間が素材長を超えていることだけではトリムを拒否しません。
- クリップは独立した選択対象です。コピー＆ペーストはコピー元と同じScene・レイヤー内で行い、複数選択は先頭を操作時点のシーク位置（最寄りの整数ms）に合わせて間隔を維持します。コピー時の素材・時間モデルごとの設定（内容オフセット、素材範囲・倍率・ループ、または固定地点）・長さ・動画の音声設定を保持し、新しいIDを発行します。一つでも重なる場合は全体を貼り付けず、境界の接触は許可します。キー・レイヤー設定はコピーせず、一回のUndo/Redoで全対象を扱います。レイヤー間移動・分割・スリップ・速度ランプ・再生途中へのフリーズ挿入は未対応です。

- レイヤーの開閉状態はUIが展開中のレイヤーID集合として持ちます。初期状態は空集合で、既存・新規レイヤーとも折りたたまれます。通常レイヤーの折りたたみではメインレーンを残し、キーフレーム・Clip time目盛り・VOICEVOX発話のレーンを隠します。非表示のレーンは背景ドラッグの範囲選択から除外し、仮想一覧の行高も表示中のレーン構成に合わせます。グループの折りたたみは子レイヤーの表示だけを変え、グループ自身のキーフレームレーンは維持します。開閉で描画・音声・パラメータ評価は変えません。
- レイヤー行のShift＋クリックは、最後の通常クリックまたはCtrl／Command＋クリックで選んだレイヤーを起点に、UI上の表示順で範囲選択します。起点はShift操作中に固定し、通常は範囲を置き換え、Ctrl／Command併用時は既存選択へ追加します。折りたたまれた子を除き、仮想スクロールの画面外の行も含めます。起点が削除・非表示・選択解除された場合は、選択中の表示可能なレイヤー、なければクリック対象を起点にします。起点はSceneごとのUI状態で、保存・Undoの対象にはしません。

レイヤーの合成処理にはVisual Moduleを使用することができます。

- 初期値は通常合成、不透明度1、無変形です。通常合成ではモジュールは透明背景の素材を出力し、タイムライン側で背景に重ねます。どの合成方法でもInから背景を参照できます。
- `replace` は背景を含めた完成結果を出力するモジュール向けです。変形後の出力で透明部分も含めて置き換えます。opacityは背景からその出力へのRGBAの補間量で、0なら背景、1なら出力そのものです。
- transformはレイヤーの出力全体に適用します。背景を加工する処理の中心・作用範囲だけを動かす機能ではありません。素材内のoriginを支点にfit後の素材を拡縮→回転し、その支点を画面上のpositionへ配置します。範囲外は透明です。positionの1は画面幅/高さの半分、回転の1は時計回り360度（1周）です。position・origin・scaleはvectorで、負の倍率は反転、0は透明化として扱います。
- originは透明な余白を含む入力テクスチャ全体を基準とし、中央が[0, 0]、左下が[-1, -1]、右上が[1, 1]です。範囲外も許容します。Visual Moduleなども出力テクスチャの寸法を使い、uniform出力にはタイムラインの画面サイズを仮想的な素材寸法として与えます。originとpositionの初期値は[0, 0]です。無回転・等倍でもoriginを変えると配置が変わります。Transformエフェクトのtranslationは従来どおり移動量です。
- 変形と合成はタイムライン専用の1パスで行い、VisualModuleRendererは合成設定を扱いません。無変形・opacity=1の置き換えは元のUniformOrTextureをそのまま受け渡します。

## レイヤーの識別色

レイヤーの識別色はInspectorで指定・解除できます。`color`は0〜1のRGBA配列または`null`で、初期値は`null`です。未設定時はレイヤー種別ごとのテーマ色を使用します。色バー・クリップ・グループの帯に反映され、子レイヤー行の祖先の色バーも各祖先の設定に従います。映像・音声の処理には影響せず、設定は保存・複製とUndo/Redoの対象です。

## マスク

- 画像を出力するレイヤーは、静的な`mask: null | { channel: 'alpha' | 'luminance'; inverted: boolean }`を持つ。nullは通常描画。マスク時は自身の色を重ねず、同じ合成境界の下層の合成結果を切り抜く。Transformは境界を作らず、Group・Scene内部のマスクは外側へ作用しない。Group・Scene自身も内部の描画結果をマスク素材として使える。音声・Camera・Transform自身には設定を持たせず、音声出力も変更しない。
- Alphaは素材の透明度、輝度は作業RGBの重み`[0.2126, 0.7152, 0.0722]`と素材の透明度からマスク値を求め、0〜1へ制限してから必要に応じて反転する。premultiplied RGBでは内積に透明度が含まれるため、alphaを再乗算しない。
- 素材のfit・変形・座標空間・clipToFrameを適用した範囲外はマスク値0。反転後は1となる。下層の描画範囲・基準枠は維持し、マスク素材の範囲を加えて拡張したり、残った領域へfitし直したりしない。カメラ背後のレイヤーは従来どおり合成をスキップする。
- マスク時のopacityは適用強度で、0では下層を保持、1では完全適用する。結果は`下層RGBA * mix(1, マスク値, opacity)`。RGBとalphaを一緒に減衰させる。保存したblendModeはNone・Replaceを含め使用せず、通常描画に戻すと再び使用する。
- クリップ区間外・無効レイヤー・映像出力のないGroupでは処理をスキップする。有効な透明出力は通常マスクで下層を消し、反転マスクでは残す。複数マスクは下から順に適用する。
- チャンネル・反転・マスクの有無はキーや式で変更しない。素材・変形・適用強度の時計とモーションブラーは既存の評価規則に従う。InspectorはopacityをMask strengthと表示し、マスク時はblendModeを隠す。設定の変更はCommandでUndo/Redoできる。

### 別レイヤーによるマスク

- 画像を出力するレイヤーは、`layerMask: null | { sourceLayerId: string; channel: 'alpha' | 'luminance'; inverted: boolean }`を持つ。設定時は参照先の単独描画結果で、そのレイヤー自身の作用範囲を切り抜く。既存の`mask`（下層全体の切り抜き）と併用すると、その作用範囲にも参照マスクを掛ける。
- マスク元は同じ合成境界の別の映像レイヤーに限る。Transformを透過して選択でき、Group自身は外側の境界に属する。flat・preserveDepthともGroupの内外をまたぐ指定は拒否する。Sceneレイヤーは完成した画像を使い、参照先Scene内部のレイヤーは選べない。
- 参照先の位置・変形・投影・opacity・clipToFrameと、その参照先自身の`layerMask`を反映する。対象側のFitや変形はマスク元へ再適用せず、共通の合成空間で重なる画素を使う。マスク画像の範囲を対象の描画範囲へ加えない。
- Alpha・輝度・反転の計算は既存マスクと同じ。マスクを被覆率へ掛けるため、通常合成では対象だけを減衰し、Replaceでもマスク外の下層を保持する。対象のopacityは通常の合成設定として使う。
- 未解決・無効・祖先無効・クリップ区間外・映像出力なしの参照先は透明黒とする。通常マスクは0、反転マスクは1。削除後もIDを保持し、Undoで復旧できる。チャンネル・反転・参照先は静的な設定で、マスク元自身の時計・モーションブラー規則に従って評価する。
- `isIncludedInComposite`は通常合成へ含めるかを指定し、初期値はtrue。falseでも素材・単独描画への参照と音声出力は有効で、`composited`はそのレイヤーを重ねない下層結果になる。Inspectorでマスク元を通常合成から除外できる。`isDisabled`は引き続き映像・音声・参照用評価をすべて停止する。
- 参照の依存は単独描画・合成へ加え、素材出力へは加えない。マスク元が対象の素材を読む配線は許可し、マスク同士・下層入力・画像入力を経由した循環は無効化や区間外でも拒否する。同じScene配置・サブサンプル内でマスク元の評価を共有する。
- 設定は保存・CommandのUndo/Redo・複製の対象。複製範囲内のマスク参照は新しいIDへ付け替え、範囲外への参照は維持する。タイムライン行には参照マスクと通常合成からの除外を表示する。

## 動画の固定表示

動画クリップは通常再生の`TimelineVideoPlaybackClip`と固定表示の`TimelineVideoHoldClip`のunion。固定表示は整数msの配置・表示長と小数msの`sourceTimeMs`を所有し、素材範囲・倍率・ループ・内容オフセットを持たない。`audioEnabled`はfalse。表示区間は通常の半開区間で、表示長は素材長に依存せず、左右の伸縮・移動では固定地点を変えない。素材長と照合するのは固定地点だけで、隣接クリップとの衝突と最小1msは既存の配置規則を使う。

InspectorのHold current frameは、操作時のScene時刻を速度・逆方向・ループに従って素材時刻へ写し、通常描画と同じリーダーで選ばれるフレームのtimestampを確定する。逆再生の排他的境界と秒/ms変換の丸めを考慮し、固定後も同じフレームを選ぶ。映像のない区間は操作を失敗させる。デコード待ちに選択・クリップ設定・素材・Sceneが変わった結果は破棄する。Hold source timeの明示保存も実フレームを選び直し、表示区間を維持する。

切り替え・地点変更はholdVideoClipFrame Commandで行い、配置・素材ID・クリップIDを保持する。Undo/Redoでは元の時間モデルを復元し、旧モデルのフィールドを残さない。コピーと保存も固定地点を保持する。素材変更は同一Assetの再選択も許可し、通常再生に戻す。音声計画とループ計画には固定クリップを含めない。固定するのは動画の前景だけで、合成設定・キー・後続エフェクトはScene時刻で進める。同じ素材時刻の既存キャッシュでデコードとGPU転送を省き、合成は毎回行う。

## エフェクトレイヤー

- `TimelineEffectLayer` はエフェクトの種類・パラメータ・解像度を所有し、クリップは時間情報だけを所有します。作成後のエフェクト種別変更は扱いません。Visual Moduleを経由せず `EffectRenderer` をクリップごとに使用し、区間外では破棄します。
- `EffectDefinition.kind` は `modify` / `generate` を明示します。作成時、modifyは主入力を `lowerLayerOutput`、合成を `replace` にし、generateは定義の入力初期値と `normal` を使います。主入力がnullなら自動割当を行いません。modifyの主入力のリセットも `lowerLayerOutput` に戻しますが、手動の入力・合成変更は互いに連動しません。
- `lowerLayerOutput` は同じ親の下層レイヤーの合成結果です。グループ内部から外側の背景は参照しません。下層がなければ透明黒です。配列・構造体内を含め `canNode: true` の末端にだけ指定でき、主入力以外にも指定できます。サンプリング設定の既定値は `cover` / `repeatMirrored` / `linear` です。入力型はcolorとして既存のノード互換性判定を使い、UIの型安全設定が有効なら不一致の接続を禁止、無効なら警告付きで許可します。
- `anotherLayerOutput`は同じScene内の映像レイヤーをIDで参照します。Group・Transform配下も選べますが、Sceneレイヤーの参照先Scene内部には踏み込みません。音声・Camera・Transform自身は対象外です。エフェクトでは`lowerLayerOutput`と同じ末端へ指定でき、Visual Moduleレイヤーでは`canNode: true`の公開画像入力へ指定できます。Visual Module内部のBindingには追加しません。
- `outputStage`は`source`（素材出力・既定）、`rendered`（単独描画結果）、`composited`（下層との合成結果）です。通常の素材出力はレイヤー自身の配置・合成前。単独描画は配置・投影・opacity・clipToFrame・`layerMask`を反映し、blendModeと下層切り抜き用の`mask`は適用しません。合成結果は参照先と同じ合成境界内で、そのレイヤーまで合成した画像です。Transformは境界を作りません。エフェクトとVisual Moduleはレイヤーとしてのprimary出力を使います。
- `preserveDepth` Groupの素材出力は、通常描画と同じ空間で子のZ・Groupや祖先の変形・カメラを反映して合成した中間画像です。Group自身のopacity・blendMode・マスク・clipToFrameはまだ適用しません。2D画像として渡し、後段で変形・投影を二重適用しません。Groupの配置やカメラを変えると素材出力も変わります。
- 配置を持つ出力は参照先の合成空間のScene基準枠で確定して画像入力へ渡し、位置と透明余白を維持します。画面外領域はこの境界で切り取ります。素材の寸法がそのまま利用できる画像・Effectなどは元の寸法を維持します。
- 未選択・参照切れ・無効・祖先無効・クリップ区間外・映像出力なしは、どの段階でも入力として透明黒を渡します。参照IDは保持し、削除のUndoで復旧できます。Group・Sceneの複製では、複製範囲内への画像参照も新しいIDへ付け替えます。
- 画像の依存は素材・単独描画・合成結果を区別し、`lowerLayerOutput`・公開主入力・Groupの内部合成も含めて静的に循環を検出します。無効化やクリップ期間が重ならないことによる例外は設けません。配線・出力段階・並び順・階層・公開入力の変更時に再検証します。
- 通常描画と画像参照は同じScene配置・サブサンプルの評価結果を共有し、素材の履歴を二重に進めません。参照する側だけがモーションブラー無効でも、取得先は自身と祖先の設定に従った通常描画の時刻・空間で評価します。参照する側の基準時刻で取得先を再評価しません。
- Visual Moduleの公開主入力も編集でき、既定値とリセットは`lowerLayerOutput`です。明示Bindingは自動割当より優先します。公開入力にはfit・wrap・filterを保存せず、サンプリングは内部接続で指定します。エフェクト側の画像Bindingは従来どおりこれらの設定を持ちます。
- 直接のパラメータ編集・選択・キー操作は `['items', 'item-id', 'color']` のようなIDパスを使います。配列要素の削除で内部のキーも消え、UndoでIDごと復元します。キー・式の評価時刻とスコープは通常のレイヤー引数と同じです。`EffectRenderContext.time` だけはクリップの内容時刻を秒で渡します。
- 出力は `primaryOutput` だけを使用し、nullの場合は合成をスキップします。タイムラインに不向きなエフェクトも候補から除外しません。Player入力、シーク前の履歴再現などは保証しません。
- 解像度はノードと共通の `EffectResolution`（`auto` / `context` / `customAbsolute`）で、初期値は`{ mode: 'auto', scale: 1 }`です。autoは素材固有寸法・解像度用入力のテクスチャ寸法・所属Sceneの順で解決します。
- `auto` / `context`では正の有限数の倍率`scale`を数値で自由入力でき、基準となる幅・高さの両方に掛けます。両モード間では倍率を維持し、`customAbsolute`から戻すと1になります。保存・Undo/Redoの対象で、式・アニメーションには対応しません。
- 全体のプレビュー・書き出し倍率で計算用寸法を求めた後にレイヤー自身の倍率を掛け、四捨五入して各辺を最低1pxにします。入力テクスチャに全体倍率を重ねて適用しません。autoで入力に追従する場合は入力側の倍率も引き継ぎ、contextは所属Sceneの寸法だけを基準にします。GPUの上限超過はエラーにし、`customAbsolute`は全体倍率だけを適用します。

## シーンの解像度

- Sceneは `resolution: { mode: 'project' } | { mode: 'customAbsolute', width, height }` を持ちます。projectは親Sceneではなく、プロジェクト自身の基準寸法を参照します。設定は配置レイヤーではなくScene定義が所有します。
- 数値指定は基準サイズです。プレビュー・書き出しの倍率はScene・素材・ノードの基準サイズに一度だけ適用し、入れ子や入力追従で重複適用しません。レイヤーのscaleは描画解像度を変えません。
- Sceneの出力は、そのSceneの描画寸法を持つ画面として確定してから親へ渡します。定数や無変形replaceでもこの画面を維持し、親のfit・origin・transformは透明余白を含むScene全体を対象にします。Visual Module自体の境界では従来どおり定数を維持します。
- 書き出し寸法は選択したSceneの基準サイズと書き出し倍率から求めます。プロジェクトの基準サイズを上書きせず、倍率と最終出力寸法を独立して渡します。MP4の偶数寸法補正は最終Canvasだけに適用します。

## Transformレイヤーとカメラ

- Transformは合成境界を作らず、子へXYZ移動・XY拡縮・平面内回転を継承する。ローカル原点を支点に拡縮→回転→移動し、入れ子は親行列×子行列で合成する。非等方scaleと回転によるせん断も保持する。Zは加算のみで、XYのscaleでは変わらない。
- Position XY・Position Z・Scale・Rotationは所属Scene時刻の式・キー・オートメーションで評価する。既定値は位置と回転が0、scaleが[1, 1]。負のscaleは反転、0はその軸を潰す。回転の1は時計回り360度（1周）で、Sceneの縦横比を補正する。
- On screenにも祖先TransformのXY移動・拡縮・回転を反映し、Zとカメラは適用しない。flatグループ内部ではZを使わず、XY変換だけを内部2D配置へ適用する。プレビューの枠・逆変換も同じ行列と境界を使う。
- カメラはXY・Z・roll・縦画角を持つ。rollは既定値0、1が時計回り360度（1周）で、所属Scene時刻の式・キー・オートメーションを使える。投影はカメラ位置を引いてからロールの逆回転を適用する。On screenはロールの影響も受けない。
- カメラ位置には祖先Transformの行列と加算Zを適用し、rollには祖先のrotationだけを加える。親のscale・反転・せん断はカメラの向きや画角を変えない。カメラと映像を同じTransformへ入れても、親のscaleによる拡縮は相殺しない。
- ブラー無効時は、指定したTransformとその子孫をフレームの基準時刻で評価する。カメラ自身だけの固定では、祖先Transformの拡縮・回転・移動はサンプル時刻のまま維持する。

## グループレイヤー

- `TimelineGroupLayer`は`layers: TimelineLayer[]`を所有する。`clips`・独立した解像度・ローカル時刻は持たず、子孫も所属Sceneの時刻と画面を使う。レイヤーIDはグループをまたいでScene内で一意にする。
- 透明背景に子を下から順に合成し、グループ自身のopacity・blendを一度だけ適用する。flatは内部を2D合成して一枚の平面へ、preserveDepthは子のZを維持して投影後にグループ合成する。画面外も保持し、clipToFrameで明示的に切り取る。外側の背景を共有するパススルー合成は提供しない。グループ内の`lowerLayerOutput`とVisual ModuleのInは、同じ親の下層だけを受け取る。
- 有効な子孫の映像出力がない時刻はグループの合成をスキップする。有効な透明画像の出力は`replace`も含めて合成する。無効なグループは子孫の描画・音声・直接参照を無効にし、描画リソースを解放する。音量0や不透明度0とは区別する。
- `anotherLayerAudio`は同じSceneのグループ内も参照できる。自分自身を除く音声出力レイヤーを対象とし、グループを選んだ場合は子孫のミックスを返す。取得元自身と子孫の音量を反映し、取得元の祖先グループの音量は反映しない。祖先が無効な場合は入力なしとするが、参照IDは保持する。参照先Scene内部のレイヤーには跨らない。`lowerLayerAudio`は同じ親の下層だけを取得する。
- 仮クリップは子孫の全クリップの最小開始〜最大終了で求め、無効なレイヤーも含む。内部の空白も帯に含めるが、評価の有効区間には使わない。空のグループには帯を表示しない。長さの拡縮・トリム・内容オフセットはない。
- 仮クリップの移動は全子孫のクリップ、グループ自身と子孫の全タイムラインキー、VOICEVOX発話キーを同じ整数msだけ移動する。クリップ外のキーも含め、0より前へ出ない範囲で制限する。参照先Sceneや共有Visual Moduleの定義、素材内容オフセットは変更しない。式・オートメーションの時計は引き続きScene時刻とする。
- グループ化は同じ親の連続した兄弟を対象とし、その位置へ既定設定のグループを置く。親変更は自己・子孫への移動を禁止する。グループ解除は子をその位置へ昇格し、グループの設定は破棄する。見た目・音量を保存する補正は行わない。構造変更は一回のUndo/Redoとレイヤー階層の同期で扱い、Scene設定の変更とは分ける。同じ親に残る既存配置の描画履歴は維持し、親が変わる配置は移動先で生成する。
- グループ複製は全子孫のレイヤーIDとクリップIDを再発行し、複製範囲内の`anotherLayerAudio`参照だけを複製先へ付け替える。範囲外への参照は維持する。Scene複製も同じ規則とする。開閉状態はUIだけが持ち、無効状態とは独立する。
- プレビューの子レイヤーの枠は祖先の変形を順に反映する。ドラッグはポインターを祖先の逆変換で子の座標系へ戻して編集する。所属グループのキャンバス端への吸着は、祖先の変形を反映した画面上の距離で判定し、移動・拡縮とも許容距離を6 CSS pxに保つ。祖先の倍率が0ならハンドルを表示しない。

動画・音声の倍率の絶対値は0.01〜16（1〜1600%）とし、負なら逆再生する。極端な早送りによるデコード・音声フィルターの負荷を制限するため、UI・Command・読み込み時に同じ範囲を検証する。0倍は許可しない。

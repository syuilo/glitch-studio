# 空間座標と距離

位置・移動ベクトル・距離・SDFには、描画領域の**長辺全体を1**とする共通の等方的な単位を使います。中央は`(0, 0)`、右が+X、上が+Yです。この規約はGlitch Studio全体で固定し、座標系を選択する設定は設けません。

| 描画領域 | 左下 | 右上 |
| --- | --- | --- |
| 正方形 | `(-0.5, -0.5)` | `(0.5, 0.5)` |
| 横長2:1 | `(-0.5, -0.25)` | `(0.5, 0.25)` |
| 縦長1:2 | `(-0.25, -0.5)` | `(0.25, 0.5)` |

幅W、高さH、長辺L=max(W,H)に対し、位置`(x,y)`の画像上のピクセル位置は`(W/2+xL, H/2-yL)`です。X/Yへ同じ倍率を掛けるため、円・角度・ベクトル長は縦横比によって歪みません。同じ縦横比で解像度だけを変更しても、相対的な配置は変わりません。

## 位置とベクトル

位置Aから位置Bへの移動は、そのまま`B-A`です。例えば`(0.1,0)`は、位置なら中央から右へ長辺の10%、移動ベクトルなら右へ長辺の10%を表します。Vector Displacement、Transform、Channel Shift、Text PatternのTranslationなどはこの移動単位を受け取ります。ベクトルの回転・長さ・極座標分解にも縦横比補正は必要ありません。

Pointer Trail・Position Trailも同じ単位を使い、Vector Coordinatesを持ちません。軌跡のStrengthや減衰は効果の係数として適用します。Optical Flowの出力は共通単位/秒であり、1フレーム分の移動として使う場合は経過秒数を掛けます。Gradient・Scalar Gradientは共通座標に対する偏微分を返します。Normalize後の勾配は長さ1です。

旧座標への変換関数`ISOTROPIC_TO_SCREEN`は廃止します。

NoiseのCoordinatesは共通単位の絶対座標です。Coordinate SourceがScreenの場合も同じ共通座標を使います。Size Referenceはノイズの密度を換算し、入力座標の単位は変更しません。Offsetはノイズ内部の座標単位です。

ベクトル型そのものは任意の数値の組も表せるため、すべてのvector値を位置と解釈するわけではありません。拡大率、周波数、反復回数、セル内比率などは、それぞれのパラメータ固有の意味を維持します。

## Size Reference

[Size Reference](size-reference.md)は、見た目のサイズを指定する際の換算基準です。位置や出力データの単位を切り替える設定ではありません。基準寸法Bに対する長さsは、共通単位では`sB/L`になります。セル幅やフォントサイズに対する比率、周期に対するPhaseなどは、それぞれの局所的な比率を維持します。

SDFは内側が負、輪郭が0、外側が正で、距離の1は長辺全体と同じです。Shape SDFのSize ReferenceがHeightでも、出力距離の単位はLong Sideです。同じ描画領域なら、異なるSize ReferenceのSDF Boolean・SDF to Mask・Glassへ接続できます。空形状の予約値65504は距離として倍率変換しません。

## Timeline

レイヤーのPosition、Transform、Group、CameraのXY/Z、シェイプ・文字の位置と寸法も共通単位を使います。Positionは配置先のScene基準、Originは透明余白を含む素材全体の長辺基準です。素材とSceneの縦横比が異なる場合、それぞれの画面端の値も異なります。OriginをFit後の見えている範囲から再定義することはありません。

On screen / Worldはカメラと祖先の投影を適用する範囲の設定として維持します。数値の距離単位は同じです。カメラの画角は縦画角で、作成時の既定Zは`H/(2L tan(22.5°))`です。既定画角45°でZ=0のSceneが画面に収まります。保存済みZはSceneの比率変更時に自動換算しません。

## 内部座標と入力接続

全画面頂点・画像サンプリング・Timelineの合成行列とクリップ範囲は、内部で各軸`[-1,+1]`を使えます。公開する位置・変位との境界で`@gs/shared/spatial-coordinate.ts`により換算します。内部アルゴリズムが画素・高さ・短辺単位で計算する場合も、公開する入出力を共通単位へ戻します。

入力のFit/Wrap/Filterは既存のサンプリング規則を維持します。異なる描画領域へ接続する際のベクトル値の変換、SDFの距離補正や再計算は行いません。同じ縦横比の解像度変更には共通単位をそのまま使えますが、異なる縦横比へのFitでは距離と形状が一致しない場合があります。非等方拡縮後のSDFは、単一の倍率補正では厳密な距離場になりません。

旧座標や廃止した座標系設定からのマイグレーションは行いません。
